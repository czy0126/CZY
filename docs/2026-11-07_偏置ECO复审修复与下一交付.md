# 偏置关断ECO复审、实际修复及下一交付（2026-11-07）

本轮审核了新增偏置关断原生ECO。它确实已有原理图、网表和行为仿真，但原“SET优先”“默认断开”“反灌通过”不能直接作为硬件结论。已修正原生逻辑和负载条件，并在本机重新运行LTspice。

## 已修复到原生文件

**POR与复位冲突。** 原SET=FAULT或POR，RESET只屏蔽FAULT。POR和RESET并发时，实际CD4013可令Q与Q反相输出均高，PERMIT与Q反相输出形成的使能可能开通；软件SET优先函数把问题藏住了。参考[TI CD4013B原厂手册](https://www.ti.com/lit/ds/symlink/cd4013b.pdf)。

已复用U50C：5脚SET_LATCH、6脚SET_N；U52A的2脚改SET_N。U52B先产生ENABLE_RAW，U52C用8脚ENABLE_RAW与9脚SET_N相与，10脚才输出ENABLE。这样SET同时屏蔽复位与使能。没有增加逻辑芯片数量。新增测试按实际元件引脚网络穷举，包含Q反相输出为高的危险状态；原生网表也已重新核对。仅证明静态网络，真实门延迟与慢上电仍需验证。

**实际负载。** C54原3.3µF并不等于SR板C1+C2+C3的10+1+0.1µF；已改11.1µF等效负载。该等效电容银行仍待准确料号，不应直接当标准单颗11.1µF采购。R62在15V下耗散0.225W，原0805/0.1W不足，已改1206/最低0.5W要求，准确MPN仍待选。

**仿真边界。** 模型增加POR期间复位脉冲、SET/RESET重叠和使能监测，CD4013两异步输入同时高时不再令Q反相输出保持低。预置锁存与栅极初态只用于该行为场景，删除了“异常启动脉冲只是模型假象”的推断。撤回人工100pF采购上限：真实两只主PMOS的总Qg/Ciss、Q55及寄生需重新计算，不能硬凑60pF。

## 补充反向阻断反例（本轮新增实跑）

运行 tools/bias_cut_reverse_corner.py 生成假设阈值失配deck，再以本机LTspice执行并用--record记录。在15V输入/16V强制反灌、主开关Vt=0.6V、Q55 Vt=2.5V、两者Vh=0.3V的行为模型下，输入回灌最小约0.616656A，反灌沿最大约0.736030A，100µA筛选失败。原始deck/log/json位于pcb/bias_cut_eco/bias_cut_reverse_mismatch.*，含输入与日志哈希。

这是**假设模型反例**，不是已选器件的原厂角落，也不是硬件测量。它证明原选型约束和18V单点不足以保证阻断：Q51可能先导通，而Q55尚未能抬栅。下一交付优先级因此上调：先重新审查反向阻断检测/高边路径，可比较有实际反流保护与限流的集成方案；若保留分立方案，必须给出全温阈值关系、栅驱动及瞬态依据，不能仅挑“逻辑电平PMOS”。R57持续耗散与启动限流一并处理。
