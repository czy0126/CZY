# Rev B 整改审核与后续路线

本轮结论：旧偏置功率段不接受；已交付替代候选的原生原理图、BOM、10个LTspice功率路径筛查及可重建脚本。真实控制、SR换流、保持热量和硬件验证尚未完成，不能据此投主板。旧Rev A文件保留为失败证据，后续修改以Rev B为候选起点。

## 已完成的实际改动

路径：`VDD_IN → Q50 → R59(22Ω) → D50 → VDD_SR`。

- 删除依赖阈值匹配的Q51/Q55跟随结构；串联D50阳极朝输入、阴极朝输出，不存在绕过它的Q50体二极管反灌路径。
- Q50候选DMP3098L-7，SOT23，1G/2S/3D；R50改10k栅源上拉。Q52、独立5V锁存及SET/reset互锁保留。
- D50候选ES1D-E3/61T，SMA；不能把模型的nA级漏电当成实际器件保证，原厂100°C上限为100µA（额定反压测试条件）。浮空输入仍可能被漏电充电。
- 增加22Ω/1%启动限流，候选CRCW120622R0FKEAHP；R57改2.2kΩ，候选CRCW12062K20FKEAHP。0.75W额定需满足原厂PCB热条件，脉冲合格状态仍为OPEN。
- Q41/R44快速REG钳位不改。R57现在只承担较慢的偏置泄放，不能替代快速关断。
- R62只是假负载，C54只代表SR实际11.1µF电容；集成时不能追加同一组负载和电容。

交付在 `pcb/bias_cut_revision_b/`；生成器 `tools/bias_cut_revision_b.py`。制造索引已标记Rev A历史失败、Rev B候选原理图，二者均无偏置板PCB或制造批准。

## 可重复证据及其边界

本地LTspice 26.0.2实际运行10个deck；原理图ERC=0；相关120项Python检查通过。`report.json`记录各deck/log哈希，`full_control_simulated=false`、`hardware_qualified=false`。

| 项目 | 本轮结果 | 不能推出的结论 |

## 本轮进一步确认的关键卡点

1. **实际偏置预算大于原15mA假设。** BSC010N04LS6表中0→10V Qg最大83nC（指定测试点）；两只、200.62kHz，再加1.5mA控制器工作电流，计算为34.80mA。实际REG可到约11V，83nC不是该电压下的完整保证上界，必须继续补充。四组约139mA只是相同假设的估算，不允许四组共享当前22Ω方案。优先每个UCC24624独立偏置切断支路，或重新设计集中限流。
2. **慢泄放不一定使钳位能量变大到不可接受，也不能直接宣称安全。** 偏置确实隔离后，11.1µF在15.75V储能约1.38mJ（不含REG电容、其他回灌及关断延迟期间能量）。这能约束一次事件的总能量，但不能替代局部功率、结温和重复故障验证。
3. **持续外部注入VDD_SR时，上述有限电容能量界失效。** D50只阻止其流回输入；无法消除施加在输出的外部电源。即使R57仅0.262W，UCC24624仍可能持续给REG钳位供电。H5必须找出实际回灌来源、源阻抗与能量；若VD/其他引脚持续供电，须在该路径整改或改成不依赖持续短接REG的可靠门极关断方案。
4. **原15V硬件H1条件不能与Rev B输出直接混用。** 在未改输入规范前，Rev B带载输出低于15V；新增实际偏置范围测试，同时保留原15V参考测量，分别标识。

### P1：验证板与SR换流闭合

T1–T3收敛后制作偏置验证小板PCB、DRC、BOM、贴片与制造文件；板上预留VDD_SR、REG、两路VGS、反向注入、电流测量接口。复用已存在的SR故障验证板，避免重造整套控制平台。

硬件顺序：无主功率仅外供偏置 → 受限能量SR激励 → 接入单磁件低功率。H0–H5逐项保留原始示波器CSV、探头比例、采样率、供电/负载条件及文件哈希。SR换流须检查VDS/VGS/支路电流、反向导通、死区与故障相位；禁止以VDD下降曲线替代换流证据。当前所有未执行硬件行保持未执行。

### P2：主功率、磁件与布局

控制接口稳定后推进磁件样件与功率板：按现有RFQ核实实际磁芯尺寸/高度、材料损耗、绕组结构、漏感与热路；不要把计算完成称为磁芯完成。先单组低功率确认磁化/漏感/谐振及SR相位，再扩展四组均流。磁件机械与大电流铜路布局可提前进行，控制接口未闭合前不冻结全板投产。

输出应包括实物可采购BOM、绕组图和磁件测量记录、可编辑原理图/PCB、ERC/DRC、制造包、装配与上电步骤。固定变比优先验证增益随输入/负载的自然变化，不把2V精确稳压作为当前拓扑承诺。

### P3：逐级功率与薄型迭代

先完成低电流稳定启动和停机，再按25A、50A、100A里程碑测试效率、温升、均流、纹波和换流。首版目标仍以可工作的100A级样机为先；之后才推进120A与≤10mm薄型。每一步只按测得的损耗/磁通/温升决定下一版，不继续扩展审核框架而拖延样机。
