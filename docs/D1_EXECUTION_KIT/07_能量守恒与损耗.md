# 100 A 能量账本闭合实验：统一物理口径

## 核心方程

同一电路、同一窗口 [t0,t1] 下：

    ∫ Pin dt − ∫ Pout dt
      = ∫ Σ P_diss dt + E_stored(t1) − E_stored(t0) + E_unaccounted

按全窗时长 Δt 归一化成 W。输入端口、输出端口、所有行为源/偏置和真实 MOS/二极管功率符号需事先统一；损耗不得重复统计变压器 Rser 和磁件设计包估算铜损。**模型效率、器件估算损耗、物理守恒闭合**是三种不同报告。

## 容易漏的能量项

1. 四只多绕组耦合变压器，不只是 ½ΣLi²：储能有矩阵形式 E_L=½ iᵀ L i，包含全部 Lp/Lsa/Lsb 互感项（前提是该耦合模型构成合适的正定/半正定储能矩阵，并与 SPICE 耦合定义一致）。若内部状态不可观测，应写 ENERGY_NOT_CLOSED，不宜猜一个储能变化补差。
2. Cr/Cout/Cin、自举和 MOS Coss/Cgs/Cgd：E_C=½CV² 对恒定线性 C 成立；电压依赖 Coss 应采用 Eoss(V) 或积分，不能直接用名义 C 一概替代。
3. MOS 的沟道、反并联二极管、门极驱动/独立偏置源、CT 负载、输入输出铜箔与 ESR；区分外部工程估算与 deck 实际测得。
4. 残差小不等于峰值 SOA 安全；同样，守恒未闭合不妨碍先开展 CAD 设计，但**禁止**发布有效率认证和连续额定。

## 原仓库目前的异常如何排查

- 100A 主账本目标残差≤0.2W，一些 5/2/1ns 情况仍 NOT_CLOSED；50V/120A 相位对齐的已列损耗差约 0.492W，超过目标。
- 改求解步长会改变 SR 导通时序/输出工作点，所以“5ns→0.5ns”不应被简单视作固定物理状态的数值细化。
- 先固定负载条件，复核相位、同窗口；将端口电力和每个耗散元件逐项积分，再分解储能和外部偏置。对比至少 5/2/1ns 与多相位窗口及不同求解选项，观察稳定值，不允许随意删去 0.605W 之类较大的端点储能项。
- 对新增实际 PCB 铜路损耗，四组各约 25A 均流假设下应用 Σ I_k² R_k，而非将某最差支路毫欧值乘全部 100A²。

## 交付模板

templates/simulation_run_register.csv 保存每次重跑；在具体技术报告中附 energy_terms.csv（后续可新建）列：term、source_ref、sign、integration_window、J、average_W、observed_or_estimated、uncertainty、SHA256。目标是别人可以从同一 RAW 重算，而不是“看上去效率很高”。

## 数值闭合判据

研究对象若只是行为模型，必须如实注明“不具有真实开关器件的非线性/热/寄生完整性”，即使 0.2W 达标也不能自动升级为硬件损耗和额定认证。
