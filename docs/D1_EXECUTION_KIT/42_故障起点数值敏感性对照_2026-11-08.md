# 42 — P0 电源启动的诊断仿真，不改变黄金模型

目的：原始 5A SR_ON 在 0.5698ms 左右发生 SR_DEVICE 体二极管内部节点奇异矩阵，10A SR_ON 在 0.5578ms 左右出现 NaN；两者都位于 VIN 0.4–0.8ms 斜坡，而 REG 1.2ms 后才启动。应该比对正常二极管/无 TT/小泄漏，而不是宣称真实 SR 控制失效。

此工具自动基于已提交的 5A 标准源网表，截取前 0.62ms，只移除依赖 6–8ms 的旧测量并增加 600us 的诊断观测，运行四种完全分离的方案：原始 ON、二极管 TT=0 的 ON（仅数值诊断）、增加 100Meg 并联泄漏电阻的 ON（仅数值诊断）、原始 OFF。使用 ADI 官方签名安装包的 LTspice Windows Runner 并行求解并保存原始 .log/.raw，即使 solver 报错也保留输出。

注意：任何简化模型即使能跑通也不能据此公布效率、5A 实际负载能力或硬件上电许可。短时间 0.62ms 对比仅能定位第一个数值失稳的模型影响，不代表 8ms 启动或稳态完成。根源应以完整模型真实复现、器件物理 SOA 和正式硬件关断实验验证。
