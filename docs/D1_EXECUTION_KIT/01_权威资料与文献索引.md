# 权威资料、论文索引与使用顺序

**选择规则**：①厂家原版 Datasheet/应用笔记（引脚、额定、保护、温度）；②会议/期刊论文（架构和测量方法）；③PCB/EDA 厂商当前工艺能力（制造约束）；④开源模型（仅供方法参考）。**绝不把论文中的器件/性能直接写成 CZY 验收。** 看不到 datasheet 的参数列必须 PENDING。

## 文献中能借鉴、不能照搬的量

- IEEE-01 的文献实验点：40 V→1 V、200 A、1 MHz，报告峰值效率 97%，功率密度 1394 W/in³；**不能**视作该 CZY 模型在 48V→2V 的效率。借鉴的是“缩短大电流副边绕组并靠近 SR+Cout”的布局物理。
- IEEE-02：APEC 2024 报告 24:1 的高增益 500 A 演示，200 A 时效率 >95%、500 A 时 >90%、峰值 97.1%（为论文声称的测试条件）；借鉴“级联原边、并联次级、标准 PCB 变压器”，但必须重新确认新旧拓扑可否满足 10 mm、故障保护和主隔离。
- 工艺官网参数会随工厂、层数、板厚变化；特别是 **五磁件沉槽、盲槽离铜层剩余介质厚度和压紧结构**，必须取得 PCB 制造商对具体 stack-up/开槽图的书面 DFM 答复，而不是只引用网站上某项最小能力。

## 建议每份参考的提取表

| 字段 | 目的 |
|---|---|
| source_id / exact_url / document_title / revision / retrieved_date | 可追溯，不随浏览器跳转丢失版本 |
| applicable_pin_or_rating / condition / min_typ_max / temperature | 不偷换典型值与绝对最大值 |
| design_ref / selected_MPN / difference_from_existing_model | 确认对哪个 PCB/BOM 位号生效 |
| evidence_path / reviewer / status | 关闭条件（PENDING / REVIEWED / REJECTED） |

用 templates/reference_traceability.csv 逐项填写；此目录不自动下载厂商 PDF，也不把未审核网页摘要当成器件数据。
