# D1 — 原生主板 39 个错误厂商元件号的工程替代候选（2026-11-08）

**NOT_FOR_FAB / NOT_FOR_PROCUREMENT。** 本次是可核查的供应商型号收集，不是物料认证、BOM更换或实物采购。基于原生EasyEDA厂商字段硬门禁 `hardware/dcx_main/native_inventory_bom_gate.json` 的39个冲突实例，整理出13种需修复的电阻/电容设计目标和实际厂家可订购型号。R8只允许禁装，不存在“先找1k替换”的问题；其余38个有具体候选号。

所有型号都是**0603名义尺寸、标称值符合**的采购调研候选。不得将此文件替代真实 EasyEDA 元件库和 PCB Land Pattern/EP 映射，不得自动勾选 `AddIntoBom` 或 `ConvertToPCB`。

## 明确需要的工程复核

1. **C7–C10 REG**：采用 Murata GRM188C71E225KE11D，2.2uF/25V/X7S/0603 的候选，需检查UCC24624 REG 工作直流偏置条件下的有效容量、温度容差和实际门极脉冲供电，并核对 X7S 是否满足电路所要求的温度特性。不能仅以2.2uF标称满足。
2. **C101/C103/C105/C107/C109/C111 VDD**：TDK C1608X7R1E105K080AB 1uF/25V/X7R/0603 供初选；需验证实际 12V 轨和异常瞬态、偏压后有效容量。
3. **R20–R27、R4/R5 栅电阻**：Vishay CRCW06032R20FKEA 2.2Ω/1%/0.125W 只是标准阻值型号；**高频开关波形脉冲功率、最高峰值电流及温升没有取得额定证据**。可对照 Vishay CRCW-HP 脉冲增强系列后再定型：https://www.vishay.com/doc?20043= 。
4. **R28–R35 SR漏极Kelvin**：Vishay CRCW06030000Z0EA 0Ω/0603 只是信号支路参考。严禁通过其通 100A 主功率电流，检查从 SR drain 焊盘到 UCC24624 VD1/VD2 的独立 Kelvin 取样。
5. **R8**：优先将实际元件从原生主板 BOM/PCB 中明确 DNP；仅改名义值并不能修正安全默认关断。前次原始工程读取仍显示 R8 装配标志开启。
6. 另外检查 C5 bootstrap 220nF 的电压和充放电能力，C11/C12/C13/R3 过流/滤波/软启时序和 R1/R2 定时设计。全部核查于真实设计电压、温度、公差、功耗后才允许物料锁定。
