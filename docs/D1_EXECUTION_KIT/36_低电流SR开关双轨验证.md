# 36 · D1 不再串行等待：5A/10A 同一功率级 SR 开/关两条验证线

**状态：MODEL_ONLY；不放行任何 48V、10A 或 100A 实物上电。** 本包的唯一目的，是将“先证明磁件/谐振功率级基本正确”和“证明全部 SR 保护、偏置与 100A 可靠”拆开执行，而非为了等待偏置 eFuse、R57、五磁件或 100 A 铜路把全部工作卡住。

## 方案改变

原 D1 48V→约2V 24:1 设计、原边控制、CT、4组3:1:1变压器、Cr/Lr 和校准的 BSC010N04LS6 SR_DEVICE **全部保留**。以现有真实冷启动源 `sim/v3/sr_tank_dual_v33_cold_phys.cir` 自动生成 4 个对照网表：

| 模型 | 负载电阻 | 输出电流只是按 2V 估计 | 诊断用途 |
|---|---:|---:|---|
| `sim/v3/poc_5a_sr_off.cir` | 0.4Ω | 5A | 用理想外部零伏栅极钳位禁用所有 SR 控制，仍保留 MOSFET **体二极管**，检测基础功率级与整流路径 |
| `sim/v3/poc_5a_sr_on.cir` | 0.4Ω | 5A | 同一功率级启用原校准 UCC24624 行为控制，测控制增益、反向电流与门极异常 |
| `sim/v3/poc_10a_sr_off.cir` | 0.2Ω | 10A | 观察较大整流压降、Lr峰值和二极管模式风险 |
| `sim/v3/poc_10a_sr_on.cir` | 0.2Ω | 10A | 对照有源 SR 的增益与电流行为，选择下一步测试工况 |

**5A/10A 是假定 Vout=2V 的目标而非电路已输出的电流**。固定比例 LLC 在轻载、无负载、体二极管模式下可能和 2V 预估相差很大。不能把此四份网表当做已跑过 LTspice、也不能用理想栅极钳位作为物理硬件保护证明。

## 已投入仓库的可执行程序

1. `python tools/poc_low_current_decks.py --check`：与实际 D1 源文件逐字比较四份网表，源头变更即停；`--write` 用于有意调整冷启动模型后重新生成。
2. `python -m pytest -q tools/test_poc_low_current_decks.py tools/test_run_poc_low_current.py`：保持四组源电路、原边/CT/磁件不变，SR_OFF没有Xsr控制且8路栅有理想钳位、模型及测试在无LTspice时绝不标为已求解。
3. 在**安装原厂 LTspice 的 Windows PC**执行：`python tools/run_poc_low_current.py --case 5a --mode both --run`；然后 `--case 10a`。自动按 [ADI 原厂 `-b` 命令行](https://analogdevicesinc.github.io/ltspice-reference/ai_ref/LTSPICE-QUICKSTART.html)调用，验证每份是**本次新生成的日志**，提取 VOUT/IRMS 代理/原边峰值与门极状态，产生模型结果 JSON，记录网表和日志SHA-256。
4. GitHub Action `d1-low-current-sr-ab-preflight.yml`只运行离线源级测试；它**没有 LTspice 许可证，不产生波形，也不作为功率上电批准**。

## 模型通过后的最短实物路线（新增的阶段独立门禁）

| 里程碑 | 可以立即做 | 只有哪些实测之后才可继续 |
|---|---|---|
| M0：48V全功率级空载与5A模型对照 | 跑上述四份LTspice，比较 SR_ON/OFF Vout、原边峰值、支路二极管电流、门极；识别磁件DOT、CT方向和谐振腔问题 | 只有真实模拟结果，不能据此进行硬件上电 |
| M1：受限功率无SR实物证明 | 磁件端子/DOT实物核对，使用**受限能量、可记录实际限流**的台架电源、可信的 SR 源栅关断接法，逐级测试 48V/低电流；SR控制器无需在此阶段启用 | 必须证明所有 SR MOSFET 的真实VGS始终保持关闭、二极管应力/温度有裕量、输出电压无异常过冲、保护独立有效；此项没有自动获批 |
| M2：低电流启用SR | 回到真实UCC24624 VDD/REG和Q41/R44门极关断，先低功率H1/H5波形，再在受限条件测试SR_ON；比较损耗和换流波形 | 真正H1/H5原始数据、VGS、REG、反灌状态、低能量过流与断线 |
| M3：D1连续100A | 并行推进100A铜路、端子DOT、磁件实测、热、保护、最终BOM和完整PCB ERC/DRC | 上述硬件全部有证据后逐级加电，不由M0/M1自动放行 |

## 一项重要但受限的需求变更

**不再把“故障后1ms内将11.1µF VDD_SR放至3.63V”作为M0/M1进入核心功率级仿真的必备前置条件。** 对无SR验证最重要的是**SR VGS可靠为关断状态**，不能用VDD电压代替门极关断证明。原厂 UCC24624 真正开闭判据是 **REG UVLO**，不是VDD_SR的某个任意下降时间；Reg关断阈值3.63/4.0/4.25V（min/typ/max），需按真实VGS与REG验证。

但这**绝不意味着已放行**原SR偏置ECO：原常通电Q54+47Ω/0.25W在18V强制反灌下约6.3W的已知风险仍是P0，主动SR运行或100A原板投入必须解决eFuse、电容放电和Q41/R44热/反灌问题。不得借本阶段临时电流指标移除真正关断保护。

## 快速筛选判据（只用于确定下一步，不是厂家标准）

- 若任一 LTspice 模型VOUT_MAX超过2.5V，或模型原边峰值超过已知104.17A旧故障峰，则先处理拓扑/启动/控制，不能直接进入硬件；2.5V是工程提前警报而非输出器件绝对额定。
- 若SR_OFF波形有MOS沟道明显导通/不正常反向电流，需要重新审查内部寄生与栅极钳位模型，不能默认“0V=理想二极管”。
- 若SR_ON在5A下表现出门极交越或明显反向电流，应先调整SR参数/采样，再决定10A硬件方案；不能因名义效率提高就跳过关断门禁。
- 在受限功率实物前，真实T1–T4/CT 的DOT、绕组绝缘和正确引脚、低能量供电限制、示波器安全接地和输出电容过冲都必须单独检查；**没有当前实物证据，本文件不授权通电**。
