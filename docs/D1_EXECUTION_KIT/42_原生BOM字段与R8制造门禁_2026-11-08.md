# D1 2026-11-08 原生 EasyEDA BOM 字段与 R8 制造门禁

数据源不是设计文稿推测：仓库内已留存的 2026-11-06 EasyEDA 原生读取结果，hardware/dcx_main/gen/native_inventory_raw.json 含83个真实元件实例的 Value / Manufacturer ID / Supplier ID / LCSC 部件描述 / AddIntoBom / AddIntoPcb 字段。它代表旧版原始工程快照，不能冒充今天的原生工程状态。

这一门禁与 PR #60 的值检查不同：逐个核对实际 manufacturer_id、supplier_id，而不只是 design Value。对51个拥有确定目标的 Samsung 和 UNI-ROYAL 原生实例，39个物理订购型号与目标不相符，其中37个实例的显示值已经被改成设计目标，另有C5和R3仍连显示值也未修改。对R20栅极电阻：显示2.2Ω，manufacturer_id=0603WAF1002T5E，supplier_id=C25804，实际器件为10kΩ；对C10 REG去耦：显示2.2uF，manufacturer_id=CL10B104KB8NNNC，supplier_id=C1591，实际为100nF。必须更换物理器件而不是再编辑 Value 文本。

R8在该原始快照中两项Add Into BOM/PCB仍为true；仓库已有的R8 ECO只对copy另存并复核，原始工程SHA未变，不能据此称主板已默认断开。此情况须先在真实原生CAD中修改并重新打开导出验证；实际防护许可还需独立硬件测得。

输出可执行工具：python tools/native_inventory_bom_gate.py --check；若要求采购/制造门禁请运行 --release-check（该旧工程必定fail）。详见 hardware/dcx_main/native_inventory_bom_gate.json 逐项清单。任何脚本成功只代表读取该快照没有漂移，不代表系统制造或安全放行。

后续动作：用全新原生 EasyEDA 导出覆盖/对照库存数据，核对每个 Manufacturer/Supplier/Value/Footprint，选择经过供应商资料核实且满足电气要求的器件；先修正默认关断再做 GUI/ERC、带网PCB、热验证、磁件PAD/DOT及SR反灌保护。制造状态继续NOT_FOR_FAB。
