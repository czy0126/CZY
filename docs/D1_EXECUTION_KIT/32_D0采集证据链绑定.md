# 第32章 · D0 采集证据链绑定（第29/31章的衔接工具）

> **状态：可执行的软件绑定工具，尚无真实台架数据。** 本章交付 `tools/d0_evidence_chain.py` 与负向回归测试。它只回答一个问题：**交给审核人的对齐报告、12 列 CSV、限值配置和门极审计报告，是不是同一次采集的同一批字节？** 它不认证波形来源、不证明物理同时性、不代替第29章的门极验收，也不放开制造闸门。

## 一、为什么需要它

[第29章](29_D0十路门极同步波形证据验收.md) 的审计器只读 `--csv` 与 `--config`；[第31章](31_D0多仪器同步对齐与重采样.md) 的对齐器只写 CSV 和它自己的报告。两者之间没有工具检查：

- 审计器读的 CSV 是不是对齐器写出的那一份；
- 审计报告里的 `limits` 是不是当前这份配置；
- 对齐网格的 `dt_s` 能否满足审计器的采样分辨率上限；
- 对齐后原点样点会不会正好落在 `trip_low_max_v` 与 `trip_high_min_v` 之间，被审计器判为 `ambiguous TRIP_STIMULUS logic level`；
- 审计报告本身能否由这份 CSV 与配置**重新算出来**。

任一项不成立时，把四份文件放在一起送审，看起来就是一条完整证据链，实际可能来自不同次实验或经过事后编辑。本章把这层检查显式化并 fail-closed。

## 二、输入

| 参数 | 来源 | 作用 |
|---|---|---|
| `--manifest` | 第31章同步配置 | 取 `TRIP_STIMULUS` 生产者的触发阈值；校验其 SHA-256 与对齐报告一致 |
| `--alignment` | 第31章输出报告 | 取网格 `dt_s`/`pre_s`/`post_s`、CSV 与 manifest 的 SHA-256、对齐状态 |
| `--csv` | 第31章输出 | 第29章要审计的 12 列文件本身 |
| `--config` | 审核人填写的第29章限值 | 分辨率、前/后窗口、迟滞门槛 |
| `--audit` | 第29章输出报告 | 待绑定的审计结论 |

工具**不接受**报告里记录的路径作为证据来源，只按命令行传入的实际文件计算 SHA-256；报告中的路径仅用于显示。

## 三、检查项与状态

结构不变量（任一项失败即 `CHAIN_INCONSISTENT`，退出码 2）：

1. `csv_hash_matches_alignment_report` / `csv_hash_matches_capture_audit`：CSV 字节必须同时等于对齐报告 `output.csv_sha256` 与审计报告 `source.csv_sha256`；
2. `manifest_hash_matches_alignment_report`、`config_hash_matches_capture_audit`：manifest 与配置同理；
3. `case_ids_agree`：四份工件（manifest、对齐报告、配置、审计报告）的 `case_id` 必须相同且非空；
4. `aligned_columns_are_the_twelve_column_contract` 与 `aligned_csv_satisfies_the_twelve_column_contract`：列名与顺序必须是 `time_s`, `TRIP_STIMULUS`, `P_HO`, `P_LO`, `SR1A`…`SR4B`；
5. `aligned_row_count_matches_report`、`aligned_grid_is_uniform_at_declared_dt`、`aligned_csv_span_matches_declared_grid`：CSV 的真实行数、等间隔与首末时刻必须与对齐报告一致（对齐报告自身没有哈希绑定，所以这三项是防事后改报告的唯一手段）；
6. `observed_sample_spacing_matches_aligned_dt`：审计报告记录的实测最大间隔必须等于从 CSV 复算的值；
7. `alignment_status_is_known`、`alignment_structural_checks_all_pass`、`capture_audit_status_is_known`；
8. `audit_report_is_reproducible_from_the_csv_and_config`：用同一 CSV 与配置重新运行第29章审计，`status`/`violations`/`limits`/`trip_time_s`/最大间隔/重叠事件/十路 `pass_waveform` 必须逐项相同；
9. `audit_limits_equal_config_limits`：审计报告记录的限值必须等于从配置解析出的值；
10. `grid_dt_meets_capture_auditor_limit`、`grid_pre_covers_min_pretrip`、`grid_post_covers_disable_plus_hold`：网格分辨率与前/后窗口必须满足审核人的限值；
11. `aligned_grid_includes_the_trip_origin`：必须存在距 `t=0` 不超过 `dt_s/2` 的样点；
12. `trip_trigger_threshold_outside_ambiguous_band`、`origin_trip_sample_is_unambiguous`：触发阈值与原点 `TRIP_STIMULUS` 样点都不得严格落在 `(trip_low_max_v, trip_high_min_v)` 内；
13. `permanent_release_flags_remain_false`：对齐报告的五面旗、审计报告的四面旗（它不建模物理同时性）都必须是 `false`，`requires_independent_hardware_review` 必须是 `true`。

状态与退出码：

| 状态 | 退出码 | 含义 |
|---|---|---|
| `CHAIN_CONSISTENT_CAPTURE_ONLY` | 0 | 工件互绑、网格可分辨、审计可复现且为 `PASS_CAPTURE_ONLY`；**仍不是硬件证据** |
| `CHAIN_CONSISTENT_PROVENANCE_INCOMPLETE` | 1 | 链一致，但对齐依据未审核或仪器元数据不全 |
| `CHAIN_CONSISTENT_AUDIT_REJECTED` | 1 | 链一致，但第29章审计本身拒绝了该波形（这是物理发现，不是工具故障） |
| `CHAIN_INCONSISTENT` | 2 | 哈希/身份/网格/复现任一项不成立；工件不是同一次采集，或报告被事后编辑 |

无论退出码为何，报告都写盘（`--report`），并恒写五面 false 旗与 `requires_independent_hardware_review: true`。

## 四、使用方法

```powershell
python tools/d0_scope_sync_align.py --manifest out/d0_scope/sync.json `
    --csv out/d0_scope/aligned.csv --report out/d0_scope/aligned.json

python tools/d0_gate_capture_audit.py --csv out/d0_scope/aligned.csv `
    --config out/d0_scope/limits.json --output out/d0_scope/audit.json

python tools/d0_evidence_chain.py --manifest out/d0_scope/sync.json `
    --alignment out/d0_scope/aligned.json --csv out/d0_scope/aligned.csv `
    --config out/d0_scope/limits.json --audit out/d0_scope/audit.json `
    --report out/d0_scope/chain.json
```

## 五、必须由工程审核人决定的事

- **`case_id`**：四份工件必须写成同一个事件标识；工具只检查相等，不判断标识是否对应真实事件。
- **限值与网格**：`max_sample_spacing_s`、`min_pretrip_s`、`min_post_trip_hold_s` 仍按第29章的实物依据决定；工具只检查对齐网格是否满足它们。
- **触发阈值**：建议等于 `trip_high_min_v`。若不同，工具在阈值或原点样点落入迟滞带时直接失败；仅“不同但不落入带内”时给出警告。
- **审计报告**：`CHAIN_CONSISTENT_AUDIT_REJECTED` 表示证据链完整但结论不通过，**不得**改配置去让它变绿。

## 六、能力边界

测试波形全部是合成的；任何测试通过都不能引用为台架证据。工具不读示波器原生文件、不校验探头衰减/带宽/共地/隔离、不证明两台仪器物理同时采样，也不检查 D0 电路是否真的存在。真实路径仍是：D0 十路低能量保护实物 → 真实采集 → 第31章对齐 → 第29章逐通道 VGS 验收 → 本章绑定。当前制造闸门仍是 `NOT_FOR_FAB`。
