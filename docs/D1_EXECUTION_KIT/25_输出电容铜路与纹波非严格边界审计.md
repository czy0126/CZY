# 第25章：输出电容铜路径与纹波不能误称严格上下界

2026-11-04工程审核确认，旧SOURCE-04将一维15条**完全独立铜路**算出的银行ESR 0.2688mΩ称为“下界”，又把旧100A仿真中的42.76mVpp称为电容分布网络真实纹波的“下界”。实际PCB尚无带网铜箔/过孔/共用回流几何，这两项严密性都不成立。长条独立走线、铜厚2oz、100℃、每接头50µΩ只是**一组情景参数**。分流/支路电阻和电容实际Z(ω,T)受共享回路影响，不能保证单调增加，更不能把各自的shared输出路径重复求和。

本轮保留0.2688mΩ情景计算及其约34.4%理想ESR增量，取消“实际电路下界”和“纹波必然变大”的推断，并新增测试要求模型主动说明‘not a bound’和‘no monotonic ripple bound’。实际A720原厂3mΩ测试条件为100kHz/25℃，而本脚本默认以100℃计算铜阻；**同一数值是跨测试条件的概算**，不是实测100℃完整电容网络。

要真正验收，取得实际带网PCB，对正/负回流及过孔网格做2D/3D电阻提取；以器件datasheet在实际频率/温度/寿命的复阻抗+实测ESL构建分布网络，再把电源和负载一起运行带浪涌的时域仿真。第24章已修正电容最高高度到原厂2.1mm，冷板机械和整机仍`NOT_FOR_FAB`。
