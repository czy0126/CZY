# D1 主功率板 PCB 交付主线（执行冻结 V1，2026-11-09）

> **唯一当前交付目标：可编辑、网络完整、真实器件封装且完成原生 ERC/PCB DRC 和板厂 DFM 的 D1 主功率板版图/制造审核包。** 设计对象是 48 V / 固定 24:1 / 约 2 V / **100 A 目标** / 完整装配 **≤16 mm 目标**；成本不设上限。D2 120 A、D3 ≤10 mm 是后续阶段，不得作为 D1 首板绘制的前置条件。**禁止把这份执行冻结理解为通电、100 A 连续或投板批准。**

## 2026-11-09 磁件路线调整：先自研 Maxwell，厂家回件不阻塞 G1

**根据最新研发决定：成本暂不限制，磁件第一阶段先按自研几何 + Maxwell 验证推进，而不是等订制磁件厂家回件。** 此调整只重排 B 线顺序，不取消 A 主板 PCB 的最高优先级，不创造第四条在制工作流。

**已完成的实际独立准备工作**：[概念几何参数源](../../design/v3/maxwell/diy_magnetics_concept.json) → `python tools/maxwell_diy_geometry.py --write` 可生成四组 ELP38_Lr 2/3 匝×0.92/1.00µH STEP、1 套 ELP32 3:1:1 变压器*几何占位*和 1 套 CT 100:1*尺寸占位*；`tools/maxwell_diy_pcb_envelope.py --write` 用既有原生网表生成 **24+2 个由设计团队自行定义的 G1 临时 PAD/网络/DOT 几何草案**。这些自动文件不对应已验证的真实端子，不能当厂家物理签核，也没有更新实际 EasyEDA 工程。

**Maxwell 确认必须是真正求解，不是 STEP 导出**：先运行 `python tools/maxwell_diy_run.py --prepare --case ELP38_Lr_3turn_0920uH`，在持有 Ansys Maxwell 授权的机器上用 `--solve --accept-synthetic-bh` 进行初始**概念**静磁场求解；记录实际磁链/原始矩阵和迭代网格、(B_{max})、实际 `L(I)`，包含0.5/13.881/22.53/84.02/104.17/121.515 A。现有 100°C B–H 序列是**人工插值**而不是 TDK 原厂完整曲线，配合简化绕组只可决定是否继续选该芯型/气隙，**不可给出已认证的增量电感、局部饱和与AC铜/铁损**。后续导入真正核实的100°C非线性B–H及几何，单独做涡流/200.62kHz损耗。现有 `maxwell_lr_from_step.py` 的严格原厂签核路径保持不变。

**为什么优先跑3匝 Lr**：目标外置0.92µH，2匝在121.515 A概念筛查约0.291T，超过0.248T筛选线；3匝约0.194T但解析气隙2.356mm超出厂家例示计算区间。Maxwell的第一任务是看局部饱和/气隙边缘漏磁及不同绕组可容纳性，不能用解析气隙当已定版加工尺寸。T1–T4 的3:1:1独立多绕组电磁模型与CT的真实100:1绕组尚未完成，**提供了几何 STEP ≠ 六件磁件均已经过 Maxwell 仿真**。

**PCB 进度规则**：G1 允许采用这26个**设计所有、清晰标成临时的**PAD及6个磁件包络开始原生板布局；**不要求先获得厂商定制磁件图纸或报价**。等本团队明确线圈真实连接、出线结构、可制造性、绝缘、Maxwell非线性与AC损耗，再锁定设计自有正式PAD/绕组图并走G2/G3安全制造审核。真实D0关断/保护及高流铜排约束不会因为“可以模拟”而免除。

## 1. 本轮计划为什么冻结

截至这份冻结，`hardware/dcx_main/dcx_main_board.eprj2` 已有 **83 个原生器件实例**，网表的逻辑连接大部分经过检查，但主板**没有已确认可制造的原生带网 PCB/Gerber**。`hardware/dcx_mech/power_stage_routed.kicad_pcb` 虽有 **61 条网络布通、214/214 连接、0 未连接报告**，它是**带占位封装的连通性概念板**；0.8 mm VOUT/PGND 参考铜线及满板铺铜筛选在 2 oz 铜时仍约 **1.8204 mΩ**，不能满足双极完整路径 150 µΩ 内部目标。重跑自动布线或者再做一份零 DRC 报告不会替代真正百安培铜路。

已知硬阻塞（不能用文字关闭）：**5 只磁件 T1–T4、CT 的 24 个真实 PAD/DOT**（Lr 另有 2 个实体端子）、**61 个占位登记**、**39 项原生 Manufacturer ID 与设计目标冲突**、**R8 在原生 BOM 与 PCB 仍为待装**、原生 GUI ERC、真实完整带网 PCB/DRC、Gerber/装配 BOM/板厂 DFM、独立故障关断原理设计与台架证据。

## 5. 任务筛选规则：默认不做琐碎、重复、非阻塞工作

每个新 Issue / PR 在动工前回答下列四句话，否则**默认排入 P2，停止主动推进**：

1. **解除哪个 G1/G2/G3 阻塞？** 必须填写上面 A/B/C 的工作流、Issue 与“源路径 → 真实目标产物”。禁止仅写“提高质量”“继续优化”“再做综合审核”。
2. **这次工作之后哪一个可查看的工程证据会不同？** 有原生CAD源/物理图/测试RAW/真实厂家回件；单纯多一个 Markdown 评审或者多一次绿色 CI **不算版图进度**。
3. **是否一定需要现在做？** 新仿真/新模型/数值容差只有在改变待冻结元件、严重 SOA/安全、可制造铜路或真实测试准备时才升 P0；其余维护原已有模型，不发起新扫参。
4. **什么情况下立刻停止？** 连续一次复现仍不能转化成实际 CAD/厂家/台架交付，转为 Issue 记录 P2 等待条件；不反复尝试同一路径。安全隐患立即停止危险实验，不受“一次”限制。

**当前明确不在主线**：[#6 的 100 A 能量账本微小差额](https://github.com/czy0126/CZY/issues/6)、10 A SR_ON 默认求解器反复调参、扩大到 120 A 的新性能扫描、D3 ≤10 mm 紧缩结构、扩展新报告格式、在已有真实 EDA 工具前提未解除时重复刷新同一份自动布线概念板。保留现有科学和失败证据，不删除、不宣称已解决；安全否决项一旦与现实器件直接相关，可按 1–4 条恢复 P0。

**不搞“任意改版”**：如果确认 24:1/当前 Cout ESR/真实结构有妨碍 G1-G3 的物理不可行点，允许设计负责人提出有数据的 ECO（替代原生CAD/结构与预算），但不可重新做一轮没有制造目的的拓扑大全。**成本不作为拦截理由**，物理工艺/安全/证据边界不放松。

## 6. 提交纪律与每次汇报格式

- **先成果后汇报**：每个活动期优先提交 A 的可编辑 PCB 变更；B 的厂商实回件；或 C 的原始实际 VGS/保护数据，再写必要评审。除安全漏洞外，尽量不要只提交新的审核长文。
- **一个主 Issue + 三个现有子 Issue**：[#4](https://github.com/czy0126/CZY/issues/4) 展示本周期唯一重点、阶段与 blockers；#9/#12/#36 展示各自实际交付。#1 极性由 B 线关联处理。一个新任务能落到这四个 Issue 时，优先回复现有 Issue 而不是开新“计划总表”。
- **每次仓库复盘限定五项**：本次合入的**真实 CAD/供应商/台架产物**；G1/G2/G3 进退状态；当前 1–3 个活跃工作包；明确实体依赖与责任角色；下一步最小交付。这是反馈事实，不是产生新报告的授权。
- **审批边界**：`NOT_FOR_FAB` 只有真实厂家、EDA GUI 原始产物、PCB/DFM、保护与审核证据解除时才能改变；无授权不得制造或上电。不要以“PR merged / 0 DRC / 5A RAW 完整”替代以上放行。
