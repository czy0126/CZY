# 45 · D1 从仓库到可测首件：现场执行手册（2026-11-09）

> **唯一交付目标**：48 V 标称输入、24:1 固定比例、约 2 V/100 A 级 LLC-DCX 首件，完整装配高度目标 ≤16 mm。D2=120 A，D3=≤10 mm；二者不是 D1 首件制造或 D0 低能量试验的前置条件。**本文件是执行程序而非制造或带电许可；D1 保持 NOT_FOR_FAB。**
>
> 适用基线：`feat/d1-fab-package@be5d715d`；最新实际电气/机械设计优先以仓库原生文件、供应商正式图纸、实测为准。下文“推荐时段”是协调目标，不是任何供应商、仿真计算或硬件达标的时间承诺。

## 0. 执行规则：每项必须有可以验证的退出物

1. 不再把“新增脚本 / 新增报告 / CI 全绿 / 理论 BOM / 0 DRC”当作首件进度。任务必须提供原生工程、来源受控制造数据、厂家正式回件、实物或原始波形。结果分为 `DESIGN_DRAFT`、`EVIDENCE_REVIEW`、`VERIFIED`、`BLOCKED_PHYSICAL`；没有真实证据不可填 `VERIFIED`。
2. 只对**本任务**设置依赖。仿真批处理异常不停止磁件询样、D0 假门极低能量试验或 PCB 电流路径设计；缺磁件实体脚号也不停止提前做器件摆放和铜路草案，但绝对阻止物理焊盘冻结及制造签发。
3. **每个器件必须同时检查 Value、Manufacturer ID/MPN、Supplier ID、封装、焊盘号、实际网络、DNP/装配设置**。仅在显示值中把 100 nF 改成 2.2 µF 仍可能实际采购 100 nF；将 R8 显示为 DNP 但仍在 BOM/PCB 同样不可接受。
4. 功率级、D0 保护、SR 15 V 偏置使用**独立版本和相同一条基准接口契约**。改变 SR 架构或保护电源方案，要先更新原生接口与真实验证程序，不能将两个驱动输出并联。
5. 第一次高能量上电必须由有资质的实验室工程师审核电气安全、绝缘、限能、急停、测量方法和器件 SOA。仿真/本手册不构成授权。

## 2. C 线操作卡：把原生主板真的转成可制造设计

**输入**：`hardware/dcx_main/dcx_main_board.eprj2`，`hardware/dcx_main/gen/read_native_inventory.js`，`gen/eco_r8_bom_pcb_inhibit.js`，`placeholder_eco.csv`，`native_inventory_bom_gate.json`，`docs/D1_EXECUTION_KIT/43_39个厂家料号替代候选_2026-11-08.md`，`hardware/dcx_main/output_loop_candidates.json`。

**步骤 C-1：单一主项目副本与 R8。** 在 EasyEDA Pro 打开原生项目**副本**，确认项目名和版本，运行原生读取脚本导出 Manufacturer/Supplier/Value + BOM 加入/PCB 转移字段。仓库原始 Nov 6 快照为 83 件、61 个占位登记、39 处已识别 MPN 与目标值冲突；R8 仍入 BOM 且入 PCB，这些是**历史快照**而不是最新编辑器实时结果。先根据第34章/`eco_r8_bom_pcb_inhibit.js` 提供的**两阶段 VERIFY/APPLY + attestation**按原生编辑器要求操作；不得将干运行输出或注入临时封装的内存会话当作已保存工程。保存后**重新打开副本**，再次导出真实 BOM、PCB 转移表、引脚网络及 R8 记录。R8 实物禁装只解决常上拉，不等于 `RUN` 已存在经验证的安全许可链，任何失电/故障均需确保禁止导通。

**步骤 C-2：关键物料先于一般 RC。** 依功能顺序逐组替换：① QH/QL + 8×SR（准确器件引脚、Kelvin 源极、热焊盘）；② Cr、Cin、Cout（实际纹波/直流偏压/温度下容量、ESR、耐压、安装高度）；③ R3/过流链（脉冲功率与封装）；④ 输入输出连接、两个极性的100A大电流界面；⑤ T1–T4/Lr/CT 厂家实脚；⑥ 其他驱动/去耦 RC。`tools/vendor_native_cad_eco.py`、`tools/native_inventory_bom_gate.py` 是判定和计划工具，不能更换原生元件。原生器件替换后，逐件检查 Manufacturer、MPN、真实封装、焊盘映射，并保留变更前后网表 diff。

**步骤 C-3：先画有网电流拓扑，再锁机械尺寸。** 优先布置 QH/QL → Cr/Lr → 四组变压器 → SR → Cout → VOUT/J_OUT，以及完整 **PGND/J_OUT 返回路径**；各 SR 的驱动 VGS 需相对于各自 Kelvin source，功率回流不可占用小信号参考地。允许真实磁件封装未交付时先用**明确不能投板**的几何占位画主要路径。最后用正式脚号/焊盘替换，做逐引脚完整网表检查；不可把 `hardware/dcx_mech` 的布通草图当成主板正式 PCB。

**步骤 C-4：制造放行检查。** 真实主板：完整原生 ERC；PCB DRC + **zero unconnected**（不仅 zero violations）；焊盘到元件/原理图 pin map；装配 BOM、DNP、IPC 类板材/层叠/制程限制；Gerber + 钻孔 + position + 各层输出；厂商 DFM 与审核签名。`python tools/d1_fabrication_gate.py --require-release` 在证据不全时预期应返回失败，**不允许为了通过而编辑审签 JSON 的布尔值**。PR #65 进一步补充了厂家 MPN 和 R8 双字段否决，合入后也要同时检查生成的 `remaining_dependencies` 视图。

**失败改道**：原生 API 无法做物理器件替换→用 GUI 逐位删除重放，不要仅覆盖 Value；2 次 GUI 导出无法保持器件身份→导出完整设计并由 CAD 工程师迁移到可维护的 KiCad 项目（新项目必须独立核实原生网络与符号封装，不是自动“等效”）；未获得 T/Lr/CT 的厂家脚号→继续铜路/摆放但禁止焊盘定版和 Gerber 签发。

## 3. B 线操作卡：供应商今天就能处理的磁件询样

**器件数说明**：T1–T4 四只功率变压器、Lr 一只谐振电感、CT 一只电流互感器，共 **6 只磁件**；“24个端子”是 T1–T4 和 CT 的逻辑端子映射检查数，**不包含 Lr 自己的实体端子签核**。不能把逻辑 PIN、供应商 PAD、PCB 焊盘编号混为一谈。

**发单**：按 `hardware/dcx_main/rfq/T1.md` ... `T4.md`、`Lr.md`、`CT.md` 原始需求，向至少两家能制作平面/低高度磁件的厂家发包。主推 ELP38/I38，备选 ELP43/I43；要求回：
- 正式尺寸公差图（绕线包覆/装配、压块、最大高度、板边引出/焊盘）；完整实体端子号、绕组方向 DOT、中心抽头工艺、原边三匝连线；
- 目标 Lm、漏感、Lr 的有条件测量，磁芯牌号/材质 B-H 和损耗特性，DCR；频率、温度、偏置电流条件；
- 100°C 及最坏故障工况下的 L(I) / 饱和裕量，绝缘/耐压/测试方法，铜损和磁芯损耗、可制造气隙工艺、样品批号；
- 两种芯型的报价与可做/不可做及原因，优先交付 **1 只同型 3:1:1 T + 1 只 Lr + 1 只 CT**，低风险验证后再做四只 T 的全套。

**回件质检**：使用 `docs/D1_EXECUTION_KIT/templates/magnetic_vendor_response_24_TEMPLATE.csv` 与 `tools/magnetic_vendor_map_audit.py` 核对每一逻辑端与厂家真实 PAD、DOT、图纸版本及回件哈希。再用受限低压激励检验两半绕组相对于 CTAP 的瞬时相位、比值与开路电压；逐项量 Lm/漏感/DCR、带电流偏置 L(I)、高温和机械高度。不得仅凭 Maxwell 磁通仿真代替厂家制造公差和现场 DOT 极性测试。

**失败改道**：两家都无法保证 D1≤16mm→先评估 ELP43 或其他实测可行芯型，冷板形态作 D1 的 ECO；若仍不行，**另外设立临时较高的 D0 功能验证夹具**先确认电路与驱动，不伪称 D1 16mm 达标。3个工作日内没有可用正式图纸时，增加第三家供应商并推进 PCB 非锁定布局，不重复等待同一家口头承诺。

## 4. D 线操作卡：低能量实物驱动先做两路，不先做 176 器件完整板

**D01 原边**：使用匹配目标封装/EN 引脚的 TI UCC27282 系列 EVM 或最小夹具、隔离且限流的偏置，装真实数据手册证据支持的等效 Qg/Cg 与门极电阻。分别捕获 EN/FAULT、HO-HS、LO-VSS、VBS、12V/5V rail-good，测试 EN 有效/无效/悬空、上电、掉电、欠压、锁存故障、ACK 被卡住。浮动高侧必须用合适隔离/差分测量，**不可把普通接地示波器地夹接到高侧开关源极**。

**D02 SR 二选一**：候选 A 为 UCC24624 保留比例门极，审查外接 UCC27524A 是否破坏比例门极时序；候选 B 为确切含 TRIG/DIS 的 NCP4306 订货型号。分别测单路真实 SR VGS、门极残余、误导通、持续故障禁止及异常恢复。onsemi NCP4306 手册把触发→DRV 传播和进入低功耗 DIS 的延时列为**两种不同过程**（例如 TRIG-DIS 约 75–125µs 是进入 disable mode 的条件延时，不是快速栅极拉低的完成时间）；必须按真实型号/温度/触发消隐逐个验证。绝不同时并联两个 SR 驱动输出。

**D03 决策表**：A/B 的评价必须由波形量得的最大关断持续时间、误导通频次、源极参考电位变化、故障保持与恢复行为，以及门极峰值/负压/SOA 决定，**不按“控制逻辑更简单”直接投票**。任一候选出现故障期间重新导通、掉电默认高 VGS、门极持续残压越界，立即拒绝，转另一种架构。两种都失败则保留 SR_OFF **低能量模型/台架诊断**并重新选择控制架构；不因此继续推进100A实体运行。

**D04/D05**：D03 后才画 D0b 十路独立栅极关闭硬件，真实硬过流不得在冷启动期间全程被屏蔽，硬故障锁存要求 SET 优先、复位需新沿且故障已消失；10 路各自的 VGS/源极都必须有证据。`tools/d0_gate_capture_audit.py`、`tools/d0_scope_sync_align.py`、`tools/d0_evidence_chain.py` 只核查原始波形数据一致性，实物来源、仪器校准、探头延迟及被测条件仍需人工签核。

**关断判定公式**：以指定最坏故障条件、温度和器件 SOA 为依据确定最大容许关断窗：
`t_detect,max + t_logic,max + t_driver,max + t_gate_decay,max < t_SOA,allowable`。
左侧必须含触发盲区、RC、供电消失、各路 Gate 残压与实际负载；右侧必须能从器件与磁件故障能量/脉冲 SOA 论证。**不能用芯片典型10ns、理想门极钳位或单条空载波形充当此不等式的证明**。

## 5. A 线：LTspice 实跑复现与遇阻时转向

最新 PR #58/#61 的 Windows 工作流不是已经求出功率级失稳。2026-11-08 的可见日志显示，官方安装成功后，在 `1V DC / 1kΩ / 2us` 的最简单批处理 smoke test 阶段 25 秒无有效完成证据。优先排除 GUI 首次启动、用户会话、headless runner、可执行路径/权限和产物写目录问题；在最小电路没通过前**不要运行四组长模型，也不得修改 SR 物理模型来“治”一个运行器问题**。

操作顺序：① 已完成交互式首次初始化的 Windows 开发机上先执行 `tools/ltspice_batch_smoke.py`；确认进程终止、有效 .log/.raw 及实际测量；② 同一环境调用 `tools/run_poc_low_current.py --help`，按帮助执行 5A 的 SR_OFF 与 SR_ON，分别保存来源、波形、模型 SHA；③ 5A 的**实际** Vout/Rload 才是模型实际负载点，不以 2V/R 贴标签；④ 5A 全部通过才推广10A；⑤ 针对两种负载都比较启动时间、SR VGS、二极管电流及器件应力，决定是否进入 M0。

备用路线：GitHub hosted Windows headless 执行重复失败→改用带真实交互桌面的 Windows 台架或经审核的自托管运行器；只有最小电路通过后才恢复 `PR #58/#61` 的模型工作流。不得用增加 `timeout`、跳过 smoke 或伪造 .log/.raw 替代求解成功。数值异常与电路本体异常必须分别给出可复现证据。

## 6. E 线：15V SR 偏置、反灌与掉电关断

`PR #52` 的 TPS26630RGET + CSD19537Q3T + BSS138-7-F 为**独立偏置概念板**，不是主功率级可投板硬件。已有原生 KiCad 10 ERC 成功日志但物理 Q1/U1 焊盘和 EP、真实模型与持续反灌能力仍待验证；不能把其成功 ERC 作为已达到 D1 整机放行。先做外部分压 UVLO/OVP 的**15V最低和最高输入工况**、上电浪涌和 SR Qg/Iq 总负载预算；再做偏置断电、VDD_SR 反向灌电、REG 放电及其真实 MOS SOA。旧 `Q54+47Ω/0.25W` 持续 18V 反灌约数瓦损耗方案不得无条件复用。eFuse 的限流/反向阻断也**不是栅极强制放电器**：两种功能分开验收。

**暂停条件**：任何 DC backfeed 使控制器半供电、SR VGS 重新抬升、硬件无故障锁存、掉电不能维持默认关断，停止 SR_ON 实体集成；不阻塞 M0 模型、磁件 RFQ 和主板低风险摆放。

## 7. F 线：100A 双极回路、冷板与实测损耗

全环路应计算 `VOUT + 接点 + PCB/过孔 + 返回 PGND`，而不是只量单根正极铜排。`tools/output_loop_budget.py` 当前为**概念筛选**：例如每极宽30mm、厚1mm、长15mm，假设每个接点20µΩ、4个接点、PCB预留30µΩ，则两极总电阻约132.66µΩ、100A I²R≈1.327W；接点若50µΩ则环路约252.66µΩ，超出现阶段150µΩ设计预算。接点20/50µΩ**均非供应商保证值**。

实际下一步：① 决定 VOUT 与 PGND 双极最短独立回路与每组 SR→Cout 入口；② 输出接头尽可能减少接点与长窄收颈，比较镀层/扭矩/端子结构；③ 含过孔桶壁、分布电流/铜箔厚度/板材、并联回流、PCB 铜温度和实际接头 I²R/热阻；④ 有实物时在额定温度、装配扭矩下四端 Kelvin 测每个接点和全环路（不能仅用通断蜂鸣器）；⑤ 对照 IPC-2152 载流/温升方法并用板级热测试修正，而不是把某个铜宽表当作全板安全额定；⑥ ≤16mm 剖面包含 PCB、焊料/磁件凸起、固定件、绝缘、TIM、冷板、最大尺寸公差、局部热点。初步冷板可独立开发，不必等待 D3≤10mm。

**分级实物验证**在 M2、C05、F04 与磁件/保护 SOA 均已批准后进行。25/50/75/100A 每档记录稳定输出电压、输入功率（含外部偏置的独立计量）、效率、核心器件温度、接触点温升、各组电流均衡、波形峰值、波形电压源极参考和冷却条件。实际 100A 短脉冲不能自动成为 100A 连续额定；连续条件要达到指定的热稳态、降额与故障后果判定。

## 9. 交付与 GitHub 一次性复盘约定

每个工程 PR 附**五句话**：修改了哪份原生设计/电路；输入版本与来源；实际运行命令或实物操作；可复算原始证据及状态；本次仍不能放行的范围。电气设计 PR 与文档审查 PR 尽量拆开，避免试验失败连带影响正式 CAD。原始日志、EDA BOM/网表/DRC、图纸修订号的 hash 与 Git SHA 一并交付。按 `README.md` 的当前关键路径建立每次复盘，不重复生成新的一整套平行台账。

**最小自查命令**（从仓库根目录，须按目标分支决定哪些文件已经合入）：

```powershell
python tools/remaining_dependencies.py --check
python tools/native_inventory_bom_gate.py --check
python tools/d1_fabrication_gate.py --require-release
python tools/check_d1_parallel_execution.py
python tools/output_loop_budget.py --check
python -m pytest -q tools/test_remaining_dependencies.py tools/test_d1_fabrication_gate.py
```

这些检查在真实证据不全时可能有预期的非零退出；它们是**停工哨兵**，不是可通过调布尔值清除的测试。若 `--require-release` 现在意外返回成功，必须作为 P0 查明原因，而不是直接下单。
