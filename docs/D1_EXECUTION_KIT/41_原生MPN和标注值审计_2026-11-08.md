# P0 — 原生元件库型号与设计电阻电容值不一致（2026-11-08）

**制造风险警示，不是已改动原生电路。** 运行 python tools/native_mpn_value_conflicts.py --check，并阅读 hardware/dcx_main/native_mpn_value_conflicts.json 中每一个参考位号。

## 已确定的事实

项目原生库标识 CL10B104KB8NNNC 的原厂物料确为 Samsung 100nF / 50V / X7R / 0603；0603WAF1002T5E 为 Uniroyal 10kΩ / 0603。对现有 61 个占位参考中的 51 个有设计目标和上述两类已知库号的元件逐个交叉检查，有 39 个物理值与标注目标不相同；其中 37 个此前被归类为 ALREADY_CONFORMS。该旧分类只证实文本 Value 已改对，不是制造商 BOM 真正的器件值。

典型高风险：C7-C10 的设计目标是 2.2uF，而库号对应 100nF；R28-R35 的设计目标是 0Ω Kelvin 连接，库号却对应 10kΩ。R20-R27 的 2.2Ω 栅电阻亦对应库号 10kΩ。若原生 EDA 的 BOM 导出直接取库号，未来采购会出错。该风险必须用实际 EasyEDA 工程导出的 BOM 核实；不能根据此脚本认定实体板已经装错。
