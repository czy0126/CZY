# 2026-11-03 D1 候选器件技术复核与具体修补

## 本轮确实更正的项目（可追溯代码与数值）

**P0：R3旧选型在120A工况不满足持续功率额定。** `design/v3/bom/oc_burden_pulse.json` 源自受控仿真 `mean(V(ocd)-V(ocm))²/R` 的正确实现；48V/120A故障前 **125.701 mW** 已超过旧0805/125mW名义值。故障脉冲峰 **10.08 W**，最大已记录故障窗口能量 **0.1310 mJ**；脉冲宽度等效值约13µs。旧方案在 [Panasonic官方页](https://industrial.panasonic.com/ww/products/pt/general-purpose-chip-resistors/models/ERJ6ENF10R0V) 明确0.125W，**现标记 REJECTED，不再映射到R3**。

**新建未验证候选：** [CRCW251210R0FKEHHP 精确订货号（DigiKey授权渠道）](https://www.digikey.com/en/products/detail/vishay-dale/CRCW251210R0FKEHHP/5079191) 和 [Vishay CRCW-HP e3 原厂Rev.17-Mar-2026](https://www.vishay.com/docs/20043/crcwhpe3.pdf)。10Ω±1%、2512、1.5W@70℃、最高0.70mm；与旧10Ω工作值相同，**只解决连续功率候选的明显不合格**。P70相对于当前最坏仿真持续值比值 **11.93倍**；按原厂p6简单线性环境温度曲线（有条件、未实测）：125℃≈0.529W、140℃≈0.265W、150℃≈0.088W。该曲线不是实际器件结温、温升的测量。

**脉冲判定仍 OPEN。** 原厂p5给出了2512的单次与重复脉冲曲线，p6给出了脉冲电压限制，当前约10W的瞬时峰值和0.13mJ的积分能量均须与**真实时序、温度、重复周期、波形**配对后判断。13µs等效宽度不能代替实际非方波的热应力卷积，也不能由<1次初样故障就推广到反复故障。原厂资料存在，不再写“脉冲图厂家无法获取”，但**不能自动写已通过**。

**CAD脚号/机械修订**：旧标注“0805”的PCB位号R3必须改为2512，建议贴近CT整流网络、避免增加高频寄生回路。维持CT变比100:1及负载电阻10Ω，不擅自重改OC时延/分压。原生`.eprj2`、完整网络及图形ERC/DRC、焊盘等未处理，后续实际修改前仍然禁止投板。

## 2026-11-03 新增P0回归修复：R1/R2 的 RT / DT 功能标注反了

**原生导出网表** `hardware/dcx_main/gen/netlist_export_raw.json` 明确显示 `R1 = DT→PGND`、`R2 = RT→PGND`、`U1.1 = DT`、`U1.2 = RT`。原 BOM/61件选型将R1标注976Ω RT、R2标注5.36kΩ DT；**只要按上一版候选把料号装进原生PCB就会把两个功能阻值装反**，而原来的子网一致性报告不会发现。

现已 **以原生接线为实物连接定义，统一更正物料对应**：`R1=DT=5.36kΩ→ERJ3EKF5361V`，`R2=RT=976Ω→ERJ3EKF9760V`；同步更新 `component_decision_register.json`、BOM draft、61行候选矩阵、RFQ种子、回归断言。UCC25600原有推荐时序阻值 **5.36kΩ DT、976Ω RT均保持不变**，这次只改工程位号对应，不冒险编辑原生原理图。新增 `tools/d1_functional_net_audit.py` 并把 `controller_rt_dt_roles_match_native_netlist` 纳入D1制造闸门，下一次即使网络数量全部匹配，只要功能/阻值映射错也会直接失败。

## 资料本身的复核

- Panasonic [976Ω](https://industrial.panasonic.com/ww/products/pt/general-purpose-chip-resistors/models/ERJ3EKF9760V) 与 [5.36kΩ](https://industrial.panasonic.com/ww/products/pt/general-purpose-chip-resistors/models/ERJ3EKF5361V)：原厂型号值、1%和0603相符。
- TDK [2.2µF/25V X7S 0603](https://product.tdk.com/en/search/capacitor/ceramic/mlcc/info?part_no=C1608X7S1E225K080AB) 与 [1µF/50V X7R 0603](https://product.tdk.com/en/search/capacitor/ceramic/mlcc/info?part_no=C1608X7R1H105K080AB) 的标称规格匹配。但X7S温度变化±22%，X7R ±15%，也都需要实际DC bias曲线。
- [TDK 220nF/50V/0805 bootstrap](https://product.tdk.com/en/search/capacitor/ceramic/mlcc/info?part_no=C2012X7R1H224K125AA) 厚度1.25±0.20mm；必要的HB-HS bootstrap容量要按VCC12偏置和低温/高温重算。
- [Panasonic 0Ω 0603](https://industrial.panasonic.com/ww/products/pt/general-purpose-chip-resistors/models/ERJ3GEY0R00V)：官网该型号未给出额定功率，它是jump-link而不是理想0Ω；八个SR感测电路需评估最大电阻/取样偏移和回路布局。
- Yageo [2.2Ω/0603](https://www.yageogroup.com/component-documentation/download/specsheet/RC0603FR-072R2L)：官方零件表支持2.2Ω、1%、0.1W@70℃，用于门极时应关注瞬态电流，不可把0.1W DC规格当门极脉冲额定。

## 新增自动防回退

`tools/verify_vendor_candidate_matrix.py` 的 `r3_minimum_rating` 会从 `oc_burden_pulse.json` **实时读取各基座仿真最坏故障前功率**，要求标称P70至少为其三倍，并拒绝0805及意外变更的状态；测试注入0.125W旧方案和0.1W不足方案应抛错。不绕过器件选型/制造闸门。定量结果另见 [r3_vendor_rating_screen.json](r3_vendor_rating_screen.json)（区分“连续功率初筛”和“脉冲、原生PCB、真实热条件未过”）。

## 尚不能由本轮自动完成

1. 导入带正确引脚焊盘的2512原生器件，替换R3旧封装，执行完整原生ERC、同步带网PCB并做DRC；缺少图形工具中的有效审核。
2. 用实际波形而不是等效宽度推算或实测R3启动/重复故障脉冲，验证厂商给定曲线；若上电硬件不能安全反复注入，首样先限能。
3. T1–T4、Lr、CT五磁件24脚真实厂家物理端子、DOT、实物L(I)，以及主桥+8SR独立故障关断，均未闭合。
4. 50V/120A对照仿真的同源/同求解器全窗验证、额定热、输出电容组实测100–200kHz ESR/电流、整机能量守恒误差，仍需独立执行。
