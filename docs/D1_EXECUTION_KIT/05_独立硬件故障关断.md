# 主桥与八只 SR 的独立故障关断：实现与验收

**当前事实**：基座 48V/120A 热故障模型，在保存窗末端 A 侧四只 SR 高门极；末段电流约 1.405A 的事实不能否定启动时约 285–303A 的模型应力。50V 基座故障在保存轴约 296.929µs 塌缩，只有加 1fF cshunt 子变体完成到 320µs；其相位和工作点可能随数值路径改变。行为级 PROT-B 使用理想 0.05Ω 钳位+理想锁存，不是一个可直接焊接的关断电路。

## 1. 真实控制器必须考虑什么

- **UCC25600**：OC 约 1V 逐周期/关断、2V 锁存，必须按不同触发条件和手册最小/最大阈值设计；关断原边**不会**自动证明 8 只次级 SR 都 fail-low。SS 引脚拉低与 UVLO/欠压复位也需审。
- **UCC24624**：根据 VDS 感测驱动两只 SR；其 REG UVLO 对 VG1/VG2 有不同强弱下拉（手册规定 REG>2V 与 <2V 条件），standby 和频率判断也不能保证外部所有故障时同步关断。错误地直接短接活跃 VG 输出到地可能造成芯片输出级打架。
- **UCC27282**：主桥半桥驱动有其自身 EN/HI/LI/UVLO/交叉导通保护，需按照真实料号及 PCB 供电/地弹/自举计算。不允许凭 SPICE 理想 Bgh/GH 波形宣布 Cboot 已验证。

原厂入口：[UCC24624](https://www.ti.com/lit/ds/symlink/ucc24624.pdf)；[UCC25600](https://www.ti.com.cn/lit/gpn/UCC25600)；[UCC27282](https://www.ti.com/product/UCC27282)。

## 2. 需要设计的保护链（拓扑候选，不是已验证原理图）

    CT/快速电流检测 + 原 UCC25600 OC
                      |
               比较器+消隐/滤波
                      |
           硬件锁存+失压默认安全
                /            \
      原边半桥禁止通道     四组双 SR 的独立关断/禁止
                \            /
                 供电复位和受控重启

**输入失效安全**：任一驱动偏置掉电、控制器未启动、独立保护电源先断、CT 断线、门极路径失联时均默认禁止开通。由器件手册核定如何实现硬件 OR/disable，不得把理想钳位直接并联在实际驱动器的推挽输出上。若某 SR 控制器没有可强制 shutdown 的功能，要设计合适的外部隔离/缓冲/下拉拓扑并验证 VG 与门极的应力、传输延迟和漏电；更换驱动方案也是选项。

**锁存条件**：启动期间屏蔽快速过流的时长要有明确依据；屏蔽期间短路仍必须有另一条安全约束，不能直接把独立保护整体关闭。故障解除、Vout 残压、驱动偏置恢复、主桥 SS、八路 SR 重新启用的顺序必须在同一功率级仿真和首件实测中确认。

## 3. 参数不能从模型数字直接选

当前 PROT-B 的 10µs 快滤波和 1.8V 门槛只是一个示例。实际门槛需要以 CT 极性/变比/负载电阻、整流压降、精度/噪声、OC 功率级、最严 50V/120A 故障曲线推回；采用**min/max 容差**、比较器迟滞、温度、漏电、传播延迟和 RC 误差。SOA 判断使用真实器件的 I_D(t)×V_DS(t)、实际故障脉宽和 Tj/Zth，**不能只用 304.96A×1.25 得到 380A 就叫安全**。

## 4. 故障场景矩阵与硬验收

| 场景 | 主要证据 | 结果必须呈现 |
|---|---|---|
| 48V/100A、120A 运行中短路 | 同一求解设置的 raw/log | 主桥 HO/LO、8×VG/VDS/Id、OC、锁存、I²t |
| 50V/100A、120A 同上 | 完整 320µs 记录，非求解器前缀 | cshunt 基准和独立配对控制，故障前均值偏差 |
| 上电/冷启动、启动屏蔽期间短路 | 不用稳态 .ic 代替冷启动 | SS、遮罩、安全锁存、峰流、应力 |
| 比较器/CT 开路或失去电源 | 非理想故障注入 | 默认关断，不出现高栅压 |
| UCC24624 REG/VDD 失压+主桥仍有能量 | 输入失压时序 | VG 真实下拉及负载输出行为 |
| 停机后恢复/重启 | 含输出电容残压的功率级 | 所有栅极低→供电正常→复位→受控启动，无误导通 |
| 单路 SR 驱动失效 | 单器件 Vgs/Vds/Id | 并联电流重新分配、相邻 MOS SOA 与热 |

模板 templates/protection_test_matrix.csv 可直接记录，不应把实验状态填写 PASS 直到有原始文件和审核人。

## 5. 释放保护设计的必要文件

- native main-board 同一 SHA256 版本的完整关断原理图与网表。
- 逐器件的供应商额定/脉冲 SOA 参考与实际计算，已与最坏波形配对。
- 比较器/锁存/门极驱动的实际电路、供电缺失和重启行为分析。
- 48/50V 原始波形、故障前工作点偏差、保护延迟与未收敛说明。
- 独立审查签名与所有开放问题。**仿真工程审查 ≠ 硬件安全认证**。
