# D1 可执行工程参考包（2026-11-03）

**对象**：CZY 48 V→约 2 V、24:1 LLC-DCX、100/120 A 高输出实验样机。**设计取舍**：物料、工艺与样品成本不设上限；目标总高≤10 mm；不得放松器件 SOA、绝缘、保护、制造可行性和证据可信度。

> 本目录是工作指南与可填写模板，不是新一轮同义审核。基准 main@79eee331fa5848ebad91e9712e180345d5f57814。现有 83 逻辑位号、61 个占位位号、五磁件物理脚号/DOT 待签、原生 GUI ERC 与有网络的主 PCB 缺失；制造闸门 NOT_FOR_FAB。仿真不是硬件连续额定。

## 最短启动路线

1. **先跑检查**（Windows，仓库根目录）：
       python -m pip install -r requirements.txt
       python tools/ci_check.py
       python tools/d1_fabrication_gate.py
       python tools/d1_fabrication_gate.py --require-release
   最后一行当前**应返回非零**，表示不可投板，不是软件 CI 失败。禁止手工把 JSON 的 release_approved 改成 true。
2. **按任务领取输出**：已经存在的 hardware/dcx_main/d1_delivery_tasks.csv 是正式任务卡；此包提供判据/外部资料/数据回填。优先 P0：主桥+八 SR 独立故障关断、真实五磁件端子图、61 个占位件、GUI ERC、有网 PCB。
3. **先拿厂家真数据**：不要拿论文参考 BOM 充作选定料号。将 templates/supplier_reply.csv 和 templates/magnetic_terminal_map.csv 发给供应商。任何未知项填写 PENDING，不允许靠逻辑网名补造真实焊盘。
4. **当天做出可审证据**：每项成果必须有原文件、同版本哈希、可复现步骤、审核人、通过/失败判据。把故障和电压/电流证据写入 templates/simulation_run_register.csv 复制件，原始 RAW 不进入 Git，需妥善存档并记录 SHA256。
5. **以实际门槛流转**：A0 规格→A1 有效原生原理图→A2 带网 PCB/DFM→A3 限能磁件和保护首样→A4 主样机→A5 额定及冷却；允许 RFQ/PCB 规划并行，绝不能绕过 P0 做整机上电。

## 一次交付应当包含

- 实物设计的 EDA 原文件和原生导出网表；每个未核实脚号均在审表显示 PENDING。
- BOM 的唯一 MPN、原厂 PDF 版本/日期、真实焊盘与 3D 高度、额定参数；未获实测或资料的值不能标 VERIFIED。
- 单次试验记录：原 deck SHA、RAW SHA/外部存放位置、log、分析脚本、窗口、求解器、峰值、失压/恢复、审核结论。
- 风险和更改：ECO 说明变比/电容 ESR/Lr 变化对其他工件的影响，不只改一份 CSV。
- **不把文献 40V→1V 或 500A 作为当前 48V→2V 的已达成指标。**

## 当前绝对不能写的结论

- “100/120 A 连续通过”；“投板就绪”；“完整 50 V 基座故障波形”；“已通过器件 SOA”。
- “0.2 W 能量账本闭合”；“10 mm 机械/冷板已签核”；“61 个占位有真实料号”。
- “理想 0.05Ω 门极钳位就是能够量产的关断方式”。

执行 `python tools/d1_reference_kit.py --check` 检查种子文件是否与当前原生设计记录同步；需要重新生成时使用 `--write`。 [61 位号物料需求](templates/supplier_seed_61.csv) 和 [五磁件 24 脚需求](templates/magnetic_terminal_seed_24.csv) 均自动从现有 JSON 生成，并保留 PENDING；它们是对供应商的请求，不是供应商已提供的证据。真实回件请另存，不要修改此自动生成种子表。
