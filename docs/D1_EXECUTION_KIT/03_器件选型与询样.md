# 不限制成本的器件选型、RFQ 和物料验收

## 1. 先从现有清单消除“不知道买什么”

权威起点是 design/v3/bom/bom_draft.csv、hardware/dcx_main/pin_footprint_review.csv、component_decision_register.json、performance_first_component_rfq.csv。旧文档可能仍有 39 占位和 61 占位两版统计；以**当前原生工程 83 位号、61 个 PLACEHOLDER**为准。供应商回复表 templates/supplier_reply.csv 应按**展开后的位号**填写，不写成无从逐脚核对的 R20-R27 一格。

每件分开核以下 12 项：manufacturer、MPN、官网 URL、资料修订和日期、可供货数量、建议 PCB footprint、实际 pin/pad、额定/温度降额、绝对极限、200kHz 有效 ESR/ESL 或 Qg/Coss、最大装配高度及公差、审核人与取证路径。**一个 MPN 对不上 datasheet 版本即为 PENDING**。

## 2. 功率优先的初选规格（均为询样目标，非额定签核）

| 部件 | 当前证据和最低问题 | 下一步 RFQ 要求 |
|---|---|---|
| Lr | 50V 热故障模型 Ipri≈101.26A；旧 3 匝 ELP32 磁通裕量小 | 100°C L(I)、实际漏感/峰值、Amin，首选三匝 Ae≥200mm² 的低矮定制件，候选四匝 Ae≥150mm²；高度≤10mm组合后成立才行 |
| T1–T4 | 3:1:1、中心抽头 DOT 与真端子待厂家核 | 四套完全一致绕组、交错结构/漏感和 DCR/ACR，首件低压测相位 |
| Cout | 现模型 4mF/0.2mΩ 以及另案 15×470µF；纹波在 50V/120A 过载点实测 56.06 A RMS（额定 100 A 点是四路重建的 52.48 A，低 6.8 %） | 筛额定≥4V，优选 6.3V（视外形与浪涌），有效容量≥7.05mF（工作偏压/温度/寿命）、并组 RMS≥84.09A（过载点×1.5）、含实际铜路总 ESR≤0.10mΩ（探索目标） |
| Cr | 谐振模型峰 Vc≈41.36V（额定点）；120 A 过载点 RMS 11.22 A、Vc 峰 44.44 V（额定点是 9.45 A，低 18.8 %） | ≥100V 电压额定，≥15A RMS 询价目标（已高于过载点 11.22 A），需 ESR/ESL 200kHz 工作数据与热升实测 |
| Cin | 旧 1mΩ 理想电源使模型输入电容纹波非常低；半桥交流输入电流按 120 A 过载点 6.36 A 筛选（额定点是 5.32 A，低 19.6 %） | 以半桥交流输入电流 6.36 A 为筛选基线，RFQ ≥8A RMS，真实供电阻抗与 PCB 重新仿真 |
| QH/QL/SR | SPICE 理想化应力不等于真实开关 | 供应商脉冲 SOA + Zth 曲线、Rg/Qg/Coss、Vds 脉冲与负压，认证封装、焊盘/热路 |
| D_BT/boot | 旧 D_BT 文案出现过 ≥25V 错误，实际导通时反压约 48V | 按源电压最大值+浪涌/振铃选足额反压且满足动态特性；Cboot 按 Qg、漏电、频率计算 |
| J_IN/J_OUT/铜条 | 100A 接点假设没有四线法支持 | 连续/脉冲接触电阻、夹紧力/温升、端子高度/镀层/寿命实测；输出回路不得用“每触点 50µΩ 假设”直接签核 |

Cout 的 ESR 并联 N 倍改善仅对理想等效元件成立。实际还需逐个支路 ESL、焊点、分流铜层、端子电阻。耐压 4V/6.3V 是待核筛选值，不是所有供应商都有可用封装。

## 3. 询样并行方式

- **P0 供应商包**：磁件真实脚号/DOT + L(I) 高温曲线、低矮五磁件尺寸、核心选型；器件 61 位号表与驱动失效安全证据。
- **P1 方案 A/B**：低矮宽截面磁芯、三种不同封装 Cout、铜嵌件/铜条接头、可打样 SR 替代料；相同 48V/120A 故障 + 热态对比。
- **P2 优化方向**：集成平面变压器与堆叠方案只做独立样件/文献复现，不能中途替换基线拓扑而继续沿用基线仿真签核。

到货收货记录至少包括照片、型号标识、批次、资料 URL 版本、计量设备编号、测量温度、原始测量数据与接受/拒收。不得在 CSV 未收到完整数据时预先填 VERIFIED。

## 4. 每次设计更改的回写路径

    BOM/厂商数据 → 原生符号/封装/网表 → PCB&Z轴 → SPICE 元件参数 → 保护/SOA/损耗分析 → DFM/首样记录

同名“470µF”在 2.5V、4V、6.3V，不同介质、偏置和体积下不能按名义容值相等处理。
