## 1. 本轮直接修复的两类假通过

**P0 十路 SR 候选驱动映射不完整**：`tools/d1_protection_precheck.py` 原来校验八路数量、控制器输出和门极电阻，但对 UCC27524ADR 的 `INA/INB`、`OUTA/OUTB`、`ENA/ENB`、供电及回流引脚没有严格的已知手册映射，也只校验输出网络以 `SRBUF` 开头；两个通道交换缓冲编号、复用输出网名或将 pin2 写成 pin4，部分情况仍能通过。现锁定每路的预期控制器、真实驱动器 U7–U10、SOIC-8 实际引脚及唯一输出网络；更换 MPN 必须重新审核引脚表，不能只改候选字符串。加入通道交换、输出别名、错误管脚与不受控 MPN 的反例测试。

当前方案八路映射（**仅候选接口，不是原生板已放置**）：

| SR | 源控制器/VG脚 | 缓冲器 / INA或INB | OUT脚 → 原门阻 | EN脚（默认低） |
|---|---|---|---|---|
| SR1A/B | U3.1 / U3.8 | U7.2 / U7.4 | U7.7→R20 / U7.5→R21 | U7.1 / U7.8 |
| SR2A/B | U4.1 / U4.8 | U8.2 / U8.4 | U8.7→R22 / U8.5→R23 | U8.1 / U8.8 |
| SR3A/B | U5.1 / U5.8 | U9.2 / U9.4 | U9.7→R24 / U9.5→R25 | U9.1 / U9.8 |
| SR4A/B | U6.1 / U6.8 | U10.2 / U10.4 | U10.7→R26 / U10.5→R27 | U10.1 / U10.8 |

其中每片 UCC27524ADR 的 **6=VDD、3=GND**；八路各自测量门极 VGS 而不是只测 `SR_SAFE_PERMIT`。此候选会把 UCC24624 的**比例模拟栅压**变成缓冲器逻辑输出，具有实质损耗和误导通风险，不能不经新测试直接替换。参见 [TI UCC24624](https://www.ti.com/product/UCC24624)、[UCC27524A 数据手册](https://www.ti.com/lit/ds/symlink/ucc27524a.pdf)。

**P0 阶段批准信息可被覆盖**：`tools/d1_staged_rebaseline.py` 以前仅拒绝全局 `hardware_approved/production_approved`，而不拒绝 D0/D1/D2/D3 某一 `fab_release=true`；生成屏幕始终写 `fabrication_approved=false` 可能掩盖输入审批状态已变。现拒绝任何阶段未明确设置 `fab_release=false`，附四阶段逐项篡改测试。此代码**不授予**任何制造或保护签核。

## 3. 以文献决定备选架构，不把论文数据冒充本设计

- [IEEE OJPEL 2024, DOI 10.1109/OJPEL.2024.3490601](https://doi.org/10.1109/OJPEL.2024.3490601)：40V→1V/200A、1MHz 的集成平面变压器+SR+Cout器件布局，展示缩短副边导电长度、低 AC 铜损与低高度设计方向。**不是本项目48→2V的效率实测。**
- [IEEE COMPEL 2023, DOI 10.1109/COMPEL52896.2023.10221067](https://doi.org/10.1109/COMPEL52896.2023.10221067)：48V→1V/300A的绕组串联与整流器并联，提供极薄结构的 **参考方案**；先核实其电压/电流/散热窗口，不直接按面积缩放到当前 24:1。
- [APEC 2024, DOI 10.1109/APEC48139.2024.10509493](https://doi.org/10.1109/APEC48139.2024.10509493)：24:1、500A 堆叠标准 PCB 变压器，输入串/输出并与电流均衡的架构备选；可作为 D2/D3 架构对照，**不能在没有绝缘/保护/控制重设计的情况下直接替换当前 LLC**。
- [IEEE ECCE-Asia 2025, DOI 10.1109/ECCE-Asia63110.2025.11112272](https://doi.org/10.1109/ECCE-Asia63110.2025.11112272)：24:1 与集成输出端子的平面变压器布局；适合当前100A低阻铜路设计，不代表24:1一律带载精确2.0V。
- 原厂约束优先于论文可迁移性：[TDK ELP38/I38](https://www.tdk-electronics.tdk.com/inf/80/db/fer/elp_38_8_25.pdf)、[TI UCC27282](https://www.ti.com/product/UCC27282)、[onsemi NCP4306](https://www.onsemi.com/download/data-sheet/pdf/ncp4306-d.pdf)。UCC27282的 EN 禁止延时不能按理想ns处理；NCP4306 TRIG/DIS 需验证关断消隐、TRIG默认态与真实源极回路。
