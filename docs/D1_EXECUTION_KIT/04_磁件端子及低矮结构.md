# 五磁件真实端子与 D1≤16 mm / D3≤10 mm 分阶段装配指南

## 0. 需要同时解决哪五只

原方案 T1、T2、T3、T4 四只变压器及 Lr 谐振电感均可能限制高度；另有 CT 电流变压器真实端子/体积问题。不能只把四个 T 的沉槽当作整机已满足高度。当前近 9.94mm 的旧平铺估算只剩约 0.06mm 且不包含完整 TIM/固定件，增加压紧板就可能超出10mm。**自2026-11-04分阶段目标生效起，D1首样允许目标≤16mm，严格≤10mm仅作为D3优化**；两阶段均必须由结构负责人书面确定PCB模块、TIM、冷板及紧固件边界。

## 1. 磁件工厂回件应含什么

- T1–T4 每件实际可焊盘号、端子坐标、原边三匝串接顺序、DOT 同名端、两个 1 匝副边与 CTAP；严格验证仿真“中心抽头连接两个反向参考极性端”这一关系。不得把“同名端相连=CTAP”继续当通用口令。
- CT 应列 PRI_A/PRI_B 与 SEC_A/SEC_B 共**四个独立逻辑端**对应的实际脚、极性；不能沿用只有 2 pad 的临时封装。
- Lr 实物是两端器件，但必须给体积、位置和高温/故障下 L(I)。任何 3→4 匝或 Ae 变化都要重算气隙、fr、DCR/ACR、分布电容和漏感。
- 供应商出具带修订号的 2D/3D/引脚/DOT 图、绝缘距离、胶/引出铜箔/固定脚公差、样品编号；工程师对照低压注入相位图签字。

仓库 [magnetic_terminal_map.csv](templates/magnetic_terminal_map.csv) 旧版曾仅含9行且把T1中心抽头误写为`OUT`；**现已修复为24行，CTAP网名`VOUT`**，所有真实物理端子仍保留PENDING。供应商正式回件请优先使用新增的 [16列回件模板](templates/magnetic_vendor_response_24_TEMPLATE.csv) 与 `python tools/magnetic_vendor_map_audit.py --input <回复文件.csv>` 验证；详见[第30章](30_磁件24端子回件自动审核.md)。逻辑网名来自原生黄金网表，不得凭外形相似图猜端子号。

## 2. 性能优先的新 Lr 初筛不是定版

由仓库 50V 故障模型峰 I≈101.26A、1µH 名义上限考虑 +10% L 公差、+20% I 裕量，并把目标限在 0.8×参考 Bsat，则

    Ae_required = (1.10µH × (1.2×101.26A)) / (N × (0.8×0.31T))
    N=3 → 约 180 mm²；RFQ 目标 ≥200 mm²
    N=4 → 约 135 mm²；RFQ 目标 ≥150 mm²

这是 L 常数假设下的初步筛选，不代表磁芯材料在 100°C 的 Bsat 真值或测得 L(I)。**必须拿厂商所用材料 100°C B-H/L(I) 及公差回填**，尤其 100A 以上故障下电感可能大幅减小。

## 3. 五磁件 Z 向高度单据

统一原点：例如“PCB 顶面铜箔表面 Z=0”；每只记录 top_of_core、bottom_of_core、开槽深、PCB 剩余介质、胶厚、绝缘片厚、固定夹具、焊点、散热材料/压板。必须输出 min/nom/max 三列，不可只报典型 9.44mm。

- D1样机按目标≤16mm、D3薄型优化按≤10mm分别计算最坏**总装配**公差链；如果冷板/TIM/装配公差未知就PENDING。标准ELP38/I38裸芯最大12.35mm，16mm减去它仅余3.65mm，**不是已证明整机适配**。
- 沉槽不允许切断 SR→Cout 铜的主要导通路径或 Kelvin 回路；FR4 剩余介质**不是**100A 载流回流导体。
- 对开槽/盲槽与重铜叠层请求 PCB 厂书面确认：是否可加工、剩余绝缘厚、外形公差、铜皮最小安全距离、树脂/铜界面与可靠性。
- 机械 Z 约束与热路互斥时，由方案 ECO 决定是调整 10mm 目标定义、换低矮磁芯、改板材、或导热结构，不能偷偷省略 TIM。

## 4. 磁件首件验收

1. 低电压、限流正弦测试逐一核 primary/secondary 相位，测 T1–T4 DOT、CT 极性。只在无 SR FET 连接的安全状态下先验证。
2. 分别测 Lm、Lr(I,T)、漏感（定义短路端与测量频率）、DCR@20°C、ACR/f、分布电容与绝缘；记录仪器和治具。
3. 检查真正外形、铜箔边缘、端子焊接、绝缘和俯视布板干涉。首件测量不通过不要直接把名义设计参数当“偏差可接受”。
4. 所有参数回写 BOM、SPICE、原生 CAD、PCB/机械剖面和器件应力报告，同步重新执行保护故障场景。
