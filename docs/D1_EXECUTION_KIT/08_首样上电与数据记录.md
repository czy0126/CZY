# 首样、限能上电和安全验收

**禁止把首样计划理解为现在可以上 48V/120A。** 初期优先控制板、磁件和功率驱动的隔离限能治具；在机电/保护/仪器能力未审核前不能执行高流短路试验。

## 1. 验收分阶段

| Gate | 目标与实验 | 原始交付与退出条件 |
|---|---|---|
| B0 到料+尺寸 | MPN 对照、Lr/T1–T4/CT 端子图、芯片原封装、10mm 最大 Z | 供应商图、首件低压测量、BOM 审核 |
| B1 控制验证 | 偏置、UCC25600/UCC27282、UCC24624，失压/默认禁能 | 逻辑与真实输出级关断、阈值和时序；不连接高功率板 |
| B2 磁件离板测 | 高温 L(I)、漏感/DCR/ACR、低压相位和绝缘预检 | 真实 DUT 编号、仪器、扫频/偏压点、DOT 接线记录 |
| B3 PCB 装配静态 | ERC/DRC、焊盘 X-ray/焊接外观、连接四线阻值、隔离/回流 | 不能以 DRC=0 代替电气绝缘与高流铜路签核 |
| B4 限能逐级上电 | 低压/低能限流、空载再10/25/50 A、独立门极关断 | Vgs/Vds、Vin/Vout、频率、温升与异常关断，事先核准止损阈值 |
| B5 额定验证 | 经风险评审后逐级 75/100/120 A × Vin/温度 | 可靠散热、温度稳态、效率含偏置、短路/恢复、机械高度实测 |

**B5 未通过：不可以写 100/120A 连续额定。** 如无法构成安全可靠的限能实验装置，则在 B3/B4 阶段暂停上电并寻求合格台架和人员。

## 2. 必备仪器/治具（成本优先换可信度）

- 可编程限能电源、电子负载/负载切换平台（关注 2V/100A 端导线压降）、DC 精密四线电压表、隔离差分探头和合格电流传感器、示波器、功率分析仪/精确电力计。
- 适合高频绕组的阻抗分析仪及 DC bias L(I) 测试、直流微欧计、热电偶与热像仪（需发射率/接触温度核校）、绝缘与压降测量器材、快速硬件急停和物理隔离罩。
- 负载端 Kelvin sense 放在实际接口，功率计的输入/输出采样点、偏置源能耗必须清楚。仅靠设置 Vout=2V 无法证明负载端 2V。
- 所有测试人员由负责工程师审核测点与量程，禁止在 100A 回路中串入未额定的探头/分流器。

## 3. 波形必须包含

V_in、I_in、V_out 纹波、I_out、Lr 电流、半桥 Vds/Vgs、每组 SR 电流与栅压、CT/OC 节点、保护锁存、所有偏置供电；条件允许的情况下测全八只 SR 并对应到实际 refdes。记录负载跃迁瞬间与数分钟后热稳态。电源一开、能输出几秒钟 != 额定热态。

## 4. 中止与再启动

任何意外高门极、过温、强振铃、输出回灌、供电失压后不可控重启、主桥/次级短路或 CT 极性异常，立即按预先设计的独立停机机构中止。禁止通过临时提高保护阈值继续测试而未进行书面风险重新评审。
