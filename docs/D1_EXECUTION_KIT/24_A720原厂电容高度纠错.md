# 第24章：A720输出电容原厂最高高度纠错与10mm机械余量

2026-11-04从YAGEO Group [准确料号原厂规格](https://yageogroup.com/download/specsheet/A720V477M2R5APE003)确认 `A720V477M2R5APE003`：470 µF、2.5 V、3 mΩ（100 kHz/25℃）、11.69 A RMS（100 kHz）和 **H MAX 2.1 mm**。先前仓库按照某些分销商标注 `1.9 mm` 作为机械最高高度，偏小0.2 mm；不能用标称/典型高度计算冷板接触或壳体极限。原厂7.3×4.3 mm为器件本体轮廓，但**并不意味着仓库的占位焊盘已经具有厂家批准的可制造落板尺寸**。

已将原厂高度上限同步到 `tools/cout_bank.py`、`design/v3/bom/cout_bank.json`、15只C100–C114的 `hardware/dcx_mech/placement_report.json`，以及占位KiCad封装和原理PCB摆放文件的高度描述；相应回归测试逐只检查2.1 mm，不再允许1.9 mm作为最坏情况。

纠错仅影响电容高度，不改变Cout ESR的 **3 mΩ/15≈0.200 mΩ** 部件理想并联计算，也不意味着50 V仿真已按真实电容、铜箔或实测电压重新运行。电容仅2.5V，额定余量对于2V输出及负载突变仍需要最高Vout（含启动、无载、回弹和批量容差）绝对值测试；冷板装配的垫片、压缩应力、温度寿命也未通过。

**制造限制**：机械文件仍为布局研究，没有真实带网铜层/过孔、焊接高温浮高、厂商签认足迹，不应因更正0.2mm便解除 `NOT_FOR_FAB`。
