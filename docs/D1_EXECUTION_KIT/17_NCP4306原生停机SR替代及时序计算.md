# 第17章：NCP4306带原生停机脚的SR控制方案（8片）

> 2026-11-03 新增可比选方案。本方案**替换**4片UCC24624，不是与U7–U10的UCC27524A数字缓冲叠加。`NOT_FOR_FAB`未改变；只做原厂资料/脚位/计算/施工接口，**没有修改原生EDA或产生新的故障RAW**。

## 1. 为什么仍需要第二种硬件架构

原设计的 [TI UCC24624 Rev.C](https://www.ti.com/lit/ds/symlink/ucc24624.pdf) 依靠比例门极驱动、VDS约−35mV调节和预先降低VG来减小换流损耗。前一版 [UCC27524ADR缓冲方案](15_十路硬件故障关断接口及实施验收.md) 把VG当TTL/CMOS输入后会输出固定高低电平，不再保留原始模拟比例特性，因此它只应是**受控实验的候选**，不能默认是功能等价、可直接投板的原方案。

新候选为 [onsemi NCP4306AAAZZZADR2G](https://www.onsemi.com/download/data-sheet/pdf/ncp4306-d.pdf)，SOIC-8；官网2026-02 Rev.9手册封面和订货表已核对。该器件单路SR、200kHz在其最高1MHz范围内、具有 **TRIG/DIS pin5**，通过外部硬件高电平关闭本路SR。8片新控制器分别驱动原有SR1A–SR4B。它**不能保留UCC24624原本的比例门极算法**，但不需要把已产生的比例VG信号再经数字缓冲放大；相当于用另一个完整的SR算法重新设计，必须整机验证。

## 2. 原厂真实脚位与能做的硬连接

onsemi NCP4306 SOIC8 Rev9：`1 VCC`、`2 MIN_TOFF`、`3 MIN_TON`、`4 LLD`、`5 TRIG/DIS`、`6 CS`、`7 GND`、`8 DRV`。从原生 `gen/netlist_export_raw.json` 逐一核对：新U7–U14的CS分别接原MOSFET漏极 `SEC1_A...SEC4_B`，GND接各SR源极Kelvin PGND；DRV接既有R20–R27的输入，新控制器不能与仍在输出的UCC24624并联。`R20–R27`的另一端仍接GA1/GB1至GA4/GB4，各原MOSFET漏/门/源不变。逐脚JSON：[ncp4306_sr_redesign_candidate.json](../../hardware/dcx_main/ncp4306_sr_redesign_candidate.json)。

两路独立许可用**每个TRIG一个10kΩ候选本地上拉到12V_S + 两个串联常断NMOS下拉到本地GND**：只有两个许可同时被有效拉高，两个NMOS都导通并使TRIG=LOW才允许SR工作。任一许可丢失，NMOS截止，TRIG经本地VCC12_S上拉为HIGH而强制关断；若12V_S本身消失，须依赖芯片UVLO与外部栅源下拉做掉电试验。每个上拉回路在允许工作时标称约1.2mA，8路合计9.6mA；与上一方案ENA/ENB**需要默认低**相反，NCP4306的TRIG **需要默认高**。不要把上拉连到未知的高压母线；TRIG绝对最大额定跟随VCC，且在VCC以上可能由保护二极管导通。

一个串联NMOS短路、某路TRIG被硬拉到PGND、控制许可线有地弹都可能绕开停机；两路许可并不自动等于通过单点失效安全验证。原边UCC27282 EN仍要按现有R7/R8纠错，且原边和次级接地若存在隔离域需按隔离电源、隔离器、地参考实施，不准直接跨电位传输。

## 3. 关键时序，不能直接引用“10.5ns”

Rev9表5真实数据：TRIG/DIS阈值1.6–2.2V，0→5V时传播延时典型10ns/最大16.5ns；**开通后TRIG消隐30–80ns**；持续HIGH 75–125µs才进入低功耗Disable Mode，但该100µs不是快速关断等待时间；低电平退出模式后还要考虑恢复定时。TRIG内部下拉最大15µA，如果没有外接默认高上拉，失去安全主控后TRIG可能仍被拉低、SR继续导通，这不是失效安全。最低可识别TRIG脉冲10ns；任何瞬态或残留电平需在全温、VCC变化下核对。

本轮建立了[12个时序扫描结果](../../design/v3/power_priority/ncp4306_trig_timing_screen.json)和`tools/check_ncp4306_sr_redesign.py`。按本地10kΩ上拉、内部下拉最大15µA、阈值2.2V、外部等效节点寄生25/50/100/200pF与8/10/12V供电，计算TRIG从0V开始上升至关断阈值的RC时间，叠加最大80ns消隐和16.5ns传播延迟。例如8V、100pF时约0.43µs；这仍**不含比较器/锁存/传播、真实MOS门极放电和温度变化**，不能宣告硬件在0.43µs内安全关断。`cshunt`模型与这个真实时间无关。

## 4. 实施细节及按风险从高到低的验证

- 首先制作8路独立小功率控制板的两组方案：原4×UCC24624+4×UCC27524A数字缓冲（A方案）；8×NCP4306自带TRIG（B方案）。**两组相互排斥，不能混用原输出。** 优先在模拟负载与单对SR上比较实际时序、VD采样、最小导通时间、换流反向电流与干扰。
- 再完成12V_S失压、5V独立保护失压、任一路TRIG开路/短地、两个串联NMOS卡高/卡低、TRIG消隐内故障与真实R_G/C_GS放电测试。记录全部8只 `VGS、VDS、ID、TRIG、CT、LATCH` 同窗时序；原边的1.5µs级EN关闭单独计算峰值期间的Lr储能。
- 需要按照200.6kHz和实测寄生选择NCP4306最低TON/TOFF，不可把10kΩ设置电阻随意当默认：它在部分版本中可能意味着1µs Tmin，200kHz周期5µs，过长可能造成跨导通。LLD保持已验证的合理状态、逐路Kelvin CS阈值非常敏感（1mV误差对应1mΩ器件约1A）。
- `MAG-01/02`磁件全部24实际端子和L(I)/DOT，以及 `50V`配对基准320µs、第三象限SOA和可接受的数值误差，仍是独立P0阻塞；**更换SR驱动器不会自动解除它们**。
