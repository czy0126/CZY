# D1 5 A SR 开/关：真实 LTspice Windows 批处理入口

此前的四份 5 A/10 A 网表均只经过源码一致性预检，不能写成已运行仿真。新的 GitHub Actions 入口使用 Windows 2025，先验证真实 ADI 官方 MSI 的 Authenticode 厂家签名，再调用 ADI LTspice -b 命令运行 5A SR_ON 和 SR_OFF，保存 .raw、.log 和对照报告至 Actions artifact。

电路源锁定：sim/v3/sr_tank_dual_v33_cold_phys.cir；5 A 只是以理想 2 V / 0.4 Ω 选择电阻，实际电流必须根据求解 Vout 判断。仍需要用独立测量评估体二极管 SOA、REG、门极关断及磁件极性。仿真运行成功也不代表允许硬件上电或制造。

若官方下载/签名/安装/求解失败，工作流保留失败日志但绝不假称仿真完成。前一轮模型预检通过不等于本轮真实 Windows 批处理成功。
