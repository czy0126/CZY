# TLV3501 快速过流 ECO 模块

日期：2026-11-05（外部过流接口安全复核）。生成器 `tools/make_fast_oc_eco.py`，输出 `pcb/fast_oc/`，
测试 `tools/test_make_fast_oc_eco.py` 和 `tools/test_fast_oc_integration_safety.py`。器件依据 `references/datasheets/tlv3501.txt`（TI SBOS321E）。

## 1. 这块板要回答什么

路线 P1-b 指出：D0 的"快速"过流通道是 LM393，**没有 µs 级延迟依据**。本板把这句话变成算术：

D0 的 U3B 不是瓶颈，它前面的三级滤波才是：

```
OCD --[1k/47nF = 47 µs]--> OCF --[10k‖24k + 10nF = 70.6 µs]--> OC --[10k/1nF = 10 µs]--> OC_FILT --> LM393
```

三级时间常数合计 **127.6 µs**，再加 LM393 约 1.3 µs 传播，约 **128.9 µs**。
**只把 LM393 换成 4.5 ns 的比较器，系统只快了约 1.3 µs**——这就是"不得只换 BOM 名称"的意思。

本模块因此**直接取 CT 负载节点 OCD**，只经过一个 1 µs 极点，用 TLV3501 比较，
再由 2N7002 开漏输出**低电平有效 FAST_EXT_N**，仅连接 D0 的 J10.4。D0 使用 U11F 反相后经 U19 或门与原有**高电平有效 FAST_TRIP**合并。**严禁模块 J1.4 连接 TP8/FAST_TRIP，否则会抑制本地故障信号。**

本板**不是**功率级，不接主回路；`hardware_built` 与 `fabrication_approved` 恒为 false。

## 2. 电路

| 部分 | 器件 | 说明 |
|---|---|---|
| 接口 | J1 四针 | V5 / PGND / OCD / FAST_EXT_N；连接 D0 J10.1–J10.4，禁止接 TP8 |
| 比较器 | U1 TLV3501AIDBV（SOT-23-6） | 1=IN−，2=V−，3=IN+，4=V+，5=OUT，6=SHDN |
| 参考 | U2 LM4040DBZ-2.5 + R1 2.4k + C3 100nF | 2.5 V，偏置 1.04 mA |
| 分压 | R2 30k / R3 15k + C4 100pF | 1/3 分压，10 kΩ 戴维南，1 µs 极点 |
| 滞回 | R4 470k | OUT 到 IN+，正反馈 |
| 输入保护 | D1/D2 BAT54ZFILM（对应 SOD-123 焊盘，见 PR #44） | D1 阴极在 IN+（对地），D2 阴极在 V5 |
| 输出级 | R5 100R + R6 10k + Q1 2N7002 + R7 10k | 推挽转漏极开路；R6 保证 Q1 输入默认低；R7 10k 本地上拉，与 D0 R100 100k 下拉形成正常高电平 |

**SHDN 接低电平，这是本板最容易做错的一处。** TLV3501 的 SHDN 在**距 V+ 不到 0.9 V 时是关断**
（输出高阻），只有低于 V+ 超过 1.7 V 才使能。也就是说，把它接到 V+ 会得到一个 ERC 干净、
**永远不翻转**的快速比较器。R8 10k 把 SHDN 拉到 PGND（引脚偏置电流 2 pA，压降 20 nV），
`test_shutdown_is_pulled_low_because_high_disables_the_comparator` 锁死这一点。

## 3. 门限

`I_trip = Vref·(R_top+R_bot)/R_bot / 0.1 V/A = 2.5 × 3 / 0.1 = 75.0 A`（标称分压交点）。
计入 470k 正反馈后，实际**跳闸 76.6 A、释放 73.4 A，滞回 3.2 A**（均由生成器重算，测试逐项比对）。

与仓库里已有峰值的关系（全部真实存在，不是想象值）：

| 工况 | 原边峰值 | IN+ 电压 | 是否在共模内 |
|---|---|---|---|
| 稳态额定 | 13.88 A | 0.463 V | 是 |
| UCC25600 Level-1（1 V） | 24.2 A | 0.807 V | 是 |
| 冻结短路 deck | 73.68 A | 2.456 V | 是，**但不跳闸** |
| 冷启动故障 | 84.83 A | 2.828 V | 是，跳闸 |
| 48 V hotfault | 97.44 A | 3.248 V | 是，跳闸 |
| 50 V hotfault（前缀） | 101.26 A | 3.375 V | 是，跳闸 |

**73.68 A 那一行是有意的边界**：它留给控制器自己的过流（1 V / 24 A、2 V / 48 A 两级），
本模块针对的是 84–101 A 的严重故障。把门限压到 73 A 以下会与控制器争抢，
所以 `test_the_threshold_sits_above_the_frozen_short_circuit_and_below_the_severe_faults`
把这个次序写成判据。

## 4. 延迟预算（不许拿典型值当最坏值）

| 环节 | 数值 | 依据 |
|---|---|---|
| 输入极点 | 1.00 µs | 100 pF × 10 kΩ |
| 比较器 | **12 ns** | 5 mV 过驱、−40…+125 °C 的 max（典型 4.5 ns **不用**） |
| 门极网络 | 50 ns | 100 Ω × 100 pF 的 5 倍时间常数 |
| **合计** | **1.06 µs** | |

对照 128.9 µs，**约 121 倍仅为前端极点和比较器/门极的估算对比，不是最坏系统关断时间**。真实阶跃的 RC 门限穿越时间随过驱幅值变化；未计 U11F/U19、锁存器及实际十路驱动器延时。这个倍数是数量级比较，不是签核值：
既有路径那一侧是**级联时间常数之和**，不是传播延迟，报告里已按此注明。

路线要求逐项核的四件事：

- **共模**：IN+ 在 101 A 时 3.375 V，上限 V+−0.2 = 4.8 V，余量 1.4 V。共模上限对应 **144 A**，
  绝对最大值对应 **159 A**（此时 D2 开始导通）。
- **过驱**：门限处过驱随 di/dt 增长；12 ns 是 5 mV 过驱的最坏值，20 mV 时只要 6.4 ns。
- **滞回**：3.2 A，足够盖住 CT 负载上的开关噪声。
- **供电失压**：5 V 消失时参考与比较器同时失效，R6 把 Q1 栅极拉到地，于是
  **不得推断 D0 锁存/真实 VGS 已安全关断**；共享 V5 丢失、局部线缆掉电、OCD/D2 反灌均应作为未验证单故障。LM4040 的最小工作电流**本仓库没有数据**，
  所以低压拐点标 UNVERIFIED，不写数字。

## 5. 状态（模块与 D0 都在额定 V5 供电条件下）

| 场景 | 模块 Q1 | FAST_EXT_N（J1.4/J10.4） | D0 中的结果 |
|---|---|---|---|
| 无过流且两板连接 | 关断、高阻 | 由 R7 10k / R100 100k 分压约 4.55 V | U11F 输出低，不触发外部 FAST |
| 过流 | 导通拉低 | 接近 0 V，VOL 需实测 | U11F 输出高，经 U19 请求故障 |
| J1.4 信号线断开 | 与模块状态无关 | D0 R100 下拉至低 | 仍上电时请求故障 |
| 整套 V5 失去供电 | 不可作为有效数字逻辑 | 不能视为正常高电平 | **无锁存供电保障，不得宣称关断已完成** |
| 模块局部失压/地线断开但 J1.4 仍连接 | 可能反灌 | **UNVERIFIED** | 必须用低能量台架判断 |
| Q1 卡断或 R7 故障 | 不可保证 | 不可保证 | 必须单故障注入 |

本模块自身不锁存；D0 的 CD4013 锁存不等于实际十路 VGS 已关断。

## 6. 唯一允许的接线方式与接口电平验收

```text
fast_oc J1.1  V5          -> D0 J10.1 V5
fast_oc J1.2  PGND        -> D0 J10.2 PGND
fast_oc J1.3  OCD         -> D0 J10.3 OCD
fast_oc J1.4  FAST_EXT_N  -> D0 J10.4 FAST_EXT_N
                                      |
                                 D0 R100 -> PGND
                                      |
                          D0 U11F (NOT) -> FAST_EXT_H
D0 U3B -> FAST_TRIP ----------- D0 U19 (OR) -> FAST_COMBINED -> latch
```

**严禁把 J1.4 接 TP8、R15 或 D0 的 FAST_TRIP。** 模块过流时输出 LOW，而原 D0 FAST_TRIP 故障定义为 HIGH；两者不能进行开漏线与。错误直连可让 Q1 把真实的 U3B 高故障钳低。只有经过 U11F 的反相及 U19 的或门后才能并入保护。

在两板连接且 Q1 关断时，忽略输入漏电：`V_FAST_EXT_N ≈ 5×100/(10+100) = 4.545 V`。R7/R100 各 ±10% 的筛选计算仍有约 4.455 V（V5=5.0 V）。TI CD4069UB 数据表 VDD=5V 时的 VIH(min) 为 4.0V，标称值仍有裕量；但供电最低值、实际阈值、噪声、线缆负载及漏电均未签核，必须实测。参见 [TI CD4069UB](https://www.ti.com.cn/cn/lit/ds/symlink/cd4069ub-mil.pdf) 与 [TI CD4071B](https://www.ti.com/document-viewer/CD4071B/datasheet)。

**不能用“断信号线触发故障”推出断电源线也故障安全**：R7 与共用 V5 的反灌路径、OCD 输入及整个 5V 域掉电均需单独测量。

## 7. 首件验证（低能量偏置、不连接 48 V 主桥）

1. **先核线再上电**：确认 J1.1–4 分别只接 D0 J10.1–4；测量 J1.4 与 TP8/FAST_TRIP 非直连。两板均由限流 5V 供电。
2. **静态**：确认模块 REF、SHDN、OUT 实测值，TP5/J10.4 在无故障时约 4.55V；这不等于 D0 已具备安全上电许可。
3. **门限**：缓慢扫 OCD，记录实物上升翻转电压与下降释放电压；设计名义约 7.66V / 7.34V。应记录电阻误差及比较器失调，不能把理想值当作保证。
4. **极性**：输入升高时 TP4 高、TP5 低，D0 FAST_EXT_H 与 FAST_COMBINED 高；即使外部模块正常空闲，D0 原生 FAST_TRIP 高也应独立触发锁存。
5. **动态**：对 0→10V OCD 阶跃，一阶 1µs RC 从零电压到约 7.66V 触发点，理论 `t=-τln(1-7.66/10)≈1.45µs`，并非恒定 1µs。应记录真实探头、过驱、U11F/U19 和锁存时间，最终必须以实际门极 VGS 关断时刻为准。
6. **单故障**：分别断开 J1.4、V5、PGND，注入 Q1 卡断、欠压及 OCD 异常，并记录真实信号与门极状态。信号断开预期在 D0 有有效电源时触发故障；其余失电及反灌情况均标 UNVERIFIED，不能靠静态逻辑假设放行。
7. **保留证据**：保存同步采样 CSV（OCD、TP4/TP5、FAST_TRIP、FAST_COMBINED、锁存和真实 VGS）、仪器设置、版本及 SHA256。未通过上述实测与 D0 十路关断前保持 `fabrication_approved=false`。

## 8. 边界

- 只做模块；CT、整流桥、负载电阻仍在 D0 上，所以本板**不改变** D0 的 CT 传递链。
- 1 µs 极点是为抑制 CT 整流纹波选的；若现场噪声要求更大时间常数，门限不变、延迟按比例变长。
- 模块自身没有锁存、没有隔离、没有反接保护（D2 只钳正向）；整个 V5 域掉电并非由这一接口验证合格。
- LM4040DBZ-2.5 的最小工作电流未核实，低压角标 UNVERIFIED。
- ERC 0 违规只说明图纸自洽；封装、布局、温度都未审。
- U1 是 **DBV 六脚封装**，原表把它和两脚基准源一起套在 `SMD = SOT-23` 这个常量上，
  于是六脚落在三焊盘上而 ERC 全绿（ERC 不看封装）。已改成 `SOT-23-6`，
  `test_every_symbol_pin_has_a_pad_in_its_footprint` 逐件数焊盘锁死。

## 9. 布线板（`pcb/fast_oc/`）

`tools/make_fast_oc_pcb.py --check` 生成 52 × 38 mm 双层板并**当场跑 kicad-cli DRC**，
不干净就 `SystemExit`。当前结果：26 只件、9 条网、52 个焊盘、
**42/42 连接**（504 段 0.25 mm 走线、35 个过孔），
`drc.json` 三个顶层数组全空（violations / unconnected_items / schematic_parity）。

三件必须知道的事：

1. **`escape_mm = 0.0`，这是实测选的，不是省事**。路由器默认给"尚未布线的网"
   留 0.40 mm 余量，防止后续网把它的出口封死；但 U1 内侧焊盘到对面一排只有
   1.375 mm，够 0.25 mm 走线（0.775 mm 余量）、不够两侧同时留余量（1.575 mm）。
   六种确定性布网顺序在默认值下停 **40/42 或 41/42**，余量归零后 **42/42**
   且 DRC 无净空违规。该值写进 `fast_oc_pcb.json` 的 `escape_reserve_mm`，
   SR 验证板仍用默认值（`test_the_escape_reserve_...` 锁住默认不变）。
2. **安装孔位号的丝印是隐藏的**：孔中心离板边 5 mm、位号在孔上方 4.9 mm，
   可见时落在 38 mm 板外，DRC 报 `silk_edge_clearance`。官方 KiCad 安装孔
   封装本来也是隐藏的。SR 板默认保持可见（板子更大，已提交文件不能变）。
3. **`dcx.pretty` 必须先写、再生成板文件**：`board_file()` 通过 `stock_text()`
   从磁盘读封装，顺序反了会内嵌上一次的副本，全新 checkout 重生成就与提交件不一致。

**这不是签核**：`hardware_built` / `fabrication_approved` 恒 false；
全部走线 0.25 mm（信号级，没有载流要求）；只有 DRC，没有热、没有 EMC、没有首件。
