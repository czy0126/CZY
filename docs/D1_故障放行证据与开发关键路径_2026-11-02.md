# D1 阶段审计更新：故障风险关闭条件与最短工程路线（2026-11-02 夜间）

> 审核基线 `main@82a3586b328806bde57a99f339a8fea2ec189304`。本轮没有新的 LTspice RAW/LOG、磁件厂商引脚图、已确认 MPN、GUI ERC 或真实带网 PCB。详细热/冷板设计继续后置，但硬件额定未批准。

## 1. 本次发现并修复的根因

`tools/d1_unclosed_risks.py` 上轮把故障 F01 是否解除写成 `ss_at_engage_v >= 3.982V`。3.982V 只是仓库中 UCC25600 行为模型 `Ieff=max(0,1.81m - Vss/2200Ω)` 的 RT-only 模式门槛，**不是稳态认定，更不是完整故障保护证据**。若原始冷启动故障 Vss 上升至4.2V，但输出仍在变化，此旧逻辑会将 F01 误关。

已新增 `tools/hotfault_engineering_gate.py` 并将 F01 改为：**48 V/120A、50 V/120A 两个独立工况都具备有效日志预检、完整波形工程审核文件及对应原文件 SHA256 后才允许关闭这一“仿真验证”风险**。本轮两个均缺证据，所以 F01 仍 BLOCKED，并在 `unclosed_risk_register.json` 中明确标记为独立证据未获接受，而不是把原冷启动故障的 SS 判据当作关闭依据。

## 2. 工程师如何使用故障审查文件

已有两个尚未运行的 deck：
- `sim/v3/sr_tank_dual_v33_ss_hotfault_48v_120a.cir`
- `sim/v3/sr_tank_dual_v33_ss_hotfault_50v_120a.cir`

在安装 LTspice 的 Windows 工作机使用 `tools/run_dcx_pending_cases.ps1` 实际运行，验证器 `tools/validate_hotfault_log.py` 只给出 **`LOG_PRECHECK_PASS_REQUIRES_WAVEFORM_AND_DEVICE_REVIEW`**（需要后续审查），不等于自动批准保护。审核 `V(ss)`/两段 Vout、实际 `V(ctl_hot)` 和 `I(Rflt_hot)`、OC 首次越限、控制输出关断、Lr 和全部 SR 瞬态峰值、故障后恢复情况与仿真真实结束时间。

[审查模板](../design/v3/power_priority/hotfault_engineering_review_TEMPLATE.json) 默认 `approved=false`，所有布尔项 `false`。获得**实际**波形和工程师签署后，分别创建 `hotfault_48v_120a_engineering_review.json`、`hotfault_50v_120a_engineering_review.json`，引用仓库内原始 `validation.json` 与波形评审文件及**准确 SHA256**。这类报告仍只能支持**行为模型故障仿真工程审核**，不能批准磁件 Bsat、MOS SOA、机械/热、连续额定。

### 不能通过的情况

- 只有 `SS≥3.982V`，没有输出稳定的故障前两个时间窗；
- 只有 `V(oc)>1V`，没有故障开关真实导通/负载支路电流；
- LTspice 只跑到了故障塌缩前缀，未结束预定区间；
- 没有 48V 与 50V 各自独立的日志、RAW、控制/关断与工程师审查；
- 只有自动生成 JSON 写 `approved=true`，没有原始证据及哈希。

## 3. D1 关键路径与后续优先级

| 并行负责人角色 | 下一条必须提交的工程文件 | 验收与阻塞 |
|---|---|---|
| **磁件 + 供应商（P0）** | `supplier_magnetic_terminal_reply_template.csv` 的正式厂商回复；24 逻辑端对应真实 pad/DOT、实际封装与版本图 | **T1–T4 和 CT 缺物理脚号；CT 四逻辑端/两 pad 错配**不得作为真实主板 footprint |
| **电路 + 采购（P0）** | `supplier_component_selection_template.csv` 的正式回复；优先五磁件、Cr、Cin/Cout、Lr、D_BT 和功率连接器，后并行常规 R/C | 61 占位位号未有真实 MPN/封装或实际审核 |
| **EDA + PCB（P0）** | 可保存、关闭并重新打开的原生设计 + 独立 GUI ERC 报告 + 带网 PCB/DRC；优先四组 SR→Cout 和回流 | 当前 83 个位号是逻辑布图，不等于投板可制造 |
| **仿真 + 保护（P0，与 EDA 并行）** | 48/50V 两套完整 hotfault LOG/RAW；日志预检报告 + 控制关断/损耗峰值波形人工审查 | 不再仅以 SS/端口峰值判断故障保护 |
| **损耗账本（P1，与 EDA 并行）** | 50V/119.27A 的 `P_in,P_out,P_loss_i,dE/dt` 同窗 5/2/1ns 分解；100A SR 正向二极管损耗步长检查 | 50V/120A 损耗分项相差 **0.499W**，闭合残差约 **0.671W**；目标仍 **0.2W** |
| **磁件高流首件（P0）** | 3 匝 Lr 测 `L(I)`、气隙、Bsat/温度及故障峰值裕量 | 2 匝在 84.83A 估算 `B≈0.326T>0.279T` 设计限，3 匝只是候选 |

**最短推进方式：** D1 发送已有供应商 CSV、在本机启动两套独立故障仿真；D2–D3 供应商首批回复与 EDA 真实封装/GUI ERC 并行，仿真侧完成波形审核；D4–D5 导入原生带网 PCB、输出关键大电流路径及 DRC 记录。任何 P0 缺真实证据则继续 `NOT_FOR_FAB`，不虚报工期。详细热模型后置，但保留测温/限流/安全关断验证位置。
