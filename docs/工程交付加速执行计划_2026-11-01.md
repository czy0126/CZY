# 工程交付加速执行计划（48 V→约 2 V、24:1 DCX）

> 更新：2026-11-01；基线：main 提交 409cf9b66677b1af23236465f57a3af311114151。
> 本文是**从 V3 分析成果进入制造工程的当前执行入口**；原 docs/后续详细路线图.md 保留为 V1 历史记录。
> 本计划为执行顺序和验收标准，不代表任何器件、PCB 或硬件已经签核。遇到更新的实测证据，应在 design/v3/当前候选基线_2026-11-01.md 中修正参数，并在此更新任务状态。

## 0. 一句话决定方向

**优先完成可编辑的主功率板原理图、真实 PCB、制造 BOM、磁件首件和 SR 控制验证板；不再用新一轮综合审核或更多模型数值替代工程交付。**

项目慢的根因不是缺算法或缺文档，而是：
1. 设计指标尚有矛盾（24:1、48 V、100 A 与 2.00 V±2%／200 W 不能未经重新设计同时承诺）。
2. V3 已有逐脚网表（约 66 位号、65 网络、193 引脚）与大量模型，却**没有主功率板原生原理图、PCB、Gerber 和可采购制造 BOM**。
3. 关键机械/热边界（磁件端子与气隙、Cout、100 A 铜排、冷板接口）尚未从真实物料与首件获得反馈。
4. UCC24624 只存在原生控制验证原理图/行为模型，控制验证 PCB 和实际换流波形尚缺。
5. 反复审核把可以并行的 CAD、采购、磁件打样排成了串行；开发工作被小数位校核反复打断。

## 1. 完成定义：按 D1/D2/D3 三个 Gate 管理

| Gate | 必须有的真实交付物 | 判定人必须检查 | 状态 |
|---|---|---|---|
| **D1 可制造设计候选** | 可编辑原生原理图、PCB、逐脚网表对照、封装与正式 BOM、PCB 叠层、Gerber/钻孔/贴装坐标、磁件加工图、整机高度剖面、测试接口与上电计划 | 真实元件脚号/焊盘、ERC/DRC、铜路/散热及制造厂约束；关键采购件和磁件可得/可加工 | **未达到** |
| **D2 功能样机** | 首板实物、磁件检验记录、控制启动/停机/保护与限能加载示波器波形、主要器件应力和可复算测量日志 | 非硬件模型；有实测 VGS/VDS、输入/输出波形、各组电流和保护记录 | **未达到** |
| **D3 额定样机** | 46/48/50 V × 多电流 × 环境/冷却矩阵、100 A 连续热稳态、负载端电压/纹波/效率、整机机械高度、降额条件 | 电源主输入和全部外供偏置功率一并计量；给出真实可持续额定 | **未达到** |

通过软件单元测试不等于 D1，达到 100 A 瞬时峰值不等于 D3。D1 的设计发布与允许通电仍须独立安全审查。

## 2. D1 设计输入：先冻结工作包络，再锁真实器件

| 参数 | 当前第一版研发口径 | 必须在 D1 明确的决策 |
|---|---|---|
| 输入 | 46–50 V 连续候选，48 V 标称；54 V 只作为待验证边界 | 输入保护、最大电压应力与允许纹波 |
| 结构 | 保留现有半桥 LLC/DCX、四只 3:1:1 变压器原边串联与四组 SR | 不为首样并行维护多个拓扑 |
| 变比/输出 | 24:1 固定比、目标约 2 V／100 A；现有 48 V／100 A 模型约 1.887 V | **不得同时宣称 48 V、100 A、2.00 V±2% 或 200 W 都已满足**。若 2 V±2% 是硬指标，须明确改变变比、上游输入或调压结构 |
| 频率/谐振 | 200.6 kHz 标称；Cr 620 nF，总 Lr≈1.00 µH（外置 + 变压器漏感） | 根据首件漏感回填外置 Lr，不得将 1.00 µH 总感误作外置电感量 |
| 输出纹波 | 当前工程候选目标 ≤50 mVpp，未成为最终产品规格 | 给出带宽、负载端测量位置、允许动态跌落与恢复时间 |
| 输出路径 | 0.15 mΩ 当前工程预算（含铜排/接点）；目标 100 A 连续 | 输出接头、铜排、接触电阻实测方法和热边界 |
| 高度/热 | 模块最高点 ≤10 mm 候选；冷板、TIM、固定方式及沉槽公差必须单独列出 | 明确**是否包含冷板**，定义允许环境/冷却条件 |
| 偏置 | 首版允许外供并单独计功率 | 两路偏置的电压、上电顺序、功率、接口与掉电行为 |

为提高效率，以上未决项允许用“暂定值 + 风险 + 测试方式”继续布局，但任何越过器件安全额定、无法制造或影响电路正确性的事项均是投制阻塞项。

## 3. 四条并行交付主线（同一时间仅一个 CAD 主任务）

### A. 主功率板原生 CAD / 制造包（最高优先级）

**输入**：design/v3/pcb/board_netlist.csv、board_netlist.json、主功率板连接网表_2026-11-01.md、design/v3/bom/bom_draft.csv、芯片原厂引脚与封装图。

- [ ] A1：创建 hardware/dcx_main/ 中的原生工程（可选 KiCad 或团队实际使用的嘉立创原生格式；**不得用文本说明冒充原生 CAD**）。
- [ ] A2：原理图按“输入/半桥、谐振腔/四磁件、四组 SR、UCC25600/UCC27282、偏置/保护、接口/测点”分功能页；把 SPICE 行为 B 源、零伏探针和理想元件替换为真实器件及可实现外围。
- [ ] A3：器件逐引脚检查：UCC25600/UCC27282/UCC24624、原边与 SR MOS 的封装脚号、源漏、散热焊盘、DOT/CTAP、0 Ω Kelvin 链、门阻、自举二极管 ≥100 V 反压规格；制作 pin_footprint_review.csv。
- [ ] A4：导出 **原生 CAD 网表**，与黄金网表做双向 ref.pin→net 差异报告；非同名但等效网络要有正式映射记录，不得只统计器件数量。
- [ ] A5：先用 1:1 外形/3D 模型放置 T1–T4、Lr、CT、SR、输出电容和 100 A 铜排；再决定板框、沉槽、安装孔、接口。冷板/热界面、元件最高点和公差同时绘制截面。
- [ ] A6：优先布半桥高 di/dt 环路→Cr/Lr→变压器→SR→Cout→铜排，之后才布栅极回路/驱动与 Kelvin 检测/低速控制。四组 SR 分别预留电流/温度测点。
- [ ] A7：输出可采购 BOM（MPN/制造商/封装/数量/等级/官方数据手册/替代料）、叠层、DRC 报告、Gerber、钻孔、贴装坐标、装配图与制造审查清单。

**A 完成标准**：原生电气与机械工程可以打开；没有未解释的 ERC/DRC 错误；网表与真实管脚/封装核对通过；铜排、电容、磁件的真实外形占位；所有 DNP、未定料和替代物被明确标识。**原生设计生成不等于硬件额定已通过。**

### B. 磁件与采购首件（和 A1–A5 并行）

**输入**：design/v3/magnetics/、design/v3/bom/lr_design.json、inspection_spec.csv、绕组工艺卡_2026-11-01.md、winding_connections.svg。

- [ ] B1：只先加工 **一套** T1 3:1:1（Lm≈10 µH）和一只候选 Lr、CT；复核四只串联的终端连接与所有同名端极性。
- [ ] B2：Lr 的首版方向为 ELP32 N97 **三匝候选**，1.444 mm 气隙为计算值，不是完成签核的量产规格。物理配置线性仿真给出 84.02 A @1.0 µH、104.17 A @0.875 µH 故障电流峰值；两匝的计算磁通已越限。要求加工方确认大气隙、边缘磁通、铜损、固定和高度的可实现性。
- [ ] B3：检查实际引脚和尺寸；测每只变压器 Lm、各配置短路漏感、各绕组 DCR、变比、极性、绝缘和高度。Lr 测大信号 L(I)、气隙温升。CT 测传递、复位、饱和及保护触发延迟。
- [ ] B4：测得漏感后更新总谐振电感，重新计算外置电感所需 L_ext = 1.00 µH − 实测折算漏感；回填仿真与 BOM 后才冻结定制磁件数量。
- [ ] B5：同时核查 Cr 在约 200 kHz 的纹波电流/ESR，Cin 的实际输入阻抗与 RMS，Cout 的真实规格、铜排电阻和 100 A 连接器。

**风险**：Cout 的 15×470 µF、7.05 mF、0.20 mΩ 仅为理想并联近似，**0.20 mΩ 没有包含 PCB 和连接寄生余量**。2.5 V 耐压在高输入和过冲下需重新计算。候选料号的完整原厂频率/温度/电压数据、实装高度与热寿命必须在投制前核对。

**B 完成标准**：首件实测记录与机械外形可供 A 使用；不因“气隙理论通过”跳过大电流下非线性与温升验证。

### C. UCC24624 SR 与原边驱动验证板（和 A / B 并行）

**输入**：pcb/control_validation/control_validation.kicad_sch、原生 LCEDA 工程、控制验证板_设计与测试说明_2026-10-31.md、原厂 UCC24624 / UCC27282 资料。

- [ ] C1：从已有控制原理图生成实际 PCB 和 Gerber，确定电流回路、开尔文取样、门极回路、测试点、供电限流及安全边界。
- [ ] C2：仅偏置阶段验证 VDD/REG/UVLO、门极静态安全态、开关频率、死区和偏置掉电行为。
- [ ] C3：**修订原测试夹具**：T3/T7 文档中的“10 mH + ≤20 V”无法在 100–500 kHz 产生安培级交流 SR 换流。不要用正 VD 静态脉冲代替真实负 VDS 换流。设计能够产生可控安培级双向/换流电流的低压限能功率级，记录电流路径、夹具阻抗和观测基准。
- [ ] C4：带真实 MOS/Gate 负载测 VGS/VDS、TON/TOFF、PGD、反向电流、体二极管续流、两路互锁和不同温度/阈值下的变化。
- [ ] C5：根据真实数据校准 SR 行为模型/门阻/检测网络；关键波形满足安全限值后才签核主板相应连接及布局。

**C 完成标准**：有实际可复现的低能量换流测试报告与示波图，未把单组控制板的结果外推为整机四组 100 A 能力。

### D. 必要仿真 / 测试准备（支持 A/B/C，不抢主线）

- [ ] D1：仿真优先覆盖 46/48/50 V × 轻载/半载/额定、Lm/漏感/Lr/Cr 容差、四变压器失配、SR 检测延迟/Kelvin 寄生、Cout ESR/ESL、输入源阻抗、启动/掉电/OC。
- [ ] D2：为冷启动和最严可信保护故障建立“关断前能量与器件极限”的保守边界，确认 Lr 非线性可能引发的更大峰值；真实硬件故障须待保护先通过限能验证。
- [ ] D3：继续 Issue #6 但**不阻塞 A 的原理图和机械布局**。最新 133 门极周期相位对齐仿真已能分辨 0.2 W；其周期平均闭合残差约 **+0.326 W，仍在目标外**，当前不能宣称“全能量账本闭合”。只有影响器件额定、热设计或安全性的结论才升为 D1 发布阻塞。
- [ ] D4：提前落实负载端 Kelvin 测量、各路外供偏置功率、四组电流和器件热测点，在 PCB 上留真实可接入位置。

**D 完成标准**：每个新仿真必须明确“将改变哪张原理图、哪个 BOM 项、哪条保护或哪个机械尺寸”；无决策作用的扫参和新的综合报告暂停。

## 5. 投板前必须关闭 / 可以不阻塞的事项

**投板阻塞（P0）：**
1. 真实控制器、MOS、二极管脚号/封装和网络映射未核对，包含 DOT 与 SR Kelvin 极性。
2. 缺少完整可打开的原生主板原理图/PCB、正式叠层和生产输出，或存在影响连接的 ERC/DRC 错误。
3. 磁件端子、外形、高度、绝缘、绕组加工方向和 Lr 大气隙制造可行性尚不成立。
4. Cout/Cr/Cin 电压、纹波电流、温升与封装数据不充分以确定安全额定；100 A 铜路/端子无明确尺寸/测点。
5. 偏置、启动/保护逻辑存在明确过应力或可能直通、无法设置安全限能上电方法。

**不阻塞原理图/布局，但不得对外宣称已验证（P1/P2）：**
- Issue #6 的 0.2 W 完整模型储能守恒残差；在 133 周期已经测到超标，应继续定位，但不能再据此暂停 CAD。
- 变压器批次均流、SR 最终热损耗、完整板级热阻、最终效率与 100 A 连续性能（待 D2/D3 实测）。
- 54 V 边界和负载瞬态指标（若首版不将其写入已保证的工作包络，先记录为未验证）。

## 7. GitHub 协作规则：停止“再审核一遍”循环

1. **一个总入口**：README 链接本计划；current V3 baseline 仅保存当前真实参数及证据等级；历史审查保留但不再作为下一轮入口。
2. **每个 PR 只交付一个工程功能单元**：例如 A1 原理图、B1 磁件首件图、C1 验证板 PCB。PR 必须列出新增可打开文件、差异检查、仍缺的证据和下一项明确依赖；不要只补 README。
3. **每个阻塞项只允许一种验收方式**：脚号→官方手册与网表；漏感→首件仪器；波形→示波器；高度→装配剖面/高度规；效率→完整计量；禁止把“模拟器结果”冒充“实测通过”。
4. **工作在截止点做取舍**：资料不充分时保留已审阅候选及测试孔/占位，不为小幅优化多次推翻布局；真正 P0 风险仍然必须关闭。
5. **每次只更新一个可核验产物**；禁止为了报告完整而补未使用的推导，禁止仅以“单元测试绿”关闭硬件相关 Gate。
6. **明确项目指标与实测边界**：48 V/100 A 模型约 1.89 V、磁件高度预算、92%–94% 相关结果都是各自模型/估算，不能写作 2 V/200 W 连续及实物效率。
7. **周交付检查只问三件事**：产生了哪个可打开/可加工/可测量的文件？哪个阻塞被真实证据关闭？下一个阻塞的负责人和依赖是什么？

## 8. 马上执行的第一张任务卡（A1）

**目标**：基于 V3 黄金连接网表产出完整主功率板原生原理图（不是另一个设计说明文档）。

- 输入：design/v3/pcb/board_netlist.{csv,json}；design/v3/bom/bom_draft.csv；models 与控制器/功率 MOS 原厂手册；磁件端子 DOT 图。
- 输出：至少一套真实可编辑的原理图、符号/焊盘审查表、CAD 导出网表、与黄金网表的逐引脚 diff、ERC 报告。
