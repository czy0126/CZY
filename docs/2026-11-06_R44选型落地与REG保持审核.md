## 新发现并补齐的卡点

旧crowbar_pulse表只积分到3.63V UVLO，适合描述到达门限前的电容释能，不能代表完整故障能量。现在保留旧字段的明确范围，并新增从故障开始到整个保持期的恒流RC解析积分。

在95mA持续补流的假设下：

| 项目 | 计算值 |
|---|---:|
| 电容初始储能（11.9V、2.76µF） | 0.1954mJ |
| R44持续功耗 | 42.42mW |
| R44保持10ms的总能量 | 0.6293mJ |
| 保持100ms | 4.4469mJ |
| 保持1000ms | 42.6227mJ |
| REG最终电压 | 约0.456V |
| 芯片内部REG稳压器耗散（15V偏置） | 约1.382W |

这些是敏感性计算，95mA的手册测试条件不覆盖REG塌陷全过程；不能称全温上界。关键风险已由“电阻没有型号”推进到“芯片持续REG拉低时的真实供电/热行为”。电阻功耗较低并不能证明芯片可以长期这样工作。现有约19µs总关断时间仍是模型估计，不是实测。

## DeepSeek复核与纠正

任务和三轮回复见 deepseek/20261106_r44/。采纳准确料号、脉冲条件及完整保持期计算建议；明确退回两类错误：尾部指数项不能再代入已衰减的电压而重复衰减；REG下降是主动关断目的，不能把下降本身判为异常。也撤回了未定义REG注入试验及等待温升10秒才停止的建议。最后的 bench_reply.md 已确认纠正；之前回复作为审核痕迹，不作操作指令。
