## 2. A5 机械布置的核心风险

| 项目 | 当前记录 | 审核意见 |
|---|---|---|
| PCB 外形 | 155×131 mm、35 个占位／实际外形对象 | 可用于摆件，**还不是高速回路和 100 A 电流路径的可实现布局**；板框要随真实 SR→Cout→J_OUT 路径与冷板机械边界复核 |
| 5 只磁件 T1–T4、Lr | ELP32，最坏裸磁芯高度 9.8 mm；平铺含胶/标签估计 9.94 mm | 相对 10 mm 仅余 **0.06 mm**。0.5 mm 固定压件时估计 **10.44 mm**，已超限；五只磁件要一起考虑沉槽/固定，不能只给 T1–T4 沉槽 |
| PCB 沉槽 | 现设想下沉约 0.5 mm | 需要 1:1 **剖面**：基板剩余厚度、绝缘/层间铜、焊料/固定件、凸起、冷板/TIM、装配公差与加工许可。先由制造厂确认工艺，再声称 ≤10 mm |
| CT、Cr、J_IN、控制区 | `placement_report.json:provisional` 四项 | **P0** 尽快选出真实外形／封装。J_IN 暂定高度 10 mm，本身已吃满限高；强烈建议优先评估更低接口或把输入端子放到高度约束之外，不能假设现有占位可用 |
| QH/QL | 体尺寸已按 Q5A 数据手册最大值修订 | `land_pattern_provisional` 仍是占位焊盘，**不可制造**；需要按官方推荐焊盘图校对栅漏源与散热焊盘 |
| Cout | 15×470 µF、2.5 V、ESR 理想并联 0.20 mΩ、占位高度 1.9 mm | 候选电容实装最大高度／纹波电流降额应按原厂数据确认；2.5 V 对 50–54 V 输入空载及过冲应留可靠性余量；**PCB 分布 ESR/ESL** 不能被理想 0.20 mΩ 掩盖 |
| DRC=0 | `hardware/dcx_mech/drc.json:violations=[]`；若干检查被忽略 | 无 nets/tracks 的 DRC 不能证明连线、铜宽、电流分布和冷板可制造；仅表明该摆件文件未触发其启用规则下的报错 |

**新阶段核心建议：在 A6 全布线之前，先冻结输出 100 A 铜排/接点、15 只输出电容到 SR 的路径，并画出五只磁件的安装剖面。** 100 A × 0.15 mΩ 输出预算对应 **1.5 W** 损耗；布线需按实际电阻与热路径评估，不能仅凭 0 重叠决定“合理”。

## 3. CI 与项目可复现性：立刻修复，不以跳过测试假装通过

- **P0 软件阻塞**：机械摆件生成器依赖开发者绝对 Windows 路径（见 §0），导致 main CI 红，重复开发会看不到真实退化。
- **推荐方案**：将 KiCad 官方库 footprint 版本作为**可追溯的工程依赖**（本地 vendored / 版本固定的上游数据，核对再分发许可）或让生成器从环境变量／KiCad 官方安装目录定位；在 CI 中安装**匹配版本与库**。生成一致性测试仍应重新渲染并与提交的 `.kicad_pcb` 比较，不宜单纯删掉此测试。
- 将耗时且依赖 KiCad GUI／EDA 客户端的工作拆成明确的 CAD/机械验证 job；轻量 pytest 与 manifest 不应因为未说明的本机绝对路径失效。若只能暂时跳过，必须显式标为“依赖缺失、再生成未验证”，不能报告为完整再现成功。
- 复核生成文件 `drc.json` 的 ignored_checks；`missing_courtyard` 被忽略时，布局不能据此声称外形边界全部通过。
- PR #10 的 A1 验收必须是**真实 LCEDA 项目导出**与真实网表检查；不能只测 Python 生成的模拟期望结果。

**验收**：一次全新 GitHub Runner checkout 不含开发者私有路径，能成功再生 A5 成果并通过 `pytest`；CI 日志说明 KiCad 版本和 footprint 版本；如依赖不可取得则明确 FAIL 而不是静默 PASS。

## 4. 效率与器件物理：精度任务与制造任务分开

- 100 A 当前简化模型端口效率与 92.33% 工程损耗预算**不同核算边界**；所有结果均为 `SIM_MEASURED` 或 `ENG_ESTIMATE`，不允许作为连续硬件效率。
- 相位对齐的 133 周期闭合残差（周期平均）5ns **+0.32585 W**／2ns **+0.31392 W**，目标 ≤0.2 W，因此 `NOT_CLOSED`。
- 同一窗口输入—输出功率差变化 **+0.534 W**，列示损耗变化 **+0.625 W**；闭合残差相近并不代表每项损耗已收敛，两项可能相互抵消。Issue #6 下一步应对端口项和 SR/铜损/驱动项做逐项步长、能量方向、储能端点对照。
- 物理 Lr 故障峰值 84.02 / 104.17 A 来自**线性磁件模型**；三匝 ELP32 是可打样候选，约 1.444 mm 气隙仍需首件的 L(I)、气隙边缘热损耗及加工确认。
- 关键时序/控制和故障硬件测试尚未发生：`HW_MEASURED=0`。**Issue #6 不宜阻塞 A1 真实原理图、可行机械结构和控制板 PCB**；只要仿真发现器件超额定或失去保护能力，立即升级为投板阻塞。
