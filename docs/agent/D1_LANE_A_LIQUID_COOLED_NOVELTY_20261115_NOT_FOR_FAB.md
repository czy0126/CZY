# D1 论文差异化：48 V→2 V 薄型液冷超大电流 DCX（2026-11-15；研究模型，NOT_FOR_FAB）

> 用户新要求：①相比现有2024–2026已发表论文必须有**独立可测的技术长处**，而非只堆已有的侧接SR/PCB埋铜/冷板；②可以**牺牲部分效率换取更高的连续输出电流**，因后续有液冷；③尽量薄，便于冷板接触和局部内层铜绕组的散热。

**有意义的研究命题（均为待证假设）**：

- **N1 连续大电流能力**：在固定48→2V、电气包络相同、冷却输入功率/入口温度/最高铜+SR+磁芯温度相同条件，电磁—热—流体联动优化比“传统内层多并联+表面过孔汇流+普通下冷板”能否提高**30分钟热稳连续输出电流**；重点不是峰值超论文800A。
- **N2 电流共享与热点共同优化**：同一矩阵磁芯/相同输出电流/相同流阻/流量/频率下，若按内层交流损耗和气隙边缘场决定冷却流道及出线/层序，能否降低**各层Irms不平衡、Rac/Rdc与最高温度**；要分清冷却方案和绕组调形各自贡献。
- **N3 冷却型输出双极集电极**：通过并置的VOUT/PGND铜片/侧镀输出端子直接贴近每50A SR出口，避免全部600A依赖小孔跨层集流，测**真实4端热态输出两极电阻（含接触/铜/端子）**和EMI，比较同样工艺下纯PCB横向导出。**不能把0.8mm铜厚理想计算当成实物可实现。**

**预注册的研究成功阈值（不是已证明）**：N1 在相同热点温度上限/泵功/面积/器件条件下，热稳连续额定电流相对A基线**提高≥15%**；N2 在相同电流与泵功下，最高热点温度相对B基线**降低≥10 K**，且不能以显著增加铜损或压差来换虚假的温降；N3 在目标600A经真实四端法测得的**VOUT+PGND+接点总热态电阻≤20µΩ**。这些是为了淘汰缺少新意的设计而设的先验研究目标，不是保证达成或统计显著性证明；至少提供多件样品和重复热稳态测量，公开不确定度。

对照实验**固定**器件、相数、变比、磁材、输出电压、电流、冷却介质/泵耗、面积、环境及温度测点：
A 传统via-collected平面绕组 + 普通相同占地冷板；
B A改侧SR和对称输出双极端接；
C B采用电磁损耗热点匹配的密封薄型冷板、同泵耗；
D C同时优化绕组层序/出线/冷却回流。报告A→B、B→C和C→D的独立变化，而不是只比较A和D，避免虚假的“方法提升”。

## 2. 重新调整性能：同一工作点、允许更大损耗但不能放弃热预算

以 **500–600 A/2 V**为主要高密度研究对象。默认96%不是硬性条件，而采用**满载效率95%偏好，93%研究性底线**；若低于93%，必须论证电流/薄型化收益与水泵耗电是否抵消损耗增长。原始EC原理图的额定是否能承受这一级电流需要实测，不能直接从100A按比例缩小电阻负载。

**所有尺寸是CAD拟合及极限布局要求，不是已成功摆入必需器件的工程结构。** 即使E3达到4,767W/in³“仅电气”条件数学指标，若连铜芯、驱动、控制、必需电容、电气端子都放不进去便不成立；不允许把这些元件转移到“外部板”里欺骗体积。含冷板的计算只把**同等XY面积的2.5mm冷板**算入；横向接头/歧管/CDU体积需要在实物总成下另报，冷板压降及泵功耗另报。

**效率容忍度的实际含义（E3 600A）**：95%满载损耗63.16W；93%满载损耗90.32W；97%满载损耗37.11W。假设整个模块温度相对于冷却液升温目标50°C，仅用于算整体均匀热阻的上界，95%目标需要**总热路径≤0.792°C/W**，93%需要**≤0.554°C/W**。这并不是芯片结温/内层磁件热点的验收值；结温温差、芯损热点和冷却液流动换热仍需独立CFD/热像/原位探针。

**水侧温升并不等于芯片温升**：以纯水 `Cp=4180 J/kg/K`、`ρ=1 kg/L`、600A/95%时63.16W作为假设，1 LPM名义水温升约**0.91°C**、3 LPM约**0.30°C**；这是能量守恒而非证明冷却足够。若压降20kPa、泵效率25%，1 LPM理论外部电泵耗电约**1.33W**，3 LPM约**4.0W**，但实际压降/泵效率未知，且接头/歧管压损未加入。因此**3LPM指定接口在G3后置，但热接触面和无泄漏薄型冷板工艺从E1就设计**。

**双极总输出热态电阻是关键**：600A时若VOUT+PGND两极及端子合计20µΩ，输出铜耗**7.2W**；若50µΩ会到**18W**。对于各极长度5mm、宽20mm、100°C纯铜直导体的理想`ρL/A`：一层70µm铜两极合计约**161.9µΩ、58.3W**，两根各厚0.8mm的铜条合计约**14.2µΩ、5.1W**。均**没有算接触、焊盘扩展、发热不均、交流损耗**；说明单一普通PCB铜层不适合作为600A远端汇流段。侧边集电极必须用导热扩散与厚铜/铜片共同设计，并通过厂家装配与实际四端阻值验证。

## 3. 不再纠结“只有4mm”，采用能接冷板的真正薄型双面结构

**实际优先设计高度**：功率级含磁件、GaN/SR、驱动及铜端子 **≤5.5mm**；下方密闭铜/金属冷板先预留 **2.5mm**，完整装配高度（不计从侧边引出的水管直径）**挑战≤8mm**。这比把一个36层PCB硬塞进4mm更有制造意义，但依旧很激进；若厂家层叠/磁芯/灌封不允许，宁可把高度调整到9–10mm并重新计算同口径密度，不能缩短高压安全间距或隐瞒结构体积。

- **功率级上面**：低压SR以多单元侧向均匀分布，GaN半桥及门驱靠近输入侧、短Kelvin返回，24:1实际有效变比按半桥/整流连接与变压器串并极性验证。
- **PCB内部**：12–16层优先，薄层铜+分数匝/多窗口集成绕组，绕组铜、磁芯开槽、输出引出按`Maxwell L/Rac/Bsat`矩阵优化；不用小型PTH汇总600A。是否有足够实际匝数/窗口/绝缘待定。
- **功率级与冷板之间**：导热扩散铜面+有绝缘保障的TIM及实物压合；热量从SR、芯柱和内层绕组走最短可靠路径，**密封冷板不与带电PCB铜直接接触**。
- **薄型冷板内部**：按热源密度分区的并联微通道/导流脊、平行回流及柔性补偿，尽量使SR与磁件热点同时降温；入口/出口优先移到**板外侧向歧管**，防止垂直水嘴直接毁掉8mm高度。此时真正的冷板微通道尺寸、压降、渗漏边界、流量分配都待CFD与厂家验证。
- **输出端**：VOUT与PGND两片短而近邻的对称平板铜/侧壁导体接入负载，两个极性同时放热/分流/电阻检查，避免“100A有铜线、600A靠细过孔”的旧问题。

**安全底线**：液路必须与所有带电铜保持可靠绝缘，设计水路/电路的分离密封、机械压合、漏液检测和耐压。冷板一旦可能成为导电回流部件需单独隔离评估。不能把“PCB埋铜”理解成允许将水在裸露绕组中循环。
