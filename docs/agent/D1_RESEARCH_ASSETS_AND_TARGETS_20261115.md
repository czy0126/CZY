# 48 V→2 V 紧凑薄型 DCX 科研项目说明书｜R3.0

**更新：2026-11-15｜项目定位：科研实验、非商业交付｜状态：NOT_FOR_FAB / NOT_FOR_POWER_ON**
**唯一对象：紧凑薄型 48 V 输入、约 2 V 输出的固定比例 LLC/DCX 大电流电源。**
**当前首要交付：一套真正闭合、可编辑、可直接审阅的完整电路原理图，不是新冷板、另一套PCB或几张概念框图。**
仓库：[czy0126/CZY](https://github.com/czy0126/CZY)，电气参考 [PR #136](https://github.com/czy0126/CZY/pull/136)，紧凑模块 PCB [PR #137](https://github.com/czy0126/CZY/pull/137)，科研主议题 [Issue #138](https://github.com/czy0126/CZY/issues/138)。

## 0. 项目范围与文件纪律

本仓库中这条研发主线**只服务紧凑薄型 48→2V DCX**。其他尺寸级别、其他变比、千安级多单元砖式机械/冷却工程**不属于当前项目目标、必备资产、里程碑或交付BOM**。它们应在独立项目/仓库维护，不能继续合并其参数化几何、板级占位模型、CFD或文档到本紧凑模块分支。历史R2混入的其他架构内容在此版中正式废止；不删除、覆盖其他Agent正在修改的独立工作树，而是在本项目分支严格排除。

**唯一集成原则：** V5/G0给电气源图，V17 KiCad给可复用PCB布局与封装，两者不是同一块“已经验收的完整板”；其他独立板只在其真正设计的端口上连入，不把几个0-ERC结果叠加成整机合格。

## 1. P0：用户首先应看到的“成品电路”

下一位 Agent 必须先交付 **一个能用KiCad原生打开、含实际引脚与电气连接的统一顶层电路工程**，建议唯一目录：

`hardware/dcx_main/g2/compact_dcx_C0_integrated/`

验收文件（缺一项便不是“成品电路”）：

| 文件 | 不可省略的内容 |
|---|---|
| `compact_dcx_C0.kicad_pro/.kicad_sch` 及子页/符号库 | **唯一有意设计的顶层**，不能只是互不连接的V5/V6/V7/V8原理图 |
| `compact_dcx_C0.pdf` | KiCad原生导出，可清晰看到真实功率路径、各路驱动、保护及外部测试联锁接口 |
| `compact_dcx_C0.net` + 逐脚Ref/Pin/Net校验 | 真正导出网表与符号/物理封装逐脚对应，不能用全局网名“自动证明已通” |
| BOM + MPN/待选项/电气参数依据 | 关键开关、SR、驱动、Cin/Cr/Lr、磁件、输出储能、偏置、保护均有具体来源或显式PENDING |
| `C0_ELECTRICAL_ACCEPTANCE.md` + 原生ERC | 电气变比和极性、忽略检查逐项审计、风险、故障默认状态、仿真与实物验收边界 |

**必须连通的电路：** 48V输入/防护与Cin；QH/QL半桥和各自的本地VGS返回；Cr/Lr及真实磁件（可先选最小可信G0绕组，不要求立即做最终矩阵）；有正确DOT/变比推导、中心抽头/副边与整流极性的T1–T4候选和CT接口；八路SR真实门极与源端Kelvin连接；输出电容及VOUT/PGND实际回流；原副边隔离12V、UVLO、OC/故障锁存、软启动、D0默认OFF、急停和浮地GH−SW/HB−SW监测接口。

系统48→2V的等效直流电压比约24:1，**不等于每颗磁芯一定24:1匝比**；必须根据半桥/整流状态、原边串并与副边电流共享逐步推导。不能为了ERC0省略实际绕组、电容或真实偏置。R8 RUN过去是DNP，安全条件未成立不得自行激活。

可把物理尺寸很大的急停/隔离监测与实验供电实现为**外部台架治具**，而非强行塞进5.5mm功率级；但仍需在C0顶层提供真实插座、信号电平、返回线、联锁动作及默认OFF行为。用于完整电源功率密度比较时，必须清楚披露边界，不能把连续运行必需的功能隐藏在外部不计体积。

**P0审核通过≠上电许可。** 必须原生ERC可复算，无未解释的高风险错误、提供各层网表、驱动与保护的独立拓扑复核、至少一次可重复的电路级运行/异常关断模拟；上电还需要G0的磁件绝缘/硬件保护/现场安全验收。

| **E1** | **200A/400W** PCB内层绕组与高流铜互连研究单元 | 真正能制造的磁件+局部SR+两极铜件/端子CAD与热态四端电阻；现有A/B不等于可承载200A |

| **E3** | **600A/1200W** 连续；**95%偏好、93%研究性下限**；电气功率级高度**≤5.5mm**，密闭冷板约**2.5mm**，总高**≤8mm**挑战 | 全部必要器件可实际排布的PCB及磁件、Maxwell+CFD、30分钟热稳、局部热流与泵耗、故障测试。**极高风险目标，允许降低、调整和科学地记录失败** |

E3若能在30×25×5.5mm里真实装入完整电源，外加同投影面积2.5mm冷板，则仅功率级体积4.125cm³、含冷板包络6.000cm³，600A×2V条件功率密度约**4767 / 3277 W/in³**；这仅是**数学外形预算而非已设计成功**。1200W/95%总损耗约**63.16W**，93%约**90.32W**。双极VOUT+PGND连同接点总热态电阻挑战**≤20µΩ**，600A时约7.2W理想铜耗；真实接点/层间分流及最高温度需独立验证。

**研究创新点**不是“加上液冷”或“600A”本身；文献已有更大电流和液冷平面磁件。应通过A常规过孔汇流/B侧接SR短正负铜/C同泵功热源定制薄冷板/D绕组层序与冷板协同优化这四种对照，证明同热上限/冷却资源/面积条件下的持续输出电流与热点、铜损的可重复差异。试验假设：电流能力≥15%提升、热点≥10K降低、两极总热态电阻≤20µΩ，均为**待验证而非论文已得结论**。

## 4. 科研允许的缺陷 / 不可放宽的底线

**可以接受**非标准厚铜/铜片、手工装配、成本高、第一版效率偏低、未达到既定体积/电流、模型近似、未满足商用品MTBF/长期寿命/全部认证、有限的实验性器件替代；前提是用“已完成/仿真/未验证/失效原因”四列保留真实证据。

**不能接受**：无有效硬件限流与急停的高能量上电、失电仍可能误触发GaN/SR、液冷水路与带电铜无绝缘、缺真实磁件或输出回流却声称ERC/DRC0代表可上电、把电源必须存在的器件排除在体积之外、假称200/400/600A测试成功、编造Maxwell网格/真实波形。失败是科研结果，不是掩盖的错误。
