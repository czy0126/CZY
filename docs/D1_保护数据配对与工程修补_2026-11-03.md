## 2. 本轮直接修复的实际工程缺陷

### A. 主分支 CI 失败：SOA 来源哈希与 Git 换行符不一致

`main` 最近一次 Actions run `41583665858` **1 failed / 673 passed / 7 skipped**，失败点是 `test_the_committed_table_is_current`。逐项比对显示源文件字段数值没有新型别变更，SOA表中的7份来源JSON哈希仍为此前生成环境的值，与Linux checkout不同。

- `tools/protection_soa_table.py` 中来源文本以**规范化 LF 后的 SHA256**入档，使 Windows CRLF 与 Linux LF checkout 对同一内容得一致的可复验哈希；原有源内容的数值引用与窗口边界仍然不被改动。
- 重新同步 `design/v3/power_priority/protection_soa_table.json` 中所有11条记录的来源哈希。
- 新增跨操作系统换行符一致性回归测试。**不允许通过跳过pytest或删除原有哈希检查修复红CI。**

### B. 原 SOA 总表将 50 V 非配对候选隐式地放进同一性能排名

新增每次保护对照的 `paired_pre_fault`、`pre_fault_vout_delta_mv`、`paired_change_can_be_attributed_to_protection` 字段；`reached_declared_window` 和 `solver_prefix_only` 不再固定填写，而从原候选JSON的 `coverage` 重算。**50V四行A/B base/candidate现在一律不标配对，48V对照则需<1mV偏移且完整窗口。**

新回归测试专门要求这种“不能宣称因果”的差异保留。即使成本无限，也不以无效实验比较作为器件选型依据。

### C. 直接准备了两份尚未运行的 50 V 同结构对照 deck

`tools/make_paired_protection_controls.py` 根据**已运行的PROT-A和PROT-B源**各生成一份 `*_noclamp_control.cir`：
- 保留独立滤波、锁存、十个保护开关、负载、故障支路、`.tran`、50V所需 `cshunt=1e-15`；
- **只把 `PROT_KILL` 的动作阈值0.5V改为10V**，使 `V(inhib)` 在0–1V间不能闭合钳位，从而形成尽量接近候选数值结构、但不实际发挥保护钳位作用的对照；
- 此对照**故意不具有保护功能，绝不能作为硬件保护方案**。生成器与单测证明没有修改功率网表、控制与故障网络中的其他行；
- 对A/B分别运行真实LTspice到保存轴320µs，比较故障前相同35µs的Vout均值：配对要求候选与自己对应的no-clamp控制差**≤1mV**，二者完整求解，并重算Lr峰、SR峰和八只I²t。若仍无法配对，不应将50V下降幅度用于规格书。

这些是准备好的实验输入，不是宣称已经得到了新对照数据。

**补记（同日稍后运行，不属于本 PR 的文字范围）**：四份控制都跑了，结论是
`noclamp` 这一族**不能**满足配对。它确实跑满 320 µs，但故障前 `V(out)` 仍比候选低
**13.2 mV（A）/ 17.5 mV（B）**——改一个模型参数就换了一条求解器路径；开关本身是
电学开路的（`sim/v3/prot_switch_leak_probe.cir` 实测 `Vt=.5` 与 `Vt=10` 的漏流都是
**1.001e-9 A**），所以差异不是"钳位没关"。

因此追加了第二族 `_thrmute_control.cir`：开关模型**逐字节不变**，只把 `Bprot` 的触发
常数 1.0/1.8 V 抬到 100 V。它做到了**精确配对**（故障前差 **0.000000 mV**，触发前
961 298 / 824 449 个采样点逐位相同），但**求解器塌缩**：A 停在 **250.151 µs**、
B 停在 **254.980 µs**，两窗口都不完整。**PROT-03 的两条判据仍不能同时满足**：
配对成立时窗口不完整，窗口完整时配对不成立。记录在
`design/v3/power_priority/protection_candidate_50v_120a_prot_{a,b}_paired.json`
（截断、配对）与 `..._noclamp_paired.json`（完整、非配对），逐项说明见
`PROT02_独立故障锁存候选对照_2026-11-03.md` §5.6。

## 3. 不受成本约束时，优先增加哪些实质性能

- **保护**：优先将已在48V行为模型上观察到显著应力下降的PROT-B快速支路，转换为**可实际采购和布线的独立比较器+可锁存控制+十门默认关断路径**；要求软启动屏蔽不会让启动电流锁死，又不能让屏蔽期间故障完全失去保护。须核查实际比较器速度、噪声误触发、UVLO重启、栅压控制、驱动能力及八只FET的真实瞬态SOA。
- **磁件**：依照已发布 `high_margin_design_gate.json`，提高有效横截面或采用低矮定制/分布气隙Lr；3匝建议RFQ最小`Amin≥200 mm²`。它是基于故障峰值×1.2、电感偏差×1.1和`B≤0.8Bsat`的**询样目标**，必须经实际`L(I)`、气隙边缘损耗和100°C B-H核验。
- **Cout**：不为省件数使用15只2.5V的模型候选直接投板；供应商目标为≥4V，优先6.3V，真实≥7.05mF、≥84.09Arms（50V/120A过载点实测56.06A×1.5；额定100A点是52.48A的四路重建，低6.8%），以及包含铜/焊点的总ESR≤0.10mΩ，真实高度/过冲/温度/频率数据必须核验。
- **CAD/磁件端子**：优先买定制磁件首件、可验证pad图、真实器件/封装、低阻铜排和正规EDA审查时间，不应继续用新报告替代带网络PCB。允许增加PCB平面面积和铜材料，仍不得超高。
