# 48V→约2V 薄型大电流 DCX 核心路线图
更新：2026-10-31。用户确认固定变比，允许我们选择可行指标。状态：设计启动，非制造发布。

## 1. 第一版要做成什么
- 标称48V，标称电压变比24:1，输出约2V；不承诺输入变化时保持2.000V，也不做恒流源。
- 100A连续/200W为设计目标，先10A验证，再25/50/75/100A。连续能力必须以热稳定实测证明，不能用短时仿真或峰值额定替代。
- 初评输入46~50V（标称变比对应理想输出1.917~2.083V），最终输出范围包含负载压降、频偏与器差；启动由0V输入和外供偏置情形单独验证。
- 总高含PCB、磁芯、元件≤10mm为机械目标，面积先服从可制造性；散热允许外部风冷。高度是否包含外壳/散热附件应在机械图中明确，不能隐藏附件。
- 外供控制偏置，优先12V，再按芯片要求派生5V/3.3V；如需原副边不同参考的偏置，画清参考地和电源接口。辅助电源不是12V中间功率级。
- 首板不追求GPU供电动态、极致效率/功率密度或大范围输入。效率如实计入原副边门驱及外部偏置消耗。

## 2. 主路线及一次性裁决
优先单级半桥固定频率LLC DCX → 平面变压器阵列 → 分布式同步整流 → 并联输出电容和低阻端子。候选四个原边串联、各副边整流后并联的3:1:1中心抽头磁件。每个原边约分得总激励的四分之一，等效原边对半副边匝比12:1，在谐振附近半桥关系Vo≈Vin/(2×12)。此式忽略损耗且依赖实际整流连接，必须用逐节点原理图核对。
四个磁件不等于四相独立变换器。100A均分时每单元平均输出25A，但绕组/SR有效值和峰值必须按实际电流波形算，不能直接拿25A选器件。
频率先探索200~300kHz，再依据磁芯损耗、匝数、SR延迟和驱动损耗固定一个值；不把旧200kHz参数当结论。固定变比不代表固定开关脉冲即可上电：仍须死区、受控启动、合适SR导通区间和停机。
一次比较DPx/堆叠、MASC及全桥倍流，仅当主案无法满足磁件高度、可采购性、损耗或可靠SR换流时换案。不给四条路线长期并行维护。

## 4. 控制电路瘦身规则
固定频率设定＋互补死区＋原边门驱＋软启动＋SR控制＋最小电流停机为第一版边界。UCC25600可作为设频控制候选，但需核对启动频率、最高/最低频率、输出电平与驱动器输入兼容；不能直接把GD接MOS高侧。专用SR控制器同样必须检查2V输出下的检测工作条件，允许外供偏置。
删除旧项目独立基准健康监控、复杂资格链、多级复位、通信、远程监测、自动重试策略。暂缓EMI认证、输入热插拔优化、全故障矩阵和冗余保护。保留芯片UVLO、默认关断、基本死区、限流电源配合的硬件过流停机和可操作停机口；这是让首样可运行所需电路，而不是扩张保护项目。
不把热设计整体延期：100A时1mΩ就是10W，输出电阻与温升直接决定能否运行。测试源的限流不能取代桥内防直通时序。

## 5. 器件和磁件如何真正定下来
原边MOS按最高输入加振铃裕量选耐压，优先评估80/100V级硅MOS；SR从低压低阻MOS评估，耐压按实际中心抽头端电压与振铃计算，不按2V输出选。比较热态Rds(on)、Qg/Qoss、门驱能力与封装热阻后定型号。谐振电容须核RMS电流/电压及介质，输出MLCC按偏压后容量计。
磁件需要：磁芯精确料号与材料、Ae/Ve/窗口/外形、每绕组匝数和极性、每层铜厚与布局、过孔与端子、绝缘层厚度、装配方向、公差、每磁件目标Lm与漏感、AL与气隙、磁通和铜/磁损耗及散热方式。气隙根据磁路和厂家AL曲线确定，不能将简单气隙公式等同加工保证。
将漏感计入总Lr一次；串联原边的励磁支路要按真实模型折算，禁止混用总Lm和单元Lm。fr=1/(2π√(LrCr))只是谐振频率校验，不证明ZVS、负载点或软启动成功。原边串联均压、副边均流要加入公差验证。
首样可用可加工薄铜箔/独立平面磁件，但必须保留同样的电气连接及可测量参数；磁件换工艺后复算高度与寄生。采购前检查磁芯供应、加工公差和实际价格，不编造库存。

## 6. PCB优先项
先放磁芯、SR和输出端子，再安排最短输出电流路径，随后原边桥/谐振腔和控制。功率板与外置控制供电接口分清；驱动回路不得靠长排线。
叠层由绕组和电流回路决定，先评估标准4/6层与2/3oz可制造范围，不机械抄论文的埋孔和极薄复杂叠层。磁件窗口、安装压紧、铜箔引出需要机械图。用阻值/铜损和温升论证100A，不仅凭走线宽度经验。
SR检测采用Kelvin引线；开关节点与检测/振荡/采样隔离。为VGS/VDS、谐振电流、磁件温度及四路均流留测试点；预留可选阻尼位置但不任意堆吸收件。制造包必须对应同一版原理图、器件封装和磁件图。
