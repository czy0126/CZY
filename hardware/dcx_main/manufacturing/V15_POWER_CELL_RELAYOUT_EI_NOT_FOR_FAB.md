# V15 EI 功率单元级原生 PCB 重构：T4 首个真实实施

**阶段状态：V15 WIP / NOT_FOR_FAB，严禁作为实板发板依据。**

## 已经执行的原生 PCB 修改

使用原有嘉立创可见 GUI，把真实 V14 复制为独立 V15 PCB，V15 UUID **9b212da9a255a2af**。参考 PCB1 UUID 2f6fa2d508d3f9a8、V14 UUID 8c496410b2877d3c 均被保留；没有新开嘉立创窗口。

已经通过原生 API 将 SR4A、SR4B、U6、C10、C108、R26、R27、R34、R35 **全部9个器件沿Y轴上移30mm**，并同步修改 **18段实际本地信号铜线、2个局部过孔**，包括 GA4/GB4、SEC4_A/B、REG4、VD4_A、局部PGND与VCC12_S。保留 C10 真实底面180°放置。没有伪造网表或短接原副边。

实际 T4 EI磁芯中心(134,20mm)到SR4A中心由 **62.290mm降至32.558mm（缩短47.7%）**；磁芯槽下缘到SR4A的SEC功率焊盘由 **48.179mm降为18.179mm**。

预检查对源锁定的静态异网络铜箔做了 **45,667次**间距测试，要求至少0.19mm，磁芯NPTH槽另加0.5mm避让，均通过。实际PCB仍保持149器件/423焊盘/484走线/104过孔、12条内部磁芯开槽。原生独立DRC从V14 **111 Connection** 变为V15 **112 Connection**，未返回网表错误和新增物理错误。

**DRC增加的1个连接错误不是已修复：** 老有源器件到远端输出/PGND汇流的连接没有跟随整个功率单元搬迁。此类铜线必须按100A回路重新设计，而不是重新补上长而窄的走线。

**保存的真正原生V15项目**：hardware/dcx_main/g2/dcx_main_board_g2_V15_T4_POWER_CELL_UP30MM_WIP_NOT_FOR_FAB.eprj2；SHA256为 **02d59c63c747678849466cc62565c1522bc50586a7dadc06b0829016ab601e75**。原V14另存原生项目SHA256 **7dd77910bcf7ff3fd0e2be1e4194439a22189aaf353f105bbe1280c104e4f6fc** 保持不变。最新项目容器共有**三个独立PCB图纸**，不是三个独立嘉立创窗口。

## 对其余三组功率单元的真实冲突分析

在真实V15上继续检查单元整组平移而非单器件随意摆放：

- **T1**：接近磁芯时会撞上 Lr 原位置和谐振铜线。沿Y轴统一上移17mm的焊盘布线几何测试可以通过，但距磁芯仍偏大；更激进的位移必须先重定位Lr并按实际磁芯包体/公差检查。
- **T2**：QH/QL/U2主功率与驱动单元、C5/C101等占据磁芯下侧通道。若未先重排半桥，会发生大量铜线、过孔、焊盘冲突；不能先盲目把SR2移动进去。
- **T3**：Cin及SS/CS2/OCD保护采样网络挡住近磁芯布局。部分平移候选只在焊盘铜线检查中通过，但移动后的驱动器会和Cin实体包体高度重叠，所以必须先把Cin搬到半桥热环附近。
- **T4**：已经真实实现30mm功率单元平移；仍须完成100A回流和输出电容的重新布线，验证真实12层物理叠层与两侧冷板机械干涉。

## 下阶段依次处理

1. 先按高di/dt热环和实际QH/QL封装几何，把 **Cin、QH/QL、Cr、Lr、CT** 组织为同一个紧凑主谐振功率单元；同时完成封装实体外形/3D与避槽检查。
2. 再把 T1、T3、T2 对称的9器件SR功率单元靠近磁芯，每次连同本地18根信号线/2个过孔搬迁，独立验证没有新增异网络短路，保存中间版本。
3. 全部单元位置稳定后重新设计 **3:1:1多层原副边绕组、VOUT/PGND 100A电流路径、输出旁路与驱动返回**，最后收敛剩余111项原始DRC（V15当前112项）。
4. 软件仍使用 JLCPCB Capability(Two Layers Board) 规则，真实设计有12个激活铜层，因此不能声称当前无物理错误就满足多层制造规范；磁件厂家端子/DOT、Maxwell磁芯仿真、隔离间距、热/EMI测试及16mm冷板仍待确认。

TI与Infineon谐振变换器设计资料均强调功率正向与回流路径邻近、高频热环面积、电气磁件寄生和SR/门极环路布局；这些是本阶段的设计准则，而不是已经通过EMC的证明。
