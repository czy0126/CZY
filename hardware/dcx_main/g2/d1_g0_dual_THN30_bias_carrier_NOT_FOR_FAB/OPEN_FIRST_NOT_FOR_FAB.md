# D1 双路实际 OEM Traco THN30-4812 48V→两路隔离12V子板（NOT_FOR_FAB）

本目录打开同名 kicad_pro，原生 2层 PCB 包含两只 KiCad官方 Converter_DCDC_TRACO_THN30-xxxx_THT 6PIN 通孔封装，实测与 Traco 官方2024数据手册针脚位置和功能对应。U1输出VCC12参考PGND，U2输出VCC12_S参考SR_SOURCE_RETURN；两路48V输入各自经过F1/F2预留2A慢断熔断器，含2个输入1uF 100V及每路2个22uF 25V输出电容候选，PCB原生DRC=0未连接=0，来自独立设计电路图的34 pin原生ERC=0。

【重要】此处实际设计的是单独供电 *daughterboard*，不是给已存在的G0 V5主板强行塞入两块25.4x25.4模块；未来通过 J_P→J_BIAS_P 和 J_S→J_BIAS_S 各2线连接，不允许交叉回流。实际系统连线/绝缘/接头极性和保持时间未签核。

【电源与硬件安全】THN30 Remote引脚留NC，厂家定义开路=模块自动ON，故此电源子板不是安全关断装置；它须在主功率48V断能器前接入，以便急停时保留门极关断偏置。即使子板本身有熔断器，也没有真实48V主功率急停断能器、硬件失偏置/UVLO和高侧VGS监测。不能因为子板可实现隔离12V而允许主48V功率回路上电。

F1/F2只是1812封装的2A slow临时选择，额定DC分断能力、I²t与输入上电涌流没有OEM签核；MaiXu 5mm端子真实型号、两个12V输出的接线方向与防反插尚未证实。输出22uF/25V X7R 的实际直流偏压有效电容、输入浪涌（官方建议220uF 100V方案）、EMC滤波、器件发热和机械隔离/爬电仍须验证，**禁止制造或直接上电**。
