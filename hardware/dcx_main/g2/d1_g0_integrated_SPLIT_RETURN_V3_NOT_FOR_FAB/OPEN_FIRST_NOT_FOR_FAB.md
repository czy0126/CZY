打开同名前缀 .kicad_pro。本次实际修改129个输出整流/去耦/端子焊盘、181个原PGND副边走线或过孔、6块副边地铜区；原横跨全板的 In1.Cu PGND 改为原副边分割铜区，补 T4 初级 PGND 回流走廊。 R8 启动电阻仅有真实焊盘与走线但为 DNP，禁止自动开机。
