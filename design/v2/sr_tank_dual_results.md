## 1 为什么还要一个台架

换流台（`comm_v3/sr_commutation_v3_g0.cir`）用受迫正弦激励产生反向电流，它的 `di/dt = 2πfI`
是激励源的属性，不是谐振腔的属性；“1.647 mV/A”的漏极峰斜率也是这条正弦的产物。审核 P1 要求
“用有真实能量交换的双 SR 谐振台架验证实际 di/dt，再决定是否需要偏置”。

本台把 `startup_ct.cir` 的真实功率级（4 段串联原边、4 组并联副边、Lr/Cr/Lp、CT 采样链、
UCC25600 行为）原样保留，只把四组 SR 换成真实器件模型 + 时序模型。反向电流来自 Lr/Cr 经变
压器漏感的真实能量交换，所以 di/dt、反向电荷、双路重叠电流都是这台谐振腔自己产生的。

## 2 台架构成

| 部件 | 用的是什么 | 性质 |
|---|---|---|
| 原边半桥、Lr/Cr/Lp、变压器 | 与 `startup_ct.cir` 逐行相同 | 理想开关 + 估计寄生 |
| SR 器件 | `SR_DEVICE` = BSC010N04LS6 行为替身（`sr_device_v3.lib`） | 标定到手册曲线；Ld/Ls 为估计值 |
| SR 时序 | `sr_timing_v3_3.lib`，`CGATE=0 CPIN=100p` | UCC24624 数字时序替身，typ 阈值 |
| 栅极驱动 | 器件内部 `Cgs 5.1 nF + 非线性 Cgd` + 封装 LG 2.5 nH | 无独立的 6.7 nF 替代电容 |
| 负载 | 20 mΩ | 1.664 V → 83.2 A，138.5 W（**部分负载**，非 200 W 设计点） |

`PGD=0`：0 Ω / 固定 10.9 V 栅压基线，正是审核要求保留的默认。`Roffset`（VSS 偏置）为 0 Ω。

## 3 电流符号约定（实测，不是假设）

在 `startup_ct.raw` 与本源上实测：

```
I(VSa1) < 0  正流  （绕组 -> SR -> 地 -> 负载 -> 绕组），且 V(a1) = I*RdsOn < 0
I(VSa1) > 0  反向  （电流从地倒灌回绕组，而沟道尚未关断）
V(a1)        就是 VDS（源极接 sgnd）
```

这个约定决定了所有积分式的符号：反向电荷是 `∫max(0, +I)`，正向电荷是 `∫max(0, -I)`。
用反了这个台架会量出“反向电流 30 A”。

## 4 结果之前：v3_2 在真实谐振腔上会截断 SR 导通

这是本节最重要的发现，也是必须先记录的原因。

### 4.1 现象（同网表单变量对照）

`sim/v2/sr_tank_dual_v32.cir` 与主台 `sr_tank_dual_v33.cir` 的**非注释行只有一行不同**——`.include`
的模型文件。功率级、器件、`.ic V(out)=2`、500 µs 时长、`.meas` 窗口全部相同。同一窗口
（468.86–496.90 µs，8 周期平均）：

| 量 | v3_2 对照台 | v3_3 主台 | 比 |
|---|---:|---:|---:|
| Vout | 1.4752 V | 1.6648 V | **−0.190 V** |
| 周期 | 3.5048 µs（3.434–3.587） | 3.5156 µs（3.513–3.518） | 拍频 |
| EBD（体二极管） | 10.860 µJ | 1.289 µJ | **8.4×** |
| ECH（沟道） | 0.786 µJ | 1.045 µJ | 0.75× |
| 沟道占 SR 能量 | **6.7%** | **44.8%** | — |
| 单管损耗 @ fsw | 11.65 µJ × 285.3 kHz = **3.32 W** | 2.334 µJ × 284.4 kHz = **0.664 W** | **5.0×** |
| QREV a | 367 nC（194–832） | 316.5 nC（301–330） | +16%，峰峰散布 174% vs 9% |
| QFWD a | 31.96 µC（21.9–46.8） | 37.01 µC（37.00–37.04） | −14%，峰峰散布 78% vs 0.18% |
| IREV_PK | 4.61 A（3.99–5.52） | 5.135 A（5.07–5.19） | — |
| dI/dt | 0.147–0.309 A/ns | 0.041–0.076 A/ns | 2–7× |
| QOVL_ON | 0 | 0 | — |

发现它的最初证据是 1.5 ms 长跑 `sr_tank_dual.cir`（v3_2）：Vout 1.492 V、纹波 73.7 mV、
周期 3.602–3.914 µs 同样在拍频，EBD 10.31 µJ / ECH 0.571 µJ（沟道占 5.2%）。两处结论一致：
**沟道只承担个位数百分比的整流能量，其余全部走体二极管——SR 基本没在工作。**

差异不是数值噪声：输出低 0.19 V、损耗高 5 倍、正向电荷逐周期峰峰摆动 78%（主台 0.18%），而对照台只在拍频。

### 4.2 机理

v3_2 的关断比较器（`Btoff toff S`，行 108）在 475 ns 导通消隐（BON）结束后，**只要漏极出现过
一次** `V(D) > OFFTH`（+10.5 mV）就锁存 `toff = −1m` 并关断栅极，此后不再复判。

真实器件在导通期间不是一条平直的 `I·RdsOn`：SR_DEVICE 的 Coss ≈ 5.7 nF（1.5 V 时）与封装
0.3/0.8 nH、回路电感组成 ~44 MHz 的振铃，在 30–48 A 的正流上叠加 ±100 mV。于是：

```
导通开始 → 475 ns 消隐结束 → 振铃峰越过 +10.5 mV → 立即锁存关断 → 栅极落下
```

实测栅极最高电平的持续时间：对照台 **524–1453 ns（均值 754 ns）**，主台稳定在 **1455 ns**
（1454–1455）。最小值 524 ns 恰好是 BON 475 ns + TOFF 23 ns 加几个采样步长；最大值 1453 ns 说明
有些周期根本没被振铃触发，均值 754 ns 正是这两类周期混合的结果。

比较器把“振铃”读成了“漏极电压已上升、电流已反向”。

### 4.3 单变量归因

`sim/v2/sr_tank_dual_v2timing.cir` 与 v33 主台**只差一个变量**：时序状态机换回旧 v2
（`sr_timing_v2_pin100p.lib`，即 v2 逐字复制、仅把 6.7 nF 集总栅容换成 100 pF 引脚容）。
功率级、SR_DEVICE、PGD=0、`.ic`、`.meas` 窗口全部相同。

v2 的关断计时器在漏极回到 OFFTH 以下时以 1 ns 时间常数衰减，而不是锁存，所以它撑满 1454 ns。
结果 v2 与 v3_3 在**每一个量**上吻合（§5.3）——缺陷因此归属关断比较器，而不是栅极负载、器件
模型或台架本身。这也排除了“台架不收敛”的解释：同一台架、同一器件，换状态机就好。

### 4.4 修正（`sr_timing_v3_3.lib`）

与 v3_2 逐行相同，只有一行不同：

```diff
-Btoff toff S I=if(V(Q,S)>.5,if(V(age,S)>BON*1e6,if(V(D,S)>OFFTH,if(V(toff,S)<10,-1m,0),if(V(toff,S)>1e-4,if(V(toff,S)<10,-1m,0),V(toff,S))),V(toff,S)),V(toff,S))
+Btoff toff S I=if(V(Q,S)>.5,if(V(age,S)>BON*1e6,if(V(D,S)>OFFTH,if(V(toff,S)<10,-1m,0),V(toff,S)),V(toff,S)),V(toff,S))
```

删除的是“计时器未启动时锁存 −1m”的分支，即 v2 语义：OFFTH 反偏必须**持续** TOFF 才关断，
单次振铃峰不再触发。v3_2 原样保留（它是 2026-10-31 审核时点的快照），但**不得从中取 SR 导通
数字**。

## 6 按验收标准逐条回答

### 6.1 反向峰值 / 反向电荷

- QREV = **316.5 nC/周期/器件**；IREV_PK = **5.14 A**。
- 阈值来自 `SR反向电流验收判据_初稿.md` 的损耗预算，但必须重算频率：该稿用 200 kHz / Vf 0.7 V
  得 0.89 µC；本源是 284.4 kHz，`Vf = 0.78 V`（SR_DEVICE 体二极管在 48 A 的实测压降）：

```
Pbudget(0.5%) = 0.5% * 200 W / 8 = 125 mW/器件
Qrev_limit    = 125 mW / (0.78 V * 284.4 kHz) = 0.563 uC
实测 0.317 uC = 预算的 56%
Pbd           = 0.78 * 0.317 uC * 284.4 kHz = 70 mW/器件（8 只合计 0.56 W）
```

- 用该稿原参数（200 kHz / 0.7 V）则为 0.628 µC 上限，实测 50%。
- 反向峰值 5.14 A 对 12.5 A（50 A 额定的 25%）护栏的裕量是 **2.4×**。
- 该稿把 `Vf*Qrev` 当作上界；实测反向电荷 **100% 落在栅极关闭之后**（§6.5），所以这里
  `Pbd = 70 mW` 就是实际体二极管损耗，而不是保守估计。
- **注意负载点**：本台 83.2 A / 138.5 W，不是 200 W。反向电荷随负载近似线性，按 200 W 外推
  ≈ 0.46 µC，仍在 0.563 µC 以内——但这是外推，不是测量，未计入证据。

### 6.2 正向整流

- QFWD = 37.0 µC/周期 → 全周期平均 10.53 A/器件。每对两管合计 2 × 10.53 = 21.05 A，
  4 对 = 84.2 A，与实测 83.2 A 差 1.2%（差值来自死区续流与输出电容的分配）。
- 正向峰值 30.1 A，是全周期平均值 10.53 A 的 2.86 倍。器件只在半个周期里导通，
  所以对**自身导通段**的平均约 22 A、波形因数 1.36——2.86 是相对全周期平均的比值，
  不是异常。
- 沟道承担 44.8% 的 SR 能量，其余是死区续流的体二极管段（这是本拓扑的**正常路径**）。

### 6.3 双路重叠电流和能量：门压测试不够，电流测试也不够

审核说“不能只用门压重叠判断直通”。本台的数字把这句话量化了：

| 判据 | 读数 | 会得出什么结论 |
|---|---|---|
| 门压重叠 `OVL_GATE = max(Vga>2 ∧ Vgb>2)` | **恒为 0** | “没有直通”——但它在 v3_2 那个 SR 基本不导通的运行里同样是 0，因此在本台的所有运行里都不携带信息 |
| 电流重叠 `QOVL` 合计 | 446 nC/周期 | “有 446 nC 直通”——但这是错的 |
| 按门状态拆分 `QOVL_ON` | **0** | 真正的导通重叠（两管栅极同时开）不存在 |
| `QOVL_OFF` + `QOVL_MIXED` | 112.5 + 333.8 nC | 死区续流与交接，是正常的换流路径 |

`QOVL_ON` 与 `EOVL_ON` 在 v3_2（栅极占周期 17.9%）、v2（37.9%）、v3_3（37.9%）三种运行里
**全部为 0**。
结论：两条判据必须同时看，且电流判据必须按栅极状态拆分——只报合计会把正常续流误判成故障，
只报门压则给出一个永远为 0、不携带信息的读数。

### 6.4 阈值由器件应力/损耗预算确定

| 量 | 实测 | 阈值 | 来源 | 判定 |
|---|---:|---:|---|---|
| QREV | 0.317 µC | 0.563 µC | 0.5% × 200 W / 8，Vf 0.78 V，284.4 kHz | **通过（56%）** |
| IREV_PK | 5.14 A | 12.5 A | 额定 50 A 的 25% | **通过（41%）** |
| QOVL_ON | 0 | 0 | 导通重叠不容忍 | **通过** |
| 单管 SR 损耗 | 0.664 W | — | 8 只 5.31 W，占 138.5 W 的 3.8% | 信息项 |

### 6.5 di/dt 与 Roffset 决定

P1 要求先量真实 di/dt 再决定是否需要偏置。实测 0.0405–0.0764 A/ns（均值 0.051），量级温和：

- 即便栅极恰好在过零瞬间才开始关断（实际提前了 ~105 ns），TOFF=23 ns 内电流也只反向
  `0.051 A/ns × 23 ns ≈ 1.2 A`（最陡周期 1.8 A）；
- QREV 只用到预算的 56%，IREV_PK 只用到护栏的 41%；
- 也就是说，**没有需要偏置去弥补的裕量缺口**。

更直接的论据是**量级归属**（实测，不是手算）：把 QREV 按栅极状态拆分，**100% 的反向电荷发生在
栅极低于 2 V 之后**。逐周期看，栅极在电流过零前 **103–108 ns** 就已完全落下（过零时 Vga ≈ −0.07 V）：

```
栅极关断（过零前 ~105 ns）→ 正流经体二极管续流 → 过零 → 反向电流仍走体二极管 → 谐振腔拉回
沟道对 QREV 的贡献 = 0 nC
```

SR 时序只能改变“提前多少关断”。当前已留 ~105 ns 余量：再提前只让更多正流走体二极管
（EBD 1.289 µJ 里已有这一段），再推迟才开始引入沟道反向电流。Roffset 在这个平台上既改善不了
一个只占预算 56% 的量，也不是它的瓶颈——反向峰 5.14 A 出现在死区续流段，时序够不到。

因此按“0 Ω 基线优先”保持现状：`Roffset = 0 Ω`，调试焊盘保留，`sr_timing_v3_roff.lib`
不进基线。若后续角点（高低温、40 A 以上角点、CT 滤波改变后的相位）显示反向电荷逼近上限，
再以本表的 di/dt 为基准做必要的 Roffset 对照——而不是现在做一轮没有驱动因素的扫描。

## 9 未闭环

- **负载点**：本台 138.5 W。200 W 点的 QREV 是外推值，需要把 `RL` 调到 12.6 mΩ 重跑一次
  才能进证据（角点表里补这一行即可，不必新增报告）。
- **驱动边沿**：与 g0 台同一问题，栅沿仍未对齐手册 23/35 ns（`gate_load_calibration.md` §4），
  它决定 TOFF 的绝对刻度，因此决定 QREV 的绝对值。
- **器件模型**：Ld/Ls 是估计值；本台的 44 MHz 振铃频率与幅度直接取决于它们，而振铃正是 §4
  缺陷的触发条件。真实封装下是否同样触发，未闭环——但这不影响 v3_3（它不再对单次振铃响应）。
- **Roffset 对照**：本台判定“不必要”。若未来角点逼近上限，按 §6.5 的条件触发，不做预扫描。
- **PRE 在运行时被清零**的路径（`Bviol` 锁存）仍未覆盖；本台只走了正常上电时序。
