# SR 反向电流验收判据（第三轮修订）

日期 2026-10-31。状态：**REVISED_DRAFT**。本文取代同日初稿：初稿 §3 的替身表作废，
§6 的四条实测结论撤回。第三轮只做一件事——把"反向电荷 → 损耗"的错误归属换成
**内部支路能量账本**，并用它重写判据。

## 0 修订摘要（先读）

保留：`Qrev` 作为**比较指标**（趋势、均流、版本对比）；峰值护栏作为**筛查值**。二者都不再单独充当通过判据。

## 1 端口量与支路量

| 量 | 能证明 | 不能证明 |
|---|---|---|
| `Qrev = ∫Irev dt`（端口） | 反向电荷总量、版本趋势、四路均流 | 损耗归属；其中多少走沟道/二极管/电容 |
| `e_port_ds = ∫Vds·Ids dt` | 器件两端净输入能量 | **热**——非稳态窗口含 ΔE_stored |
| 支路账本（§2.1） | 沟道、体二极管、Rg 的耗散；C/L 的储能变化 | 封装外回路、辐射、磁性件损耗 |

初稿的核心错误就是把第一行直接当成第三行。三者必须在同一窗口、同一符号约定下同时给出。

## 2 判据

### 2.1 能量恒等式（窗口闭合）

对单器件、任一窗口：

```
e_port_ds + e_gate_pin = e_channel + e_bodydiode + e_Rg
                         + ΣΔE(Cds,Cgd,Cgs,Ld,Ls,Lg) + residual
```

- 残差判据：`|residual| / |e_port_ds| < 0.5 %`（284.4 kHz 实测 0.048 %）。
- 非稳态窗口必须单列 `ΣΔE`，**端口净输入不得称为热**。
- 反应性支路只能做**区间一次积分**（边到边），不能按周期求和后当功率。

### 2.2 两级预算

1. **总 SR 导通预算**（设计选择）：`P_SR_total ≤ x_total · Pout / 8`。
2. **反向相关预算**：只对体二极管支路的耗散定价：
   `P_rev = (e_bodydiode_fwd + |e_bodydiode_rev|) · fsw`（保守：反向段按耗散计）。
3. `Qrev` **不进入**上述任何公式；它只用于比较和均流筛查。

预算数值是设计选择，不是器件规格。任何签核必须写明 `x_total`、`x_rev`、温度和负载点。

### 2.3 为什么反向段取绝对值

`SR_DEVICE` 的体二极管用 TT 电荷模型。实测反向恢复段 `e_bodydiode_rev = −0.142 µJ/周期`：
模型把正向存储的电荷在反向段**回馈**给电路。真实器件的反向恢复以耗散为主，因此：

- 报"模型值"时保留负号并注明是模型行为；
- 报"验收值"时取 `+0.142 µJ`（保守上界）。

两个数都给，禁止只挑小的那个。

## 3 初稿 §3 的 v2 替身表（作废）

作废理由：固定 `Ron=1.5 mΩ`、无 Coss、无封装电感、且把 `Vf·Qrev` 当损耗。该表
（0.816 / 0.571 / 0.978 / 0.706 / 1.154 / 0.855 µC 等）降为**历史层**，不得再作证据引用。
这同时兑现了初稿 §5 自己写下的作废条件。

## 4 峰值电流护栏（临时）

`12.5 A = 25 % × 50 A` 是首版 EMI/应力**设计选择**，不是 SOA 推导值。真实 SOA 需要：
器件 Tj、脉宽、重复率、Rth(j-c)、封装与回路寄生。当前只把它当筛查线；设计点实测峰值
见 `design/v2/第三轮_测量口径与能量账本_2026-10-31.md` 的汇总表。

## 5 284.4 kHz 软启动快照的分支账本（实测）

证据：`sim/v2/sr_tank_dual_v33_internal.raw`（450–500 µs，8 周期），
`design/v2/round3_energy_ledger_284k.json`。窗口残差 0.048 %。

这个频率是**软启动快照**：由模型频率律 eq (2) 反推 `V_SS ≈ 1.408 V`，与
`Css=10 nF`、`5 µA` 的解析充电值 1.416 V 一致——不是额定稳态。

| 支路 | µJ/周期/器件 | mW/器件 | 8 只合计 mW |
|---|---:|---:|---:|
| 沟道 | 0.9361 | 266.3 | 2130 |
| 体二极管（合计） | 1.3727 | 390.4 | 3123 |
| — 死区正向 | 1.5148 | 430.9 | — |
| — 反向恢复（模型回馈） | −0.1421 | −40.4 | — |
| 栅极电阻 Rg | 0.1136 | 32.3 | 258 |
| **合计耗散** | **2.4223** | **689.0** | **5512** |
| 栅极供电（含 100 pF 正则） | 0.1178 | 33.5 | 268 |

- 总耗散 5.51 W = 138.6 W 的 **4.0 %**，是 0.5 % 预算（单器件 125 mW）的 **5.5 倍**。
- 反向段取绝对值后：体二极管 471 mW/器件，总耗散 770 mW/器件，8 只 6.16 W（4.45 %）。
- 端口反向电荷 0.329 µC，其中二极管支路 0.236 µC、沟道 0 µC、其余约 0.093 µC 为位移电流。
  "100 % 走体二极管"不成立，"Vf×Qrev 是实际损耗"也不成立。
- 初稿的 70 mW 与 56 % 两个数同时撤回；**反向相关损耗的保守值是 471 mW/器件**，不是 70 mW。

## 6 200.6 kHz 设计点的判据应用

设计频率由控制器决定：`f = 1/[2(6 ns·1 A/2.5615 mA + 150 ns)] = 200.609 kHz`。
软启动快照不能代替它；工作点必须用 `sim/v2/sr_tank_dual_v33_ss_1ms.cir`
（VCC 常开 + `.ic V(out)=1.89 V(ss)=4`，1 ms，取 887.6–997.3 µs 的 22 周期；见 §7）单独运行。

判据按 §2 执行；实测值统一放在
`design/v2/第三轮_测量口径与能量账本_2026-10-31.md` 的**唯一汇总表**，本文不重复。

## 7 冷启动与 200.6 kHz 工作点的统一验证方案

### 7.1 两次运行，职责分离

| 运行 | deck | 初始化 | 回答的问题 |
|---|---|---|---|
| A 冷启动 | `sr_tank_dual_v33.cir` | VCC 0→12 V 斜坡，SS 从 0 | 启动时序、软启动期 SR 行为、无直通、输出建立 |
| B 工作点 | `sr_tank_dual_v33_ss_1ms.cir` | VCC=12 V 常开，`.ic V(out)=1.89 V(ss)=4` | 额定点的 Qrev、支路损耗、均流、峰值 |

**陷阱（已实测）**：B 只加 `.ic V(ss)=4` 而保留 VCC 斜坡是无效的。UVLO 未满足时 FAULT
拉低，模型内部 SS 放电 FET（`RDIS=500 Ω`）以 `τ=Css·RDIS=5 µs` 把 4 V 泄到约 2.8 V；
500 µs 时 `V_SS≈3.03 V`，实测 232.1 kHz，不是 200.6 kHz
（对照台 `sim/v2/_probe/ss_ic_b.cir`）。VCC 常开后同一条 `.ic` 保留为 3.987 V（20 µs）
→ 4.227 V（500 µs），频率回到 200.6 kHz（`_probe/ss_ic_a.cir`）。

### 7.2 每个运行的验收步骤

1. **频率从 `V(sw)` 主边沿实测**（上升沿间隔的中位数，±35 % 带内剔除混叠），不用参数假设；
   门极周期只作旁证——SR 开通是漏极振铃上的阈值事件，门极周期本身抖动，且 200.6 kHz
   工作点的逐周期 `Qrev` 摆动达 3–96 %（`第三轮_测量口径与能量账本_2026-10-31.md` §3.4）。
2. **收敛检查**：连续窗口的 f、`Vout` 时间加权平均、Qrev、四路均流漂移小于容差
   （`tools/steady_state_check.py`，默认 0.5 % / 0.1 % / 3 % / 1 %）。
3. **端口 + 支路账本**：`tools/tank_metrics.py` + `tools/sr_energy_ledger.py`；
   残差 < 0.5 % 端口能量。
4. **非稳态窗口**单列 `ΣΔE`，不把端口净输入当热。
5. **均流**：四对完全相同是模型对称性的结果，100.000 % 不是鲁棒性证据；真实失配需另建。

### 7.3 冷启动如何到达设计点

模型 SS 电流：`V_SS<1.2 V` 时 175 µA，之后 5 µA。`Css=10 nF` 下：

```
t(V_SS=1.2 V)   = 1.2/175u × 10n = 68.6 µs
t(V_SS=3.982 V) = 68.6u + (3.982−1.2)/5u × 10n = 5.63 ms
```

所以冷启动 deck 的 500 µs 结果只能叫"软启动快照"。要直接观察冷启动到达 200.6 kHz，
需一次 ≥6 ms 的长跑；在长跑完成前，冷启动与工作点之间用上式桥接，并明确标注为**解析外推**。

## 8 未验证假设（按风险排序）

1. **v3.3 的 23 ns 毛刺拒绝**：没有器件/台架证据。数据手册的传播延迟不等于毛刺滤波。
   在验证前保留 v3.3 与"仅延迟"边界模型两条曲线。
2. **PGD 规律**：所有结论只测了 `PGD=0`；`PGD=1` 的等效驱动阻抗未校准。
3. **CPIN=100 pF 正则化**：它是数值正则，不是器件电容；灵敏度未扫。
4. **封装电感**：`Ld=0.3 nH`、`Ls=0.8 nH`、`Lg=2.5 nH` 是估计值，未从封装/布局提取。
5. **驱动边沿**：模型的 23/35 ns 未与实测门极波形对齐。
6. **TT 反向恢复回馈能量**：是本模型的数值行为；真器件以耗散为主，故 §2.3 取保守值。
7. **四路完全对称**：模型里四对元件完全相同，均流 100.000 % 是建模结果，不是设计裕量。
8. **工作点电压**：固定变比 DCX 的输出由负载与压降决定；200.6 kHz 下实测不等于 2.000 V，
   见汇总表。
