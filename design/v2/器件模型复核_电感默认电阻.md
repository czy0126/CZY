# 器件模型复核：LTspice 电感默认 1 mΩ 使 v3 器件模型多出 2 mΩ

日期 2026-10-31。状态：**SIMULATION_EVIDENCE / MODEL DEFECT（已修正，待复测）**。复核对象是工作流产出中的 `models/sr_device_v3.lib`（缺陷版本 sha256 `163a2c2e…`）。本文件不评价器件物理，只记录一个会污染 `.op/.dc/.tran` 全部结果的建模缺陷。**该缺陷已于 09:40:40 由模型作者加上 `Rser=0` 修正（新 sha256 `cb68e95b…`）；修正后的数值复测尚未完成，不得据缺陷版本引用任何电流/损耗。**

## 1 现象

用与工作流 `sr_device_bench_dc_fwd.cir` 相同的条件（VGS=10 V、ID=50 A）在 `.op` 下复测：

| 探针 | 实测 |
|---|---|
| 端电压 `V(d)` | 44.9 mV |
| 电流 `-I(Vd)` | **15.496 A**（应为 50 A） |
| 折算端电阻 | **2.898 mΩ**（模型注释目标 0.891 mΩ） |

把同一组方程展平后逐节点测量（`sim/v2/lead_probe/flat_op.cir`）：

| 节点 | 实测 | 解释 |
|---|---|---|
| `V(vgs)` | 9.9845 V | 栅压正常 |
| `V(r)` | 0.89756 mΩ | Rds(VGS) 拟合正确 |
| `V(isat)` | 1358.3 A | 饱和电流拟合正确 |
| `V(di,si)` | **13.91 mV** | 真正加在沟道上的电压 |
| `V(d)-V(di)` | 15.50 mV | 压降在 `Ld` 上 |
| `V(si)-0` | 15.50 mV | 压降在 `Ls` 上 |
| `I(Bch)` | 15.496 A | 沟道电流：13.91 mV / 0.89756 mΩ |

两个封装电感在直流下各掉 15.5 mV @15.5 A，即**各 1 mΩ**。

## 2 根因（已用最小 deck 证实）

LTspice 的 `L` 元件在未写 `Rser` 时，默认串联电阻是 **1 mΩ**（不是 0），`.op`、`.dc`、`.tran` 都有效。

```
I1 0 a 10
L1 a 0 1n            → V(a) = 10.00 mV  → 1.000 mΩ
L1 a 0 1n Rser=0     → V(a) = 0 V       → 0
```

瞬态同样存在（10 A 阶跃，150 ns）：默认 156.28 mV vs `Rser=0` 146.28 mV，差值正好 10 mV。

`models/sr_device_v3.lib` 的三条电感均未写 `Rser`：

```
Ld D di {LD}     LD=0.3n  → 隐含 1 mΩ
Ls S si {LS}     LS=0.8n  → 隐含 1 mΩ
Lg G gn {LG}     LG=2.5n  → 隐含 1 mΩ（栅极回路，影响小）
```

于是 SR 沟道串联了 **2 mΩ**，是 0.897 mΩ 的 2.2 倍；端电阻被算成 2.898 mΩ，与实测完全一致。

## 3 影响

- 任何用该模型做的正向压降、Rds(on)、反向电流、Qrev、体二极管导通能量都会被这 2 mΩ 系统性地扭曲；反向电流的符号可能不变，但幅值和损耗会显著偏差。
- `.dc`/`.op` 校准台会直接判“模型不达标”（2.9 vs 0.9 mΩ），可能被误诊为拟合公式错误。
- 这不是器件物理，是仿真器默认参数；不能写进任何签核结论。

## 4 要求的修正与复测

1. `Ld`、`Ls`、`Lg` 全部显式加 `Rser=0`（若要有意计入封装电阻，单独用 `R` 元件并标注来源，不要依赖默认值）。
2. 修正后重跑：`.op` 50 A 点（应≈0.897 mΩ）、`dc_fwd`（10/4.5/3 V）、Qoss/Qg/Qrr、双脉冲/换流台。
3. 在所有报告里记录 `Rser=0`，并把本次 2.898 mΩ 作为“修正前”对照保留。
4. 该修正不改变已通过的 `sr_timing_v3.lib`（其中无电感元件）。

**修正后独立复测（2026-10-31 09:42）**：把同一展平 deck 的三条电感改为 `Rser=0` 后，同一 `.op` 点（V(d)=44.9 mV、VGS=10 V）给出 `V(di,si)=44.900 mV`、`I(Bch)=50.027 A`、`V(r)=0.89750 mΩ`——端电阻回到 0.8976 mΩ，与拟合目标一致。证明 2.898 mΩ 完全由默认电感电阻造成，而非 Rds 公式错误。
