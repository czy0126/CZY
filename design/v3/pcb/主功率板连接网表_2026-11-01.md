# 主功率板连接网表（Stage D）— 2026-11-01

本文件交付的是**主功率板的逐脚连接关系**，不是原理图、不是 PCB、不是 Gerber。
它解决的是 Stage D 被点名两次的那个缺口：迄今只有控制验证板（`pcb/control_validation/`），
主功率腔没有任何可核对的连接定义。

方法论只有一句：**网表由仿真的 deck 生成，不由人重新画一遍**。
一张手画的原理图能通过"看起来对"的检查，却无法证明它与跑出 1.887 V / 188.3 W 的那个电路是同一个电路。
`tools/board_netlist.py` 直接读 `sim/v3/sr_tank_dual_v33_ss_1ms_100a.cir`，
把仿真节点改名为板级网络、把仿真元件改名为板级位号，输出 `net@ref.pin` 三元组。

## 1. 生成与校验

```bash
python tools/board_netlist.py --json design/v3/pcb/board_netlist.json \
                              --csv  design/v3/pcb/board_netlist.csv
python -m pytest tools/test_board_netlist.py -q
```

当前输出：

```
78 deck elements -> 66 refs, 65 nets, 193 pins
OK
```

`test_the_generated_files_are_current` 会重跑一次并与提交的 CSV 逐字节比对，
所以提交的文件一旦与 deck 脱节，测试就红——这是"原理图等于被仿真的电路"这条主张的可执行形式。

## 2. 映射规则

| 类别 | 数量 | 处理 |
|------|------|------|
| 映射到板级位号 | 45 | `PARTS` 表，逐元素声明（位号、引脚名、依据） |
| 显式补入的器件 | 25 | `CONTROLLERS`：U2 + U3–U6 + REG 电容 C7–C10 + SR 门极电阻 R20–R27 + 漏极开尔文链 R28–R35 |
| 带理由跳过 | 33 | `SKIP`，每个都写明为什么不是一块板上的器件 |
| 未映射 | **0** | 未映射会让运行以 `UNMAPPED:` 失败 |

三条最容易出错的映射：

1. **驱动芯片在 deck 里是行为模型。** `Bgh`/`Bgl` 是理想门极源，`Xsr1..4` 是 SR 时序模型。
   板上对应 U2（UCC27282）与 U3–U6（UCC24624），所以它们由 `CONTROLLERS` 显式补入，
   引脚**编号**取自 `design/v1/pin_connections.csv`（只取引脚位置；那张表的 OC 网络是 v1 旧值，已作废）。
2. **0 V 电流检测源会凭空造出节点。** `VSa1..VSb4` 串在 SR 漏极上，`da1` 与 `a1` 其实是同一块铜。
   若不合并，网表里会多出 8 个只有两个引脚的假网络。
3. **变压器中心抽头是一个物理引脚，但它不是“两个同名端相连”。**
   deck 写 `Lsa1 out a1`（抽头在前）和 `Lsb1 b1 out`（抽头在后）；SPICE 把 `L` 的第一个节点当 DOT，
   所以 CTAP 是 S_A 的 **DOT**、却是 S_B 的 **非 DOT**，S_B 的 DOT 在 `SEC_B` 端。
   两条半绕组都把 T1 的 CTAP 拉到 `out`，合并器折叠重复声明，只在**互相矛盾**时报冲突——
   早期版本假设两半顺序相同，结果报出 `T1.CTAP: VOUT vs SEC1_B`，是表错不是电路错。
   端子的 DOT/非 DOT 与对应网络见 `design/v3/magnetics/winding_polarity.csv`，
   连接图见 `winding_connections.svg`；`board_netlist.winding_layout()` 逐只校验
   deck 节点顺序、`PARTS` 引脚顺序与 K 耦合，任一不符即失败（issue #1 的回归测试）。

### 2.1 网表当场抓出的 BOM 错误

建网表时对照 `design/v1/pin_connections.csv`，发现 BOM 草案的 `R4-R6` 行（"gate resistors, qty 3"）
**缺了 7 只**：引脚表要的是 10 只 2.2 Ω 门阻——QH/QL 各一只，八只 SR 各一只。
更严重的是整行没有**漏极开尔文链**：UCC24624 的 `VD1`/`VD2` 各自经一只 0 Ω 电阻
从 SR 漏极取信号（`0ohm Kelvin -> SRnX.D`），不是直接搭在焊盘上。
少这一只 0 Ω，SR 关断就依赖焊盘处的 `L·di/dt`，正是这颗芯片要避免的东西。

BOM 已拆成三行（`R4 R5` ×2、`R20-R27` ×8、`R28-R35` ×8），网表也真的把这两串电阻画进网络：
`VG_iX —R— G_iX`、`SECi_X —R— VD_iX`，因此 `test_the_drain_sense_is_a_kelvin_link_not_a_short`
可以断言 `U3` 的引脚 4 **不在** `SEC1_A` 网络上。

门阻的"2.2 Ω vs 3.2 Ω"也已结案，不是矛盾：`R4`/`R5` 是**板上外置** 2.2 Ω，
deck 的 `Rgh`/`Rgl` 3.2 Ω 是**集总**值 = UCC27282 的 1.3/0.85 Ω + 2.2 Ω。
证据与回归测试见 `tools/test_gate_drive_calibration.py`。

### 2.2 第二轮：BOM 覆盖检查又抓出三处

网表新增 `bom_gaps()`：BOM 里有、网表里没有引脚、又不在 `NOT_A_DECK_ELEMENT` 里的位号，
一律判失败。跑出来三条，逐条对照引脚表核实：

| BOM 原行 | 问题 | 处置 |
|----------|------|------|
| `C1-C4` qty 4，"1 µF + 100 nF per IC" | 板上有**六颗** IC（U1–U6），每颗两只 = **12 只**，少 8 只 | 改为 `C101-C112` qty 12；10 µF 大电容不计入此行 |
| `R11-R14` qty 4，"HI/LI pull-downs" | 引脚表只有 **2 只** HI/LI 下拉（U2.7、U2.8），且已算在 `R7-R10` 行的描述里——这是一条**重复行** | 删除；`R11-R14` 成为空号，**勿复用** |
| （缺行） | U2.6 的 `1nF -> PGND` 滤波电容整个漏掉 | 新增 `C13` 1 nF |

`R7-R10` 同时改正了描述：并非四只 EN 下拉，而是 `R7` 10 k EN 下拉、`R8` 1 k 运行跳线、
`R9`/`R10` HI/LI 10 k 下拉。

### 2.3 人工复核抓到的值错误：自举二极管的耐压少了一半

上面三条是 `bom_gaps()` 抓的——它只检查**位号在不在**网表里，**不检查值**。
所以值错只能靠人对着 deck 的拓扑自己算。查出来一条：`D_BT` 行原写 "≥25 V"，实际要 **48 V**。

deck 第 125–126 行：

```
Dbt aux hb DBOOT
Cbt hb sw 220n Rser=.05
```

二极管的阳极接 `aux`（= `VCC12`，12 V），阴极接 `hb`。两个开关状态：

| `sw` | `hb` | 二极管两端反压 (`hb − aux`) |
|------|------|------------------------------|
| 0 V（QL 导通） | 12 V | 0 V |
| 48 V（QH 导通） | 60 V | **48 V** |

"25 V"只覆盖了反压的一半，选 25 V 件在每次 QH 开通时都会雪崩击穿。

同一条拓扑里，**`C5` 的 "≥25 V" 是对的**——这不是笔误差别，而是两种应力的差别：
电容跨在 `hb` 与 `sw` 之间，QH 导通时是 60 V − 48 V = **12 V**，QL 导通时是 12 V − 0 V = 12 V，
恒为自举电压；二极管却跨在 `hb` 与 `aux` 之间。**同一个自举电路里，两只件的耐压差 4 倍。**

电流不大：`I_avg = Qg·f = 48 nC × 200.6 kHz = 9.63 mA`（`Qg` 取手册 **max** 48 nC；
deck 自己的 `Cgh = 4 nF` 在 12 V 下也是 48 nC，两者一致），每周期压降 `Qg/C = 218 mV`（220 nF）。
所以约束是**耐压**不是电流，`≥100 V` 留了 2 倍裕量，选低 `Vf` 肖特基。

**但这几个数没有一个能从 deck 里测出来**，原因值得记下来：`Bgh gh0 sw V=...` 是一个接在
`gh0` 与 `sw` 之间的电压源，**不接在 `hb` 与 `sw` 之间**。整个 deck 里碰 `hb` 的只有 `Dbt` 和 `Cbt` 两只，
门极电荷没有一条回路经过 `Cbt`——所谓自举电容在模型里只是一个恒定 12 V 的偏置，
既不会放电也不会塌陷。因此 `I(Dbt)` 是零（只有启动时充一次），测不到平均电流，
更测不到充电尖峰。上面 9.63 mA 与 218 mV 是**代数值**，峰值约 0.4 A 按
"剩余裕量 / 回路电阻"推出（0.22 V ÷ ≈0.55 Ω），同样**未实测**。

结构锁：`test_the_deck_does_not_load_the_bootstrap_capacitor` 断言碰 `hb` 的元件恰好是
`["Cbt", "Dbt"]`、`Bgh` 的两个节点是 `gh0`/`sw`。哪天有人在 deck 里接上真实的门极负载，
这条会红，逼着把上面几个数改用实测重算。

回归锁：`test_the_bootstrap_diode_holds_off_the_full_input_voltage` 从 deck 里读出
`Dbt`/`Cbt` 的节点，再断言 BOM 行里写着 "48 V" 且不再出现 "25 V"。
先验证过它在旧值下确实红，不是装饰性测试。

## 3. lint 判据

`lint()` 只断言网表的良构性，不判断电路对不对：

- 没有单引脚网络（`PORTS` 里的对外端口除外：`VIN_P` `PGND` `VOUT` `VCC12` `VCC12_S` `RUN`）；
- 没有对同一 (位号, 引脚) 的矛盾声明；
- 引脚总数与合并后的行数一致；
- **BOM 里没有"无引脚"位号**（`bom_gaps()`）：每一个 BOM 位号要么在网表里拿到至少一只引脚，
  要么在 `NOT_A_DECK_ELEMENT` 里有逐条理由。这条是防"BOM 多买/少买"的唯一机械保障。

网络引脚数（节选）：PGND 32、OCM 6、SW 6、VOUT 6、OC 4、OCD 4、VCC12_S 4、
每条 `SECn_A/B` 3（变压器半绕组 + SR 漏 + 开尔文链一端）。

## 4. 连接关系要点（测试逐条锁死）

- **输入到腔**：`VIN_P → QH.D`，`QH.S = QL.D = SW`，`QL.S = PGND`；`R18/R19` 从各自门极到 10 k 下拉。
- **谐振腔**：`SW -Cr- CR_CT -CT- CT_LR -Lr- PRI_T1`，与 deck 的串联顺序一致，不是拓扑的"一种画法"。
- **四组原边串联**：`PRI_T1 → PRI_12 → PRI_23 → PRI_34 → PGND`，每段恰好两只变压器的引脚。
- **副边**：每组 `T.CTAP = VOUT`，`T.SEC_A/SEC_B` 各接一只 SR 漏极，SR 源极全部回 PGND。
  极性按端子计：`CTAP` 是 `S_A` 的 DOT、`S_B` 的非 DOT；`SEC_B` 是 `S_B` 的 DOT。
  完整端子表与首件记录见 `design/v3/magnetics/winding_polarity.csv` /
  `first_article_polarity_record.csv`，连接图见 `winding_connections.svg`。
- **控制**：U1 引脚号 1–8 = DT / RT / OC / SS / GD2 / GND / VCC / GD1，与 `pin_connections.csv` 一致。

## 5. 还不在网表里的东西（不隐藏，单列）

下面这些**故意不进网表**，理由逐条写在 `NOT_A_DECK_ELEMENT` 里，`bom_gaps()` 用同一份清单
把"故意不画"和"忘了画"区分开：

| 缺项 | 原因 |
|------|------|
| VDD 去耦 `C101`–`C112` | 六颗 IC 各 1 µF + 100 nF；deck 的电源是理想源，去耦不参与仿真 |
| EN 滤波 `C13` | U2.6 的 1 nF 到 PGND；deck 把 EN 恒定拉高 |
| `R7 R8 R9 R10` | EN 下拉、运行跳线、HI/LI 下拉；deck 直接驱动 HI/LI 并把 EN 置高 |
| `PS1` | 12 V 控制偏置，板外 |
| 布局、叠层、铜箔宽度 | 属于 PCB 阶段；`connector_budget.json` 已给出走线宽度下限 |

**已从本表移出**：原边门阻 `R4`/`R5`（值已结案 2.2 Ω，见 §2.1）。

## 6. CT 副边参考地：接法已定，残留的是共模

deck 把 CT 副边共地接到 `PGND`（`Vctg` 是它的模型源）。**这不是需要评审的取舍**：
OC 网络最终送进 UCC25600 的 `OC` 脚，而 UCC25600 自己就以 `PGND` 为参考。副边不接地就没有
直流回路，整流桥的公共点只会浮到漏电决定的位置。接 `PGND` 是唯一可行选择。

真正需要评审、并且本轮**给不出数字**的是**共模注入**：CT 原边串在谐振腔里，
`CR_CT`↔`CT_LR` 之间随开关摆 0–48 V，绕组对副边的寄生电容会把这段 dv/dt 变成位移电流
灌进 `OCD`/`OCM`。deck 没有建模这个电容。
现有缓解：`Rf` 1 k + `Cf` 47 nF（47 µs）、`Coc` 10 nF、10 Ω 负载本身的低阻。
布局要求：副边引线短、双绞、不跨越开关节点。

验证只有一条路——首样 100 A 满载下实测 `OC` 脚纹波，与 §3.5 的 0.573 V 直流电平比对。
在那之前此项标 **UNVERIFIED**，不得当成已解决。
