# 审核补充：请给出最终ECO验收条件

你的计算公式基本可用，但以下结论必须修正：
1. ≥2W电阻、≥3A MOS不是签核条件，按脉冲曲线、实际驱动VGS下Rds、重复率和SOA选具体料号。
2. 代码实际R总=4.7+1.5=6.2Ω，不是4.7Ω；1.5Ω为占位，而BOM要求≤0.1Ω未选MPN。应分别报告旧占位和候选，3.63V关断门限。不能将理想放电时间称实测最坏值。
3. 不继续展开VDD×故障×顺序×负载全组合。先最小五场：正常启动；导通中故障；换流边沿故障；VDD断电；故障控制电源断电。每场同时测VGS、VG、REG、VDD、钳位电流和原边驱动，限制能量，假设明确。
4. T1-T4的ELP32与Lr的ELP38可共存，不能强制同型号。RFQ中的仿真磁通应称仿真，不是实物实测；LI/NA不能用于总谐振电流判断变压器磁饱和。
5. 原生板已经有PCB，不是“没有PCB”；需要选Q41和可选钳位件、制造导出及脉冲核算。当前模型没有证据证明主板硬件合格。
