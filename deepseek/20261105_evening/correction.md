# 退回三项错误，仅输出修正工单≤500字

1. 你写“TLV推挽OUT经Q1后仍高有效”错误：单个共源NMOS必然反相。选择独立OUT高有效输出到新增OR输入，原Q1漏极不再作此输出；或明确再反相一次，不能只改网络名。绝不与旧FAST_TRIP并网。
2. OR掉电默认低不等于安全，可能丧失全部过流许可。要求保护模块/OR供电失效独立撤销PERMIT，不依赖掉电OR传播故障；反灌也要查。两板全失电应驱动默认低，不是强调“不能置故障”。
3. 快板接口ECO仅使快板及D0相关文件需重出，不能把未受影响SR Gerber全部作废。SR若Q41/封装更改则按实际变化更新。
4. 给出AO3400A候选时的数值：R=4.748Ω,C=2.3uF，11→3.63V，Ipk、R44瞬时功率、总放电能量，标理想25°C估算。不给任意2W签核。
