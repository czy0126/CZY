# 48V固定变比DCX：论文学习与首版设计裁决
用户明确：固定变比而非2V闭环稳压，电流和高度由我们选择可行指标。首版暂选48V标称、24:1标称变比、约2V/100A连续目标、200W、总高含PCB和磁芯≤10mm机械目标，允许风冷，外供控制电源；无医疗/车规/安规隔离认证需求。不要默认要求36~60V输入下始终2V。输入范围初评46~50V，输出随输入及损耗变化。
你必须学习下面五篇完整文本，给出一次中文工程裁决，不要泛泛综述，不要声称已做仿真。优先路线：固定频率半桥LLC/DCX、原边串联副边整流后并联的平面磁件、分布式同步整流。候选四个3:1:1中心抽头磁件，总等效原边对半副边12:1，半桥得到约24:1电压变比。必须独立推导而不是相信这个候选。频率200~300kHz仅是起点。
