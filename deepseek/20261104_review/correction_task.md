# 审核退回：请修正具体电路错误

上一答复不可直接执行。请只给修订后的五项工程指令，≤1000中文字：
1. 不能武断先关SR后关原边；严重故障应立即撤销原边能量注入并发出SR安全关断请求，各分支真实时延/残余能量要验证。正常停机与短路分开。不得为等SR而继续激励故障。关断SR不让体二极管消失，体二极管仍可能续流/恢复；撤回“不参与”。
2. 共用检测后两条并行路径，t_common+max(t_pri_branch,t_sr_branch)，另列最大失配；不是把两路传播时间串加。计入CT/整流/滤波、比较器小过驱、逻辑、隔离、驱动和实际Qg放电。
3. 四个变压器每件3:1:1，不是每件24:1；24:1是系统半桥和四件串联的有效变比。五件映射指T1-T4+CT；Lr是独立磁件不能遗漏。SR整流后的直流输出并联，不能含混写次级交流端直接并联。
4. 两周内到120A不符合没有PCB/磁件的现状。两周目标为控制原生板/制造包、磁件图和首件计划；100A和120A由回板及测试门槛决定。单次双脉冲不足覆盖偏置掉电/不同故障相位/温度。
5. 不假设有现成适合2V大电流的UCC24624 EVM。可购评估板需官方型号及电路适用性验证，优先自制单对真实SR验证板。快OC候选TLV3501官方典型4.5ns，仅作选型起点；LM393不得用来代表ns级保护。
请承认上述退回点，并输出可交工程师执行的简短指令；不再泛谈审核框架。
