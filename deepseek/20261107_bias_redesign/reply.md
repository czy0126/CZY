## 1. 关键错误（按严重度）

### E1. Q50 体二极管方向与“关断”定义不成立（致命）
DMP3098L-7 为 P-MOS，D=PASS_OUT，S=input。P-MOS 体二极管由 D 指向 S（阳极在D/PASS_OUT，阴极在S/VDD_IN）。  
- 当 ENABLE=0、Q52 关断、R50 把栅极拉到 S 电位 → Q50 关断，但**体二极管从 PASS_OUT 到 VDD_IN 正向导通**。  
- 因此“ENABLE 关断”并不切断 VDD_SR→VDD_IN 的反灌路径，只是把路径从沟道换成体二极管（Vf≈0.7~0.9V）。  
- 更严重：常通输入下若 VDD_IN 掉电，VDD_SR 通过 R59+D50+Q50体二极管向 VDD_IN 反灌，D50 方向（阳极R59侧、阴极VDD_SR）在此路径中**反偏**，不能阻断；Q50 体二极管才是导通元件。  
- 结论：该拓扑在“输入掉电、输出有电”时**没有反灌阻断能力**，与旧偏置切断要解决的问题同类，只是换成了体二极管路径。

### E2. D50 方向与“反灌检查”自相矛盾（致命）
D50 阳极在 R59 侧、阴极在 VDD_SR。正常供电路径 VDD_IN→Q50→R59→D50→VDD_SR 是正向，OK。  
但反灌路径 VDD_SR→R59→Q50→VDD_IN 中 D50 是**反偏**，看起来“阻断”，实际反灌走的是 Q50 体二极管（见 E1），D50 根本不在这条路径上。  
所以“D50 提供反灌阻断”是错误认知；D50 只阻断 VDD_SR 向 R59 节点倒送，不能阻断 Q50 体二极管路径。

### E3. Q52 下拉逻辑与“仅 ENABLE 时下拉”的栅极状态不安全（高）
Q52 2N7002 仅 ENABLE 时下拉栅极。ENABLE=0 时 Q52 关断，R50 10k 把 G 拉到 S。  
- 若 input 浮空，S 浮空，G 也被 R50 拉到浮空 S，Q50 状态由漏电决定；DMP3098L Ciss 最大 1008pF，浮空节点电荷保持可能使 Q50 长时间半开。  
- 需要**栅极到 source 的确定性放电路径**（例如 R50 已有，但 S 浮空时无效），以及 input 浮空检测/下拉。当前“浮空输入漏电充电待核验”不是待核验，是**必须设计闭锁状态**。

### E4. R59 22Ω 的启动/浪涌与脉冲能力未闭合（高）
22Ω±1% 在最坏 15V+5%=15.75V、D50 Vf=0.92V、VDD_SR 初始 0V 时，启动电流上界：
I_start,max = (15.75 − 0.92) / (22×0.99) = 14.83 / 21.78 = **0.681 A**。  
这远超“15/30mA 偏置模型”，也远超 R59 候选 CRCW1206 22Ω 的连续功率（0.681²×22≈10.2W 瞬时）。必须查脉冲曲线；仅按能量不够，因为 1206 脉冲能力受峰值功率和脉宽限制。  
若 C54=11.1µF 从 0 充到 14.25−0.92≈13.33V，能量≈0.5×11.1µ×13.33²≈0.986 mJ；但峰值 0.68A、时间常数 τ≈22×11.1µ≈244µs，首脉冲功率~10W，1206 能否承受要看脉冲曲线，不能只用 0.986mJ 判断。

### E5. R57 2.2kΩ/0.75W 在 18/24V 持续反灌下耗散超标（高）
R57 接 VDD_SR→Q54→GND，Q54 ENABLE_N 高时导通。若 VDD_SR 被反灌到 18V：
P = 18² / 2200 = **147.3 mW**，OK（<0.75W）。
24V：P = 24²/2200 = **261.8 mW**，OK。
但注意这是**持续**工况；若 Q54 导通且 VDD_SR 被外部 24V 硬灌，R57 本身不超，但 Q54 AO3400A 的 Vds=24V 超过其 30V 额定？AO3400A Vds=30V，24V 接近但未超；18V OK。真正问题是**如果 VDD_SR 被灌到 30V 以上**，Q54 和 R57 均危险。需要明确反灌源上限。  
另外 R57 2.2k 在 15V 正常时耗散 102mW，长期 OK；但“ENABLE_N 高时导通”意味着正常上电若 ENABLE_N 误高，R57 持续 102mW，可接受但需确认逻辑。

### E6. 无 1k 假负载时跌至 3.63V 的时间计算（需明确模型）
C54=11.1µF，R58=100k 被动泄放，R57 若 Q54 关断则不在。无 1k 假负载、无其他负载，仅 R58：
τ = 100k × 11.1µF = 1.11 s。
从 15V 跌到 3.63V：t = τ × ln(15/3.63) = 1.11 × ln(4.132) = 1.11 × 1.419 = **1.575 s**。
若从 14.25V 起：t=1.11×ln(14.25/3.63)=1.11×1.367=**1.517 s**。
若 Q54 导通（R57 2.2k 并联），τ≈2.2k×11.1µ≈24.4ms，t≈24.4ms×1.42≈**34.6ms**。  
关键：3.63V 是 UCC24624 欠压/REG 余量相关阈值吗？需确认。若 3.63V 时 Q41+4.7Ω 仍钳位 REG，则慢放电期间 Q41 可能持续短路 REG，热量需算。

### E7. Q41+4.7Ω 在慢放电下持续钳位 REG 的热量不可接受风险（高）
Q41 故障时直接钳位 REG，必须保留。若 VDD_SR 慢跌（1.5s 量级），REG 可能长时间处于钳位/欠压过渡，Q41 和 4.7Ω 的功耗取决于 REG 电压与钳位电流。  
- 若 REG  nominal 11V，4.7Ω 上若持续有电流，P= I²×4.7。即使 100mA，P=47mW；但若钳位期间 REG 源持续供电流，Q41 可能线性区耗散。  
- 不能只用“故障时短时”假设；慢放电把“短时故障”变成“秒级持续”，必须查 Q41 SOA 和 4.7Ω 脉冲/连续功率。  
检查方法：用真实 VDD_SR 掉电波形（含 C54 真实容值、R58、Q54 状态）测 REG 节点电压与 Q41 电流，算 P(t) 积分；同时查 Q41 SOA 曲线和 4.7Ω 电阻脉冲曲线。不能用理想阶跃模型。

### E8. UCC24624 REG 11V 余量未闭合（中高）
最低输入 14.25V，D50 最坏 0.92V，R59 22Ω 压降取决于负载电流。若偏置电流 15mA：压降 0.33V；30mA：0.66V。  
VDD_SR,min = 14.25 − 0.92 − 0.66 = **12.67V**（30mA 最坏）。  
若 UCC24624 REG 需要 11V 余量，12.67V 仅 1.67V 余量；但 Q50 体二极管/沟道压降、R59 公差、D50 低温 Vf 更高、栅极驱动平均电流未算，余量可能不足。  
必须算：I_bias = UCC24624 静态 + Qg×f + Q50/Q52 栅极驱动平均。不能假设 15mA 是全工况。

### E9. “外供15V”与 Q50 S=input 的栅极驱动电平（中）
Q50 S=15V，G 由 Q52 下拉到 0 时 Vgs=−15V，在 ±20V 内 OK；但 R50 10k 上拉，Q52 导通时 R50 与 Q52 Rds_on 分压，实际 Vgs 可能不是 −15V。2N7002 Rds_on 在 Vgs=5V 时约几Ω，10k 上拉，Vgs≈−15V×(Rds/(10k+Rds))≈−15V，OK。但 ENABLE 逻辑若为 5V CD4013，Q52 Vgs=5V，Rds_on 足够。需确认 Q52 栅极驱动源和 ENABLE_N 极性。

### E10. “删除Q51/Q55及原栅极跟随二极管”后阈值失配反例是否消失（中）
旧反例 0.617A 反灌来自阈值跟随失配。新拓扑没有阈值跟随，但 Q50 体二极管路径（E1）可能产生更大反灌。必须用真实器件模型（DMP3098L 体二极管 Vf-Ir 曲线）验证，不能用简化行为模型。

## 2. 逐项可执行修复

### 修复1：反灌阻断必须重新拓扑（对应 E1/E2）
- **不能**靠 Q50 体二极管方向实现阻断。可选：
  - 在 Q50 漏极/PASS_OUT 与 R59 之间加**理想二极管控制器+NMOS**（OR-ing），或
  - 把 Q50 改为**背靠背 P-MOS**（源对源或漏对漏），确保体二极管相互反向；但会引入旧阈值失配问题，需用**比较器+电荷泵**驱动，不用阈值跟随。
  - 若坚持单 Q50，必须承认“ENABLE 关断不阻断反灌”，并在系统层面保证 VDD_IN 不掉电或加外部 OR-ing。
- 验收：VDD_IN=0V、VDD_SR=18/24V、ENABLE=0/1 四象限，测 VDD_SR→VDD_IN 电流 < 目标漏电
